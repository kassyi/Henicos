# ロードマップ自律更新 & 管理ワークフロー

このワークフローは、Henicos プロジェクトのロードマップ（タスク進捗状況）を管理するためのものです。エージェントが自律的にリポジトリを走査して進捗を提案するか、人間がインタラクティブに操作するための UI サーバーを立ち上げます。

## エージェントへの指示

ユーザーから `/roadmap` コマンドを受け取ったら、ユーザーの要望に応じて以下のどちらかのモードで実行してください。特に指定がない場合は「1. エージェント自律更新モード」を実行し、UIを使いたいと言われた場合は「2. 人間用UIモード」を実行してください。

### 1. エージェント自律更新モード (デフォルト)

エージェント自身がリポジトリを調査し、タスクの進捗状況を推測・更新して提案するモードです。

1. **データソースの読み込み**: `docs/data/roadmap_tasks.json` を読み込み、現在未完了のタスク一覧を把握してください。
2. **リポジトリ走査と分析**: `grep_search` や `list_dir`, `view_file` などのツールを用いて、ソースコード（`src` や `tests` フォルダ内）を走査してください。対象タスクに関連するクラス、メソッド、テストコードが実装されているか（`[Skip]` が外れているか等）を自律的に確認してください。
3. **JSON の更新**: 実装が完了していると判断したタスクがあれば、`roadmap_tasks.json` のデータを更新（`completed: true`、および必要に応じて `notes` を追記）してください。
4. **提案 (Markdown形式)**: 更新した内容（どのタスクを完了としたか、その判断理由となるコード箇所）を Markdown 形式でユーザーに提案（報告）してください。問題なければコミットを促すようにしてください。

### 2. 人間用UIモード

ユーザーが直接ブラウザ上でタスクを管理するためのモードです。

1. `tools/roadmap-ui` ディレクトリに移動し、`npm run dev` コマンドをバックグラウンド（`IsDaemon: false` など）で起動してください。
2. サーバーが起動したら、ローカルURL（通常は `http://localhost:5173`）をユーザーに提示し、「ブラウザで開いてロードマップを確認・更新してください」と案内してください。
3. ユーザーがUI上で操作し「Save to JSON」ボタンを押すと、`docs/data/roadmap_tasks.json` が更新されます。
4. ユーザーからの完了合図を待って、必要に応じてコミットを提案してください。
