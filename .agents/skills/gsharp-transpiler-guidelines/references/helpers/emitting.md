# Compiler Helper Catalog: Emitting code

Part of the [helper catalog](../helpers.md), which also explains how to read the tables (paths, and a method called on
a receiver written with a leading dot) and where a new helper goes.

Brackets (`{}`, `()`, `[]`) follow `.agents/rules/transpiler-emission.md` §2, which says when a scope helper is needed;
fixed text (separators, keywords, `;`) is a literal. The other helpers:
