# Compiler Helper Catalog: Semantic model and syntax

Part of the [helper catalog](../helpers.md), which also explains how to read the tables (paths, and a method called on
a receiver written with a leading dot) and where a new helper goes.

| ----- | ----- | ----- |

| The compiler's intermediate representation of a method body (#1561), built from `IOperation`: one argument per parameter in parameter order with its position in the C# order of evaluation and the default values, explicit conversions, the value category of each expression (value, location, read-only location, pointer) from the way its holder uses it, one declaration per local, one `IrVariable` per local or parameter, the position of every node in the user's source (`IrSource`, `.ToLocation`); constructs without a node stay opaque leaves; nothing calls it yet | `IrBuilder.TryBuild`, `IrBuilder.BuildStatement`, `IrBuilder.BuildExpression` | a second walk of `IOperation` or syntax that decides argument order, categories or temporaries' types again |

| Whether an operand or the index of a target can stay in place across a split | `IrStayInPlace.Stays`, `IrStayInPlace.StaysAsIndex` | |

| The plan compared with the syntax passes, and written back as lowered syntax | `AstLoweringPipeline.HoistSplitPoints`; `IrSplitLoweringPass` (`IrSplitLoweringOutcome`, `IrSyntaxIndex`, `IrLoweredSyntaxPrinter`, `IrSplitAnnotationCheck`), which the syntax passes pass through (`LoweringAnnotations.IrLoweredAnnotationKind`), run first by `AstLoweringPipeline.Lower` (turned off in tests only by `AstLoweringPipeline.WithoutIrSplitLowering`) and by `AstLoweringPipeline.HoistSplitPointsWithIr` | |
| Is an operation a variable in C# (a local, parameter, `this`, array element, ref return, ref conditional, a field of a variable, an element of an inline array variable, `*p`, `p[i]`, `p->F`, a fixed-size buffer element; a field or inline array element of a value such as `MakeCell(j).F` is a value), e.g. whether an `in` argument without the keyword is passed by reference | `.IsVariable` (on an `IOperation`) | a syntax check of `MemberAccessExpressionSyntax`, or treating every `IFieldReferenceOperation` as a variable |
