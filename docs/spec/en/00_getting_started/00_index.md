# 0. Getting Started with G# (GSharp)

Welcome to G#! G# is a zero-overhead C#-to-CUDA AOT transpilation framework, operating as an Embedded Compute Dialect (eDSL) powered by standard C# syntax.

This section contains everything you need to get up to speed with writing your first GPU kernel.

### Contents

- **[1. Prerequisites & Installation](01_prerequisites.md)**
  Hardware, software requirements, and setup for GPU or CPU fallback execution.
- **[2. The Mental Model & Safety Net](02_mental_model.md)**
  Understanding Host vs. Device execution, Static Determinism, and strict ownership rules.
- **[3. The "Hello GPU" Tutorial](03_hello_gpu.md)**
  Write, build, and run your first massive parallel computation on the GPU using C#.
