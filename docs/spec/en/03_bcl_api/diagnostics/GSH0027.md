# GSH0027: Disposing borrowed resource

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0027 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Double-Free Hazards in Parameter Borrowing
By default, passing an `IDisposable` resource as a parameter to a method or constructor represents a **Borrow**. The caller retains ownership and remains responsible for disposing of the resource.

If the receiving method disposes of the borrowed resource, a subsequent call or disposal by the original owner results in a catastrophic **Double-Free** error, corrupting native driver memory structures.

## Cause

A method or class invoked `.Dispose()` on a parameter that was borrowed rather than owned.

## How to Fix

Do not dispose borrowed parameters. If ownership transfer is explicitly intended, decorate the parameter with `[TakesOwnership]`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public class Processor : IDisposable
{
    private readonly GpuBuffer<float> _borrowed;
    
    public Processor(GpuBuffer<float> borrowed)
    {
        _borrowed = borrowed;
    }

    public void Dispose()
    {
        // Error GSH0027: Disposing a borrowed resource leads to double-free crashes
        _borrowed.Dispose();
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
// Option A: Borrow without disposing
public class SafeProcessor : IDisposable
{
    private readonly GpuBuffer<float> _borrowed;
    
    public SafeProcessor(GpuBuffer<float> borrowed)
    {
        _borrowed = borrowed;
    }

    public void Dispose()
    {
        // Use borrowed resource safely without calling Dispose()
    }
}

// Option B: Explicit ownership transfer using [TakesOwnership]
public class OwningProcessor : IDisposable
{
    private readonly GpuBuffer<float> _owned;
    
    public OwningProcessor([TakesOwnership] GpuBuffer<float> owned)
    {
        _owned = owned;
    }

    public void Dispose()
    {
        _owned.Dispose(); // Allowed because caller surrendered ownership
    }
}
```
