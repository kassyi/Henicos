# GSH0042

## Gpu.SyncThreads() cannot be called from external helper methods

| | |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A call to `Gpu.SyncThreads()` was found inside a regular C# method instead of directly inside a `[GpuKernel]` method.

## Rule Description

State machine transformation is restricted to the AST of the target `[GpuKernel]` method itself. If a barrier is placed inside an external helper method, the CPU emulator cannot suspend the execution and unwind the C# call stack across method boundaries, making it physically impossible to construct the state machine.

## How to Fix

Ensure that all calls to `Gpu.SyncThreads()` reside directly in the body of the `[GpuKernel]` method, or within local functions that can be inlined by the generator.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel()
{
    HelperMethod(); 
}

public static void HelperMethod()
{
    // ❌ Error GSH0042: State machine generator cannot cross method boundaries
    Gpu.SyncThreads(); 
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel()
{
    // ✅ Correct: Local functions are inlined into the AST
    void LocalHelper()
    {
        Gpu.SyncThreads();
    }
    
    LocalHelper(); 
}
```
