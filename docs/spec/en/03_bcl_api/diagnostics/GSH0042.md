# GSH0042

## Gpu.SyncThreads() cannot be called from methods that are not GPU code

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A call to `Gpu.SyncThreads()` was found inside a method that is neither a `[GpuKernel]` nor a `[GpuDeviceFunction]` (or one of their local functions).

## Rule Description

On the CPU dialects, a barrier suspends the calling thread's state machine. The generator lowers `[GpuKernel]` bodies, and every `[GpuDeviceFunction]` that reaches a barrier, into state machines; a device function call that reaches a barrier becomes a suspension point of its caller, so a barrier can be placed in a device function and still synchronize the block. A plain C# method is not lowered, so a barrier in it cannot suspend.

## How to Fix

Mark the helper method with `[GpuDeviceFunction]`, or move the barrier into the kernel or into a local function.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel()
{
    HelperMethod();
}

public static void HelperMethod()
{
    // ❌ Error GSH0042: a plain C# method is not lowered into the state machine
    Gpu.SyncThreads();
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel()
{
    HelperMethod();
}

[GpuDeviceFunction]
public static void HelperMethod()
{
    // ✅ Correct: the device function gets its own state machine frame
    Gpu.SyncThreads();
}
```

A device function that reaches a barrier must not be recursive ([GSH0063](GSH0063.md)).
