# GSH0010: GSharp Prelude missing

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0010 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Core Transpiler Runtime Foundations
Every `.cu` file generated by G# depends on a foundational runtime header known as `Prelude.cu`. This prelude defines essential CUDA macros, fixed-width integer aliases, intrinsic wrapper prototypes, and macro expansion helpers.

If this embedded resource is missing during source generation, the compiler cannot construct valid CUDA C++ files. This error indicates an environment or build pipeline misconfiguration, such as an incomplete NuGet package or aggressive MSBuild assembly stripping.

## Cause

The embedded resource `Prelude.cu` was not found inside the `Kassyi.GSharp.Compiler` generator assembly.

## How to Fix

Ensure that your project references the correct version of `Kassyi.GSharp.Compiler` as an Analyzer/SourceGenerator without stripping embedded resources.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
<!-- Build Output -->
Error GSH0010: Could not find exactly one embedded resource ending with 'Prelude.cu'
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
<!-- In your .csproj -->
<PackageReference Include="Kassyi.GSharp.Compiler" Version="1.0.0" 
                  OutputItemType="Analyzer" 
                  ReferenceOutputAssembly="false" />
```
