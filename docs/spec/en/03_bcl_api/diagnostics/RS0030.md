# RS0030: Banned API usage (BannedApiAnalyzers)

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | RS0030 |
| **Category** | BannedApiAnalyzers (`Microsoft.CodeAnalysis.BannedApiAnalyzers`) |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

G# enforces strict safety and architecture boundaries via `Microsoft.CodeAnalysis.BannedApiAnalyzers` configured through `BannedSymbols.txt`. This diagnostic triggers in two primary user-facing scenarios:

### 1. Banned .NET APIs in GPU Code (Enforcing Static Determinism & Zero-Allocation)
Standard .NET features that depend on dynamic runtime infrastructure cannot be transpiled to GPU kernels:
- **LINQ (`System.Linq`)**: Relies on dynamic delegates, closures, heap allocations (`IEnumerable<T>`), and boxing—fundamentally violating the **Zero-Allocation** and **Static Determinism** tenets.
- **Reflection (`System.Reflection.*`, `Type.GetMethod`, `Activator.CreateInstance`)**: Dynamic member resolution and metadata inspection cannot be translated to static native CUDA C++ / PTX code.

### 2. GPU Intrinsics Invoked on the Host CPU
Hardware-specific intrinsics—such as `ThreadIndex.X`, `BlockIndex.X`, and `Gpu.SyncThreads()`—are mapped directly to GPU hardware special registers (`%tid.x`, `%ctaid.x`) and PTX instructions (`bar.sync 0`). 
Invoking them in standard CPU methods has no physical meaning (thread grids do not exist on the host CPU) and causes a runtime `GpuOnlyException`. RS0030 catches this boundary violation statically at compile time.

## Cause

Your code referenced an API explicitly listed in `BannedSymbols.txt`:
1. Using LINQ methods (`.Where()`, `.Select()`, etc.) or Reflection inside GPU-targeted code.
2. Referencing device-only primitives (`ThreadIndex`, `BlockIndex`, `Gpu.SyncThreads`) inside host CPU code.

## How to Fix

- **If using LINQ inside a GPU kernel:** Replace high-level LINQ queries with contiguous array access, pointer arithmetic, or standard zero-allocation `for` loops driven by `ThreadIndex.X`.
- **If invoking GPU intrinsics on the CPU:** GPU intrinsics must only reside inside methods annotated with `[GpuKernel]`. If you need loop indexing on the CPU, use standard CPU variables (`for (int i = 0; ...)`) or launch the kernel onto the GPU via `Gpu.Launch(...)`.

## Examples

### Scenario 1: Using LINQ inside a GPU Kernel

#### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
using System.Linq;
using Kassyi.GSharp.Runtime;

public static class KernelCollection
{
    [GpuKernel]
    public static void FilterEvenNumbers(Span<int> input, Span<int> output)
    {
        // ❌ Error RS0030: The API 'System.Linq.Enumerable' is banned in this project.
        // Reason: LINQ allocates closures, enumerators, and delegates on the GC heap.
        var evens = input.ToArray().Where(x => x % 2 == 0);
    }
}
```

#### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
using Kassyi.GSharp.Runtime;

public static class KernelCollection
{
    [GpuKernel]
    public static void FilterEvenNumbers(Span<int> input, Span<int> output)
    {
        // ✅ Correct: Direct zero-allocation index-based parallel processing
        int tid = ThreadIndex.X + BlockIndex.X * BlockDim.X;
        if (tid < input.Length)
        {
            int val = input[tid];
            if (val % 2 == 0)
            {
                output[tid] = val;
            }
        }
    }
}
```

### Scenario 2: Calling GPU Intrinsics on the Host CPU

#### Code with Error (Before)

```csharp
// Execution Context: Host (CPU)
using System;
using Kassyi.GSharp.Runtime;

public class HostApplication
{
    public static void Main()
    {
        // ❌ Error RS0030: ThreadIndex is banned on CPU host code.
        // Attempting to read GPU hardware thread registers in host CPU execution context.
        int currentThread = ThreadIndex.X;
        Console.WriteLine($"Running on thread: {currentThread}");
    }
}
```

#### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
using System;
using Kassyi.GSharp.Runtime;

public class HostApplication
{
    public static void Main()
    {
        // ✅ Correct (CPU context): Use host thread information or iteration counters
        int hostThreadId = Environment.CurrentManagedThreadId;
        Console.WriteLine($"Running on CPU thread: {hostThreadId}");

        // If GPU execution is required, launch a kernel onto the device:
        using var buffer = new GpuBuffer<int>(1024);
        Gpu.Launch(VectorKernel, new LaunchConfig(gridDim: 4, blockDim: 256), buffer);
    }

    // Execution Context: G# Kernel (GPU)
    [GpuKernel]
    public static void VectorKernel(Span<int> data)
    {
        // ✅ Correct: ThreadIndex is valid only inside [GpuKernel]
        int tid = ThreadIndex.X;
        data[tid] = tid * 2;
    }
}
```
