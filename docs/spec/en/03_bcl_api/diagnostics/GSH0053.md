# GSH0053: Cannot take ownership of a reference parameter

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0053 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Reference Semantics vs. Move Semantics
The `[TakesOwnership]` attribute defines a **Move** semantics where the caller relinquishes control and disposal responsibility of the resource to the receiving instance.

In contrast, C# reference modifiers (`ref`, `in`, `out`) couple the parameter directly to the caller's variable or memory location:
- `in` represents a read-only borrow of the caller's storage location.
- `ref` represents shared, bi-directional access to the caller's variable.
- `out` represents caller-allocated return storage initialized by the callee.

Applying `[TakesOwnership]` to a reference parameter creates a direct semantic conflict: a method or constructor cannot simultaneously "borrow" or "share" the caller's storage slot while claiming that the caller has completely surrendered custody and lifetime responsibility. To prevent double-free bugs, dangling references, and invalid aliasing, reference parameters cannot take ownership.

## Cause

The `[TakesOwnership]` attribute is applied to a parameter marked with `ref`, `in`, or `out`.

## How to Fix

Pass the parameter by value instead of by reference when transferring ownership.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public class PipelineRunner : IDisposable
{
    private readonly CudaStream _stream;

    // ❌ Error GSH0053: Cannot take ownership of 'in' parameter
    public PipelineRunner(in [TakesOwnership] CudaStream stream)
    {
        _stream = stream;
    }

    public void Dispose()
    {
        _stream.Dispose();
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public class PipelineRunner : IDisposable
{
    private readonly CudaStream _stream;

    // ✅ Correct: Ownership transferred by value
    public PipelineRunner([TakesOwnership] CudaStream stream)
    {
        _stream = stream;
    }

    public void Dispose()
    {
        _stream.Dispose();
    }
}
```
