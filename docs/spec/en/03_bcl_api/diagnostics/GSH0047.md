# GSH0047

## The lock statement is prohibited in GPU kernels

| | |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A `lock` statement was used inside a `[GpuKernel]` method.

## Rule Description

The C# `lock` statement relies on OS-level threading primitives, which do not exist on GPU hardware. Additionally, holding a lock across asynchronous suspend points (such as `Gpu.SyncThreads()`) is illegal in C# and results in deadlocks.

## How to Fix

To perform synchronized memory access on the GPU, use the atomic operations provided by the `Gpu.Atomic` class.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel(object obj)
{
    // ❌ Error GSH0047: lock statement is prohibited
    lock (obj) 
    {
        Gpu.SyncThreads();
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public unsafe static void Kernel(int* counter)
{
    // ✅ Correct: Use Atomic operations instead of lock
    Gpu.Atomic.Add(ref counter[0], 1);
}
```
