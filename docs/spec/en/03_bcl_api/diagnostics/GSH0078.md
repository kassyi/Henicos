# GSH0078: Struct cannot be laid out on the device

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0078 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

G# computes the layout of every user struct twice: as the .NET runtime lays it out on the host, and as the C++ compiler lays it out on the device. The generated device definition, the native shadow struct (`AotContexts`) and the launcher's copy code are all built from that one model, and the C++ build checks the device side with `static_assert(sizeof / alignof / offsetof)`.

Some layouts have no device form:

- **Partially overlapping `[FieldOffset]` values.** The device expresses an explicit layout as anonymous `union`s of the fields that share an offset, with padding between them. Two fields that start at different offsets but overlap cannot be written that way.
- **A `[FieldOffset]` that is not a multiple of the field's device alignment.** The C++ compiler would move the field to an aligned offset, so the device and the host would read different bytes.
- **A field of a reference type other than an array** (`string`, a class, a delegate). The device has no managed heap; arrays are the only reference types that G# copies to the device, as a pointer and a length.

Without this diagnostic the struct would either fail in the C++ build with an unexplained `static_assert`, or be copied with the wrong bytes.

## Cause

A `[GpuKernel]` parameter (by value, `ref`, `out`, an array or another array-like type) or a local variable in GPU code has a struct type that, directly or through a nested struct, has one of the layouts above. The message names the struct and the first field that causes the problem. A field whose type has no device representation at all (`decimal`, `DateTime`) is reported as [GSH0079](GSH0079.md) instead.

## How to Fix

- For an explicit layout, give each group of overlapping fields the same `[FieldOffset]` (a union), and place every field at a multiple of its alignment.
- Replace a reference-type field with a value: an index into an array parameter, a fixed-size buffer, or an `[InlineArray]`.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[StructLayout(LayoutKind.Explicit)]
public struct Overlap
{
    [FieldOffset(0)] public long A;
    [FieldOffset(4)] public int B; // starts inside A
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Overlap o, int[] r) // ❌ GSH0078: field 'B' at offset 4 partially overlaps field 'A'
    {
        r[0] = o.B;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[StructLayout(LayoutKind.Explicit)]
public struct Bits
{
    [FieldOffset(0)] public long A;
    [FieldOffset(0)] public double B; // the same offset: one union on the device
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Bits o, long[] r) // ✅
    {
        r[0] = o.A;
    }
}
```
