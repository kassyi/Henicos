# GSH0046

## async, await, and yield return are prohibited in GPU kernels

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

An `async` or `await` keyword was used in a GPU method, or a `yield return` / `yield break` statement was used directly inside a `[GpuKernel]` entry point.

## Rule Description

The `async` and `await` keywords are not supported in GPU methods (`[GpuKernel]` or `[GpuDeviceFunction]`). While `yield return` and `yield break` are supported in a static `[GpuDeviceFunction]` returning `IEnumerable<T>` (which G# lowers by inlining the iterator body directly at each consumer `foreach`), `[GpuKernel]` entry points cannot be iterators themselves.

## How to Fix

- Remove `async` and `await` from GPU methods.
- Move `yield return` / `yield break` logic out of the `[GpuKernel]` entry point into a static `[GpuDeviceFunction]` that returns `IEnumerable<T>`, and consume it from the kernel with `foreach` (see [GSH0070](GSH0070.md), [GSH0071](GSH0071.md), [GSH0072](GSH0072.md), and [GSH0073](GSH0073.md)).

## Examples

### Code with Warning / Error (Before)

```csharp
// ❌ Error GSH0046: async and await are not supported in GPU methods
[GpuKernel]
public static async Task KernelAsync()
{
    await Task.Delay(10);
}
```

### Corrected Code (After)

```csharp
// ✅ Correct: Synchronous kernel execution, optionally consuming a [GpuDeviceFunction] iterator
[GpuDeviceFunction]
public static IEnumerable<int> Range(int count)
{
    for (int i = 0; i < count; i++)
    {
        yield return i;
    }
}

[GpuKernel]
public static void Kernel(int[] output)
{
    int sum = 0;
    foreach (var x in Range(4))
    {
        sum += x;
    }
    output[ThreadIndex.X] = sum;
}
```
