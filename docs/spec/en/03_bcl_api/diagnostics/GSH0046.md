# GSH0046

## async, await, and yield return are prohibited in GPU kernels

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

An `async`, `await`, or `yield return` keyword was used inside a `[GpuKernel]` method.

## Rule Description

The C# compiler transforms `async` methods and iterator blocks into state machines. The G# compiler also transforms `[GpuKernel]` methods into custom AOT state machines. Using native state machine keywords inside a GPU kernel conflicts with the G# AST lowering process.

## How to Fix

Remove `async`, `await`, and `yield` keywords from `[GpuKernel]` methods. GPU kernels must be synchronous `void` methods.

## Examples

### Code with Warning / Error (Before)

```csharp
// ❌ Error GSH0046: async conflicts with GPU kernel state machine
[GpuKernel]
public static async Task KernelAsync()
{
    await Task.Delay(10);
}
```

### Corrected Code (After)

```csharp
// ✅ Correct: Synchronous execution only
[GpuKernel]
public static void Kernel()
{
    Gpu.SyncThreads();
}
```
