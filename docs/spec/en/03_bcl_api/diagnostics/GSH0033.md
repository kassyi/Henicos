# GSH0033: Unrolled loop may be silently ignored

## Details

| Property               | Value            |
| :--------------------- | :--------------- |
| **Diagnostic ID**      | GSH0033          |
| **Category**           | GSharpTranspiler |
| **Severity**           | Warning          |
| **Enabled by Default** | Yes              |

## Why This Rule Exists (Architectural Context)

### Loop Expansion and Dynamic Control Flow

The `Gpu.Hint.Unroll` hint translates to `#pragma unroll` in CUDA C++, instructing the `nvcc` compiler to expand the loop iterations inline. This optimization relies on sequential, predictable execution.

If the loop body contains dynamic control flow (such as `break`, `return`, or `goto`) that evaluates at runtime based on data conditions, the compiler cannot safely inline the loop. In such cases, `nvcc` often silently ignores the unroll pragma, leading to suboptimal performance without explicit feedback to the developer. G# surfaces this architectural limitation as a warning to preserve explicit behavior.

## Cause

A `for`, `while`, or `do-while` loop marked with `Gpu.Hint.Unroll` contains a `break`, `return`, or `goto` statement inside its block.

## How to Fix

Refactor the loop logic to remove the dynamic early exit (e.g., using masked execution or predicated writes), or acknowledge the dynamic nature of the loop by removing the `Gpu.Hint.Unroll` hint.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static unsafe void FindTarget(int* data, int target)
{
    Gpu.Hint.Unroll();
    for (int i = 0; i < 32; i++)
    {
        if (data[i] == target)
        {
            // ⚠️ Warning GSH0033: The loop marked with Gpu.Hint.Unroll contains dynamic control flow (break, return, goto) and may be silently ignored by the nvcc compiler
            break;
        }
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static unsafe void FindTarget(int* data, int target)
{
    // ✅ Correct: Removed the Unroll hint because dynamic control flow is required
    for (int i = 0; i < 32; i++)
    {
        if (data[i] == target)
        {
            break;
        }
    }
}
```
