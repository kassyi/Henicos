# GSH0039

## ref structs cannot be held across barrier synchronization

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A `ref` local or a local of a `ref struct` type (such as `Span<T>`) is used across a `Gpu.SyncThreads()` barrier, or a by-value parameter of a `ref struct` type is changed before the barrier and used after it. Any point where the CPU dialects split the state machine counts as a barrier: a block barrier, a warp shuffle, a grid sync, or a call to a device function that reaches one.

## Rule Description

During CPU emulation, `[GpuKernel]` methods are lowered into state machines. When a state machine suspends at `Gpu.SyncThreads()`, all active local variables are saved into a context struct.
C#'s memory model prohibits placing `ref` variables or `ref struct`s (which can only live on the stack) into a struct field. Therefore, it is impossible to persist these variables across barrier suspend points.

A by-value parameter is not saved either: when the state machine resumes, the CPU dialects pass the original argument again. A `ref struct` parameter that is only read (including writes through it, such as `span[i] = v`) therefore keeps its value and is not reported. One that is changed before the barrier (assigned, passed as `ref` or `out`, deconstructed into, or changed through one of its fields or a method that is not `readonly`) would silently return to the original argument after it, so it is reported. `ref`, `in` and `out` parameters refer to the caller's variable and are not affected.

## How to Fix

Do not hold `Span<T>`, `ReadOnlySpan<T>`, or `ref` variables across `Gpu.SyncThreads()`. You must re-acquire the span after the barrier.

For a parameter, change it after the last barrier, or keep the change in a value that can cross the barrier (such as an offset) and apply it after the barrier.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel(int* data)
{
    Span<int> span = new Span<int>(data, 10);
    span[0] = 1;
    
    // ❌ Error GSH0039: Span cannot cross barrier
    Gpu.SyncThreads();
    
    span[1] = 2; 
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel(int* data)
{
    {
        Span<int> span = new Span<int>(data, 10);
        span[0] = 1;
    }
    
    // ✅ Correct: Span is discarded before the barrier
    Gpu.SyncThreads();
    
    {
        Span<int> span = new Span<int>(data, 10);
        span[1] = 2; 
    }
}
```

### A changed parameter (Before)

```csharp
[GpuDeviceFunction]
public static int Tail(Span<int> s)
{
    // Error GSH0039: the slice is lost when the state machine resumes
    s = s.Slice(1);
    Gpu.SyncThreads();
    return s[0];
}
```

### A changed parameter (After)

```csharp
[GpuDeviceFunction]
public static int Tail(Span<int> s)
{
    int offset = 1;
    Gpu.SyncThreads();

    // Correct: the parameter is changed after the barrier
    s = s.Slice(offset);
    return s[0];
}
```
