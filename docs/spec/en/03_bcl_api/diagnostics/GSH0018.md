# GSH0018: GPU intrinsic called from host

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0018 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Execution Context Segregation and Hardware Register Isolation
APIs in `Kassyi.GSharp.Core` such as `ThreadIndex.X`, `BlockDimension.Y`, `Gpu.SyncThreads()`, and `Gpu.WarpShuffleXor()` are intrinsic markers designed to be intercepted by the Roslyn transpiler and emitted as native PTX hardware instructions (e.g. `%tid.x`, `bar.sync`, `shfl.sync.bfly`).

These instructions map to physical GPU registers that do not exist on the CPU host. If executed on the host, the real C# method throws `GpuOnlyException`. `GSH0018` catches this error at compile-time to prevent runtime CPU crashes.

## Cause

A GPU-only intrinsic API was called inside a method that is not decorated with `[GpuKernel]` or `[GpuDeviceFunction]`.

## How to Fix

Move the GPU intrinsic call into a kernel or device function, or remove it from host CPU code.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public class Program
{
    [GpuKernel]
    public static void Main()
    {
        // Error GSH0018: Cannot access GPU intrinsic methods from CPU host code
        Gpu.SyncThreads();
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public static class MyKernels
{
    [GpuKernel]
    public static void Kernel()
    {
        // Correct: GPU execution methods are valid inside [GpuKernel]
        Gpu.SyncThreads();
    }
}
```
