# GSH9999

## Source Generator Internal Error

| | |
| :--- | :--- |
| **Category** | GSharpCompiler |
| **Severity** | Error |

## Cause

An internal compiler error or unexpected exception occurred during the execution of the G# Source Generator (Transpiler).
This typically indicates a bug in the G# transpiler itself rather than an issue with the user's code.

## How to fix violations

1. Report the error along with the source code that caused it to the G# issue tracker.
2. In the meantime, try breaking up complex statements or avoiding unsupported syntax that might be triggering the crash.
