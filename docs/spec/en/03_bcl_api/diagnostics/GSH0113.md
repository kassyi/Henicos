# GSH0113: G# cannot generate the launcher of a [CudaImport] declaration

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0113 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

G# implements a `[CudaImport]` method by generating the implementing part of a `partial` method: a second part of the
containing type, in a generated file, with a body that loads the external kernel and launches it. That works only for a
declaration that such a part can complete:

- The method must be a `partial` method declaration without a body. A generated file cannot give an `extern` method a
  body, and a method that already has a body, or whose implementing part is already written, would get a second one.
- Every type that contains the method must be `partial` and must not be file-local (`file`): the generated part is a
  declaration of the same types in another file.
- The method must not be generic. A module has one kernel per entry point name, compiled for one set of argument types,
  so one launcher cannot pass the arguments of every type argument.
- The method must return `void`. A kernel returns nothing; results come back through arrays and `ref` or `out`
  parameters.

G# reports such a declaration instead of skipping it: without the diagnostic, an `extern` method would compile and fail
only when it is called, and the other shapes would fail with C# errors in generated code. Nothing is generated for a
reported method.

## Cause

`[CudaImport]` is on one of the following. The message names the method and the reason.

- An `extern` method, or a method with a body.
- A `partial` method whose implementing part is written in the project.
- A generic method (`Run<T>`).
- A method that returns a value.
- A method of a type that is not `partial`, or of a type nested in one.
- A method of a file-local type.

## How to Fix

Declare the method as `partial void` without a body, in `partial` types that are not file-local, with one method per
element type when the kernel exists for several, and write results through an array or a `ref` or `out` parameter.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: Host (CPU)
public static class NativeKernels
{
    [CudaImport("kernels.fatbin")]
    public static extern void Scale(float[] data, float factor, uint gridDimX, uint blockDimX); // error GSH0113
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public static partial class NativeKernels
{
    [CudaImport("kernels.fatbin")]
    public static partial void Scale(float[] data, float factor, uint gridDimX, uint blockDimX);
}
```
