# GSH0082: Struct array cannot be passed to a CPU kernel yet

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0082 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The CUDA launcher converts a struct whose host and device layouts differ through its native shadow struct (`AotContexts`), element by element for an array ([GSH0080](GSH0080.md)). The CPU launcher converts such a struct passed by value or by `ref` the same way (it pins the struct's array fields instead of copying them), but not yet an array of such structs: it passes the array as a pointer to its managed elements, in the host layout. The C++ kernel reads the device layout, so the elements are read with the wrong bytes, and a pointer read from the wrong offset can crash the process.

On the CPU dialect the layouts differ when the runtime may reorder the fields on the host: a `LayoutKind.Auto` struct, or a struct that holds an array field (directly, in a nested struct or in an `[InlineArray]` element). The vector types are 4-byte aligned on both sides, so they do not cause this diagnostic.

## Cause

A `[GpuKernel]` parameter of a project with the CPU dialect is an array-like type (`T[]`, `Span<T>`, ...) of such a struct.

## How to Fix

- Remove `LayoutKind.Auto` from the struct.
- Replace an array field with a separate array parameter and an index or offset in the struct.
- Build for the CUDA dialect, which converts the struct.

## Remarks

This is a limitation of the current CPU launcher, not of the struct: the CPU launcher passes an array of structs in the host layout. This error is removed when the CPU launcher converts struct arrays as the CUDA launcher does. A single struct of the same type, by value or by `ref`, is already converted.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (CPU dialect)
public struct Bag
{
    public int Count;
    public int[] Items;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Bag[] bags, int[] counts) // ❌ GSH0082: field 'Items' is an array
    {
        counts[ThreadIndex.X] = bags[ThreadIndex.X].Count;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (CPU dialect)
public struct Bag
{
    public int Start;
    public int Count;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Bag[] bags, int[] items, int[] counts) // ✅
    {
        counts[ThreadIndex.X] = bags[ThreadIndex.X].Count;
    }
}
```
