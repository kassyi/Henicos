# GSH0019: Manual GetEnumerator calls are not supported

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0019 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### State Machine Allocation and Interface Invocation
Explicitly calling `.GetEnumerator()` invokes interface methods on collections that allocate enumerator state machines on the managed heap. GPU kernels do not have a managed runtime to support interface tables or object tracking.

## Cause

An explicit invocation of `GetEnumerator()` was found in device code.

## How to Fix

Use standard index-based `for` loops or iterate over `Span<T>`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadKernel(float[] data)
{
    // Error GSH0019: Explicit enumerator call allocates managed object
    var enumerator = data.GetEnumerator();
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel(float[] data, int length)
{
    // Correct: Direct array indexing avoids enumerators entirely
    for (int i = 0; i < length; i++)
    {
        float val = data[i];
    }
}
```
