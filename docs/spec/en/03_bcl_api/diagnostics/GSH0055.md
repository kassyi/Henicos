# GSH0055: Native API definition violates the schema

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0055 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Generated Code Must Be Correct by Construction
A native API definition is turned directly into C# declarations (`[DllImport]` bindings or kernel launchers). Values
that become symbols are validated before any code is emitted so that a typo surfaces as a precise error on the YAML
line rather than as a confusing compiler error inside a generated file.

Each definition binds exactly one kind of native code:

| Key | Binding | Generated code |
| :--- | :--- | :--- |
| `libraryName` | Host shared library (`.dll` / `.so`) | `extern` methods with `[DllImport]`, plus a `DllImportResolver` when `libraryNames` or a path is used |
| `moduleName` | Device module (`.fatbin` / `.cubin` / `.ptx`) | Launchers that load the kernel named by `entryPoint` and call `cuLaunchKernel` |

## Cause

One of the following:

- `namespace`, `className`, a method `name`, or a parameter `name` / `type` is missing.
- A `namespace`, `className`, method or parameter name is not a valid C# identifier.
- Both `libraryName` and `moduleName` are specified, or neither is.
- `libraryNames` is specified without `libraryName`.
- A method of a `moduleName` definition declares a `returnType` other than `void` (kernels cannot return values).
- `isUnsafe` is not `true` or `false`; `methods` / `parameters` is not a sequence.
- Two definitions in the same project declare the same `namespace` + `className`.

## How to Fix

Follow the message, which names the offending key. Split a definition that mixes host and device bindings into two
files.

## Examples

### Code with Warning / Error (Before)

```yaml
namespace: MyApp.Native
className: MyKernels
moduleName: ./native/my_kernels.fatbin
methods:
  - name: Reduce
    # ❌ Error GSH0055: 'returnType' must be 'void' for module (kernel) bindings
    returnType: float
    parameters:
      - { name: data, type: "float[]" }
```

### Corrected Code (After)

```yaml
namespace: MyApp.Native
className: MyKernels
moduleName: ./native/my_kernels.fatbin
methods:
  - name: Reduce
    entryPoint: reduce_kernel
    # ✅ Correct: results are written to an output array
    parameters:
      - { name: data, type: "float[]" }
      - { name: result, type: "float[]" }
```
