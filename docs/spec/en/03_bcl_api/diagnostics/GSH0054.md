# GSH0054: Native API definition is not valid YAML

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0054 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Reflection-Free, Deterministic Parsing
Native API definitions are evaluated at compile time by the `NativeApiGenerator` source generator. To honor the
**AST-Driven** and **Static Determinism** tenets, G# does not load a reflection-based YAML deserializer inside the
compiler. Instead, it parses a well-defined YAML subset with a dedicated parser, so every definition produces the same
bindings on every machine and in every IDE.

Constructs outside that subset are rejected instead of being silently misread:

| Supported | Rejected |
| :--- | :--- |
| Block mappings and sequences (including indentless sequences) | Tabs used for indentation |
| Single-line flow collections: `[a, b]`, `{ name: x, type: int }` | Multi-line flow collections and quoted scalars |
| Plain, `'single'` and `"double"` quoted scalars | Anchors (`&`), aliases (`*`), tags (`!`), directives (`%`) |
| Literal (`\|`) and folded (`>`) block scalars | Multiple documents |
| `#` comments and a leading `---` marker | Duplicate keys |

The diagnostic is reported at the offending line of the YAML file.

## Cause

A file included as `<AdditionalFiles Include="..." GSharpApi="true" />` contains invalid YAML or a construct outside
the supported subset.

## How to Fix

Correct the reported line. The most common mistakes are an unquoted comma or `]` / `}` inside a flow collection, and
a plain scalar containing `: `. Quote such values.

## Examples

### Code with Warning / Error (Before)

```yaml
namespace: MyApp.Interop
className: MyBlas
libraryName: myblas
methods:
  - name: myblasSgemm
    parameters:
      # ❌ Error GSH0054: the comma splits the flow mapping
      - { name: c, type: IntPtr, description: Matrix C, overwritten with the result. }
```

### Corrected Code (After)

```yaml
namespace: MyApp.Interop
className: MyBlas
libraryName: myblas
methods:
  - name: myblasSgemm
    parameters:
      # ✅ Correct: the value is quoted
      - { name: c, type: IntPtr, description: "Matrix C, overwritten with the result." }
```
