# GSH0015: Auto-allocated array in loop

## Details

| Property               | Value            |
| :--------------------- | :--------------- |
| **Diagnostic ID**      | GSH0015          |
| **Category**           | GSharpTranspiler |
| **Severity**           | Warning          |
| **Enabled by Default** | Yes              |

## Why This Rule Exists (Architectural Context)

### Managed GC Pressure and Driver Allocation Thrashing

When a kernel specifies a non-void return type (e.g. `public static float Compute()`), the G# Source Generator automatically creates a companion `Launch*` method that dynamically allocates a managed C# array (`new float[gridDim * blockDim]`) on the host heap on every invocation.

1. **GC Spikes in Real-Time Loops**: Calling this inside a tight simulation loop or game frame (60+ FPS) allocates hundreds of thousands of heap objects per second, quickly triggering Gen 0/Gen 1 Garbage Collection pauses on the CPU.
2. **Driver Allocation Overhead**: Under the hood, the runtime must allocate and free temporary GPU buffers via `cuMemAlloc` and `cuMemFree` on every call.
   For performance-critical loops, the **Explicit Output Buffer Pattern** must be used.

## Cause

An auto-allocating kernel launcher method was called from within a host CPU loop (`for`, `while`, `do-while`, `foreach`).

## How to Fix

Pre-allocate a single managed array or `GpuBuffer<T>` outside the loop, and pass it into a `void`-returning kernel.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
// Host Code
for (int frame = 0; frame < 1000; frame++)
{
    // ⚠️ Warning GSH0015: Allocates a new float[] on every iteration, causing GC spikes
    float[] results = MathKernels.LaunchCompute(inputs, gridDimX: 10, blockDimX: 256);
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
// Host Code
// ✅ Correct: Pre-allocate once outside the loop and reuse across iterations
float[] results = new float[2560];
for (int frame = 0; frame < 1000; frame++)
{
    MathKernels.LaunchComputeVoid(inputs, results, gridDimX: 10, blockDimX: 256);
}
```
