# GSH0049

## Test classes must inherit from required base classes

| | |
| :--- | :--- |
| **Category** | GSharpTestArchitecture |
| **Severity** | Error |

## Cause

A test class containing `[Fact]` or `[Theory]` methods does not inherit from one of the required base classes (`TranspilerTestBase`, `StateMachineTestBase`, or `DocTestBase`).

## Rule Description

To ensure the correct behavior and isolation of GSharp compiler and runtime tests, all test classes utilizing the test framework must inherit from a standardized base class. This base class provides dialect management, fast-hash snapshot naming, and test generator utilities.

## How to Fix

Modify the class declaration to inherit from the appropriate base class:
- Use `StateMachineTestBase` for state machine lowering and AST manipulation tests.
- Use `TranspilerTestBase` for standard execution or transpilation tests.

## Examples

### Code with Warning / Error (Before)

```csharp
// ❌ Error GSH0049: Test class does not inherit from TranspilerTestBase or StateMachineTestBase
public class MyCompilerTests 
{
    [Fact]
    [Trait("Category", "Compiler")]
    public void MyTest()
    {
        // ...
    }
}
```

### Corrected Code (After)

```csharp
// ✅ Correct: Test class inherits from StateMachineTestBase
public class MyCompilerTests : StateMachineTestBase
{
    [Fact]
    [Trait("Category", "Compiler")]
    public void MyTest()
    {
        // ...
    }
}
```
