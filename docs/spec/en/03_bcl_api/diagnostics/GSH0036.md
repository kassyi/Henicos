# GSH0036

## GPU code type must be partial

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A class containing methods annotated with the `[GpuKernel]` or `[GpuDeviceFunction]` attribute, or a class, struct or record that encloses such a class, is not declared with the `partial` modifier. A struct that holds device functions itself is not reported: the generator does not add members to it.

## Rule Description

The GSharp source generator needs to inject runtime context classes (like `AotContexts`), managed state machines, and launch wrapper methods alongside the original GPU method declaration. When GPU code is declared inside a nested type, every enclosing type must also be `partial` so the generated partial declaration can be nested inside them without compilation errors (`CS0260`).

## How to Fix Violations

Add the `partial` modifier to the type declaration and any enclosing type declarations.

### Example

**Violating code:**
```csharp
// ❌ GSH0036: MyGpuKernels is not partial, preventing the source generator 
// from appending the necessary context and wrapper methods.
public class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```

**Fixed code:**
```csharp
// ✅ Safe: The partial modifier allows the generator to extend the class.
public partial class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```
