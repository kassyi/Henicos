# GSH0036

## Kernel class must be partial

| | |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A class containing methods annotated with the `[GpuKernel]` or `[GpuDeviceFunction]` attribute is not declared with the `partial` modifier.

## Rule Description

The GSharp source generator needs to inject runtime context classes (like `AotContexts`) and launch wrapper methods alongside the original kernel declaration. If the class is not declared as `partial`, the generator cannot append these necessary members to the same class, resulting in compilation errors (`CS0260`).

## How to Fix Violations

Add the `partial` modifier to the class declaration.

### Example

**Violating code:**
```csharp
// ❌ GSH0036: MyGpuKernels is not partial, preventing the source generator 
// from appending the necessary context and wrapper methods.
public class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```

**Fixed code:**
```csharp
// ✅ Safe: The partial modifier allows the generator to extend the class.
public partial class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```
