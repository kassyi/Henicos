# GSH0036

## GPU code type must be partial

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A class, struct or record containing methods annotated with the `[GpuKernel]` or `[GpuDeviceFunction]` attribute, or a type that encloses such a type, is not declared with the `partial` modifier.

## Rule Description

The GSharp source generator needs to inject runtime context classes (like `AotContexts`), managed state machines, the managed versions of device functions (which give the GPU result where C# would throw, such as `int.MinValue / -1`), and launch wrapper methods alongside the original GPU method declaration. This holds for a struct as for a class: a device function of a struct that is not `partial` would run the user's C# operators on the managed path. When GPU code is declared inside a nested type, every enclosing type must also be `partial` so the generated partial declaration can be nested inside them without compilation errors (`CS0260`).

## How to Fix Violations

Add the `partial` modifier to the type declaration and any enclosing type declarations. A struct that was written without `partial` and holds a device function needs it too.

### Example

**Violating code:**
```csharp
// ❌ GSH0036: MyGpuKernels is not partial, preventing the source generator 
// from appending the necessary context and wrapper methods.
public class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```

**Fixed code:**
```csharp
// ✅ Safe: The partial modifier allows the generator to extend the class.
public partial class MyGpuKernels
{
    [GpuKernel]
    public static void Kernel() { }
}
```
