# GSH0068

## Disposable local is never disposed

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A local variable is initialized with a new resource whose type implements `IDisposable` (`var ctx = new GpuWorkspace();`), and the method neither disposes it nor passes the ownership on.

## Rule Description

The method that creates a resource owns it. This is the "Undisposed Local" pattern of Layer 1 in the [memory safety guide](../../04_guides/02_memory_safety_patterns.md).

The local is accepted when the method contains any of these:

- a `using` declaration or `using` statement for it;
- `ctx.Dispose()` or `ctx?.Dispose()` (also `DisposeAsync`);
- a move of the ownership: an argument of a constructor (`new T(..., ctx, ...)`, as in Roslyn CA2000 `dispose_ownership_transfer_at_constructor`), an argument for a `[TakesOwnership]` parameter or a `ref` / `out` parameter, `return`, an assignment to another variable or a field, or a use inside a lambda or local function;
- any other use that is not a member access or an ordinary argument (an ordinary argument only borrows the resource).

Limits: the check is not flow-sensitive. One disposal anywhere in the method satisfies it, so a disposal that only some paths reach (an early `return` before `Dispose()`) is not reported. Only a local initialized in place with `new` is tracked, not one assigned later or initialized from a call.

## How to Fix

Declare the local with `using`, call `Dispose()` in a `finally` block, or hand the ownership to a `[TakesOwnership]` parameter, a field or the return value.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public void Run()
{
    // ❌ Error GSH0068: ctx leaves scope without Dispose()
    var ctx = new GpuWorkspace();
    ctx.Compute();
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public void Run()
{
    // ✅ Correct: disposed when the scope ends
    using var ctx = new GpuWorkspace();
    ctx.Compute();
}
```
