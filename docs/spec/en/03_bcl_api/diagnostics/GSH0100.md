# GSH0100: Every block reduces the whole sequence of an AsParallel() aggregate

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0100 |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

`data.AsStackEnumerable().AsParallel().Sum()` gives every calling thread the sum of the whole sequence. On CUDA, the threads of a block share the elements of the sum. When the inputs are the same in every block as well, the threads of the whole grid could share them, but combining the block results needs a grid sync, which only a cooperative launch allows. G# does not change how a kernel is launched on its own, so in a kernel that is not cooperative every block reads the whole sequence. The result is correct; the reads are repeated once per block.

## Cause

An `AsParallel()` aggregate that the threads of a block share (see [GSH0099](GSH0099.md) for when they cannot), whose source, stage arguments and lambda inputs do not depend on `BlockIndex`, in a kernel without `[GpuKernel(Cooperative = true)]`.

## How to Fix

Mark the kernel `[GpuKernel(Cooperative = true)]` to divide the work across the grid. A cooperative launch limits the grid to the blocks that can run at the same time on the device. Keep the kernel as it is when that limit does not suit it or the sequence is small.

## Example

```csharp
[GpuKernel]
public static void Run(int[] data, int[] result)
{
    // GSH0100: every block sums the whole of data
    result[BlockIndex.X * BlockDimension.X + ThreadIndex.X] = data.AsStackEnumerable().AsParallel().Sum();
}

[GpuKernel(Cooperative = true)]
public static void RunCooperative(int[] data, int[] result)
{
    // The threads of the grid share the elements
    result[BlockIndex.X * BlockDimension.X + ThreadIndex.X] = data.AsStackEnumerable().AsParallel().Sum();
}
```
