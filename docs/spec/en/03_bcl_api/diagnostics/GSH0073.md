# GSH0073: IteratorExpansionTooLarge

- **Severity**: Warning
- **Category**: `GSharp.Compiler`
- **Message Format**: `"Expanding the iterator '{0}' at this foreach would copy the loop body {1} times (limit {2})"`

## Cause

Device iterators in G# are lowered by **inlining at each consumer `foreach`**: the compiler clones the iterator body into the consumer and substitutes every `yield return expr;` with a copy of the `foreach` loop body bound to `expr`. When an iterator contains $N$ `yield return` statements (or chains through nested iterators whose `yield return` counts multiply along the expansion path), the consumer loop body is duplicated that many times in the emitted CUDA C++ / CPU C++ function.

`GSH0073` is reported as a warning on a consumer `foreach` statement when the total number of loop-body copies produced by expanding the iterator exceeds `32` (`IteratorInliner.MaxBodyCopies`). Excessive loop-body duplication can increase code size and register pressure on the GPU.

## Example (Warning)

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> SixItems(int seed)
    {
        yield return seed;
        yield return seed + 1;
        yield return seed + 2;
        yield return seed + 3;
        yield return seed + 4;
        yield return seed + 5;
    }

    [GpuDeviceFunction]
    public static IEnumerable<int> SixBySix(int seed)
    {
        foreach (var x in SixItems(seed))
        {
            foreach (var y in SixItems(x))
            {
                yield return y;
            }
        }
    }

    [GpuKernel]
    public static void ConsumeKernel(int[] output)
    {
        // Warning GSH0073: Expanding 'SixBySix' copies the loop body 6 * 6 = 36 times (limit 32).
        foreach (var v in SixBySix(1))
        {
            output[0] += v;
        }
    }
}
```

## How to Fix

1. **Collapse multiple `yield return` statements into a loop**: Instead of listing many discrete `yield return` statements, iterate over a `for` loop or a `[Constant]` / `[InlineArray]` table and emit a single `yield return` inside the loop. A loop with a single `yield return` duplicates the consumer body only once.
2. **Reduce nested iterator fan-out**: If an outer iterator chains multiple multi-yield inner iterators, flatten the computation into a single loop or keep the product of `yield return` counts at or below `32`.

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> SixItems(int seed)
    {
        for (int i = 0; i < 6; i++)
        {
            yield return seed + i; // 1 yield return copy
        }
    }

    [GpuDeviceFunction]
    public static IEnumerable<int> SixBySix(int seed)
    {
        foreach (var x in SixItems(seed))
        {
            foreach (var y in SixItems(x))
            {
                yield return y; // 1 * 1 * 1 = 1 loop body copy
            }
        }
    }

    [GpuKernel]
    public static void ConsumeKernel(int[] output)
    {
        foreach (var v in SixBySix(1))
        {
            output[0] += v;
        }
    }
}
```
