# GSH0002: String usage not supported in GPU kernels

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0002 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Memory Layout and Divergence Hazards of Strings
`System.String` in C# is a reference type backed by a variable-length buffer of UTF-16 characters stored on the managed heap. Using strings inside GPU kernels is fundamentally incompatible with GPU architecture:

1. **Warp Divergence in String Operations**: GPU threads in a warp (32 threads) execute the same instruction in lockstep. Comparing or manipulating variable-length string buffers causes extreme **Warp Divergence**, serializing thread execution and destroying GPU compute throughput.
2. **Dynamic Encoding and Interning**: String manipulation requires memory reallocations, null-termination or length prefixes, and Unicode encoding tables, none of which exist in native PTX.
3. **Register Pressure**: Storing strings in thread registers is prohibited by hardware register file limits. Identifiers and states should always be represented by fixed-size numeric primitives or enums.

## Cause

The `string` keyword, string literals, string interpolation, or string methods were used inside a `[GpuKernel]` or `[GpuDeviceFunction]`.

## How to Fix

Represent identifiers, flags, categories, and states using numeric primitive types (`int`, `uint`) or strongly-typed C# `enum`s. For fixed byte sequences, use unmanaged fixed-size buffers (`inline array` or `fixed byte Buffer[N]`).

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public static class Kernels
{
    [GpuKernel]
    public static void BadKernel()
    {
        // Error GSH0002: The string type is not supported in GPU kernels
        string state = "RUNNING";
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public enum ProcessState : int
{
    Idle = 0,
    Running = 1,
    Completed = 2
}

public static class Kernels
{
    [GpuKernel]
    public static void GoodKernel()
    {
        // Correct: Enums map directly to native 32-bit GPU registers
        ProcessState state = ProcessState.Running;
    }
}
```
