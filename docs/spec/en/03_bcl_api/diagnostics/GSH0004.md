# GSH0004: GPU method return type must be void or blittable

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0004 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Hardware Kernel ABI and Device Function Calling Conventions
In the NVIDIA CUDA execution model, GPU execution fundamentally enforces zero reference-type heap allocations on the device:

1. **Kernel Entry Points (`__global__`)**: A kernel entry point is mandated by the hardware ABI to return `void`. G# provides a convenience feature where a kernel returning an unmanaged value type (e.g., `float`, `struct`) is automatically lowered into an implicit output buffer where each thread writes to `result[threadId]`. Managed reference types or arrays cannot be returned because the device cannot allocate managed objects.
2. **Device Functions (`__device__`)**: Device functions decorated with `[GpuDeviceFunction]` can return `void`, an unmanaged blittable type, or be a valid device iterator (`IEnumerable<T>` yielding value types). Managed reference types (e.g., `string`, classes, managed arrays) have no device representation and cannot be returned.

## Cause

A method decorated with `[GpuKernel]` or `[GpuDeviceFunction]` declared a return type other than `void`, an unmanaged blittable value type, or (for device functions) a valid device iterator.

## How to Fix

- For kernels: Change the return type to `void` and pass pre-allocated output buffers as parameters, or return an unmanaged value type for automatic per-thread buffer lowering.
- For device functions: Return `void`, an unmanaged blittable type, or `IEnumerable<T>` with `yield return` if implementing a device iterator.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel / Device Function (GPU)
// ❌ Prohibited: A kernel cannot return a managed array object directly
[GpuKernel]
public static float[] BadKernel()
{
    // Error GSH0004: Method 'BadKernel' returns unsupported type 'float[]'. ...
    return new float[10];
}

// ❌ Prohibited: A device function cannot return a managed reference type
[GpuDeviceFunction]
public static string BadHelper(int x)
{
    // Error GSH0004: Method 'BadHelper' returns unsupported type 'string'. ...
    return "";
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel / Device Function (GPU)
// ✅ Option A (Recommended): Explicit output buffer pattern with void return
[GpuKernel]
public static void GoodKernel(float[] result, int length)
{
    int tid = ThreadIndex.X + BlockIndex.X * BlockDimension.X;
    if (tid < length)
    {
        result[tid] = 1.0f;
    }
}

// ✅ Option B: Return an unmanaged scalar (lowered to per-thread auto-allocated array)
[GpuKernel]
public static float GoodScalarKernel()
{
    return 1.0f;
}

// ✅ Option C: A device function returning an unmanaged blittable type
[GpuDeviceFunction]
public static int GoodHelper(int x)
{
    return x + 1;
}

// ✅ Option D: A device function returning a device iterator
[GpuDeviceFunction]
public static IEnumerable<int> CountUp(int n)
{
    for (int i = 0; i < n; i++)
    {
        yield return i;
    }
}
```
