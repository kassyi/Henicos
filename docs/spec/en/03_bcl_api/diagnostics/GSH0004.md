# GSH0004: GpuKernel return type must be void or blittable

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0004 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Hardware Kernel ABI and Grid Concurrency Constraints
In the NVIDIA CUDA execution model, a kernel entry point (`__global__`) is strictly mandated by the hardware and driver ABI to return `void`. 

1. **Grid-Wide Concurrency**: When a kernel launches, tens of thousands of threads execute across dozens of Streaming Multiprocessors concurrently and asynchronously. There is no single "return value register" or accumulator that represents the collective result of an entire grid.
2. **Auto-Allocation Buffer Contracts**: G# offers a convenience feature where a kernel returning an unmanaged value type (e.g. `float`, `struct`) is automatically lowered into an implicit output buffer where each thread writes to `result[threadId]`. However, returning managed reference types or arrays directly from the signature (`public static float[] Kernel()`) breaks the ABI calling convention because the device has no means to construct or size a managed C# array object in VRAM.
3. **Zero-Allocation Host Contract**: For production performance, host code should always allocate buffers upfront and pass them into `void` kernels to avoid implicit allocations.

## Cause

A method decorated with `[GpuKernel]` declared a return type other than `void` or a supported unmanaged blittable value type (such as returning a managed array `float[]` or a class).

## How to Fix

Change the return type to `void` and pass pre-allocated output arrays as parameters, or return a single unmanaged primitive (`float`, `int`) for automatic per-thread buffer lowering.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
// ❌ Prohibited: A kernel cannot return a managed array object directly
[GpuKernel]
public static float[] BadKernel()
{
    // Error GSH0004: GpuKernel return type must be void or blittable
    return new float[10];
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
// ✅ Option A (Recommended): Explicit output buffer pattern with void return
[GpuKernel]
public static void GoodKernel(float[] result, int length)
{
    int tid = ThreadIndex.X + BlockIndex.X * BlockDimension.X;
    if (tid < length)
    {
        result[tid] = 1.0f;
    }
}

// ✅ Option B: Return an unmanaged scalar (lowered to per-thread auto-allocated array)
[GpuKernel]
public static float GoodScalarKernel()
{
    return 1.0f;
}
```
