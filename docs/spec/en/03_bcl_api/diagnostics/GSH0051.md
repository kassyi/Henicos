# GSH0051: [TakesOwnership] applied to non-IDisposable type

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0051 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Ownership Semantics and the Disposable Contract
In GSharp, the `[TakesOwnership]` attribute represents a formal transfer of resource management responsibility. When a constructor parameter is marked with `[TakesOwnership]`, the caller surrenders the duty of disposing of the resource, transferring full ownership and disposal obligations to the newly created instance.

Applying `[TakesOwnership]` to a type that does not implement `System.IDisposable` (such as primitive integers, non-disposable structs, or general data classes) is a semantic contradiction. Because non-disposable types have no deterministic cleanup mechanism or native handles to manage, transferring "ownership" has no meaningful lifecycle consequence and leads to confusion or false assumptions regarding resource safety.

## Cause

A constructor parameter is decorated with the `[TakesOwnership]` attribute, but the parameter's type does not implement `System.IDisposable`.

## How to Fix

- If the parameter represents plain data (such as configuration integers, coordinates, or non-disposable structures), remove the `[TakesOwnership]` attribute.
- If the parameter wraps an unmanaged or native GPU handle, ensure its type implements `System.IDisposable`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public class BufferConfiguration : IDisposable
{
    private readonly int _bufferSize;

    // ❌ Error GSH0051: 'int' does not implement IDisposable
    public BufferConfiguration([TakesOwnership] int bufferSize)
    {
        _bufferSize = bufferSize;
    }

    public void Dispose()
    {
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
// Option A: Plain data parameter without [TakesOwnership]
public class BufferConfiguration : IDisposable
{
    private readonly int _bufferSize;

    // ✅ Correct: Non-disposable parameter passed as normal value
    public BufferConfiguration(int bufferSize)
    {
        _bufferSize = bufferSize;
    }

    public void Dispose()
    {
    }
}

// Option B: Transferring ownership of an actual IDisposable resource
public class StreamManager : IDisposable
{
    private readonly CudaStream _stream;

    // ✅ Correct: CudaStream implements IDisposable
    public StreamManager([TakesOwnership] CudaStream stream)
    {
        _stream = stream;
    }

    public void Dispose()
    {
        _stream.Dispose();
    }
}
```
