# GSH0059: Malformed trusted key line

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0059 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The G# fatbin compilation pipeline verifies binary signatures using a set of trusted public keys specified in `trusted_keys.txt`. If a trusted public key line contains typos, invalid Base64 or hex encodings, or incorrect byte lengths, silently ignoring the line could lead to unexpected signature verification failures at runtime or security misconfigurations during deployment.

To ensure build safety and fail fast on configuration errors, the `TrustedKeysGenerator` inspects each non-empty, non-comment line in `trusted_keys.txt`. Any line that is not a valid 64-character hex key or 44-character Base64 key triggers `GSH0059`.

## Cause

A line in `trusted_keys.txt` is malformed. Valid lines must meet one of two criteria:

- **Hex:** Exactly 64 hex characters (`0-9`, `a-f`, `A-F`), decoding to 32 bytes.
- **Base64:** Exactly 44 characters ending with `=`, where the first 43 characters are valid Base64 characters (`A-Z`, `a-z`, `0-9`, `+`, `/`), decoding to 32 bytes.

## How to Fix

Check the line number specified in the diagnostic error message and correct the public key format or encoding in `trusted_keys.txt`. Comments starting with `#` and empty lines are permitted.

## Examples

### Code with Error (Before)

`trusted_keys.txt`:
```
# Primary Key
d75a980182b10ab7d54bfed3c964073a0ee172f3daa62325af021a68f707511a

# ❌ Error GSH0059: Malformed trusted key line
AAAA!!notbase64==
```

### Corrected Code (After)

`trusted_keys.txt`:
```
# Primary Key
d75a980182b10ab7d54bfed3c964073a0ee172f3daa62325af021a68f707511a

# ✅ Valid Base64 key (44 characters ending with '=')
1111111111111111111111111111111111111111111=
```
