# GSH0102: Method is too deeply nested or too complex to compile

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0102 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

Transpiling C# expressions and control flow structures into target GPU device code requires recursive syntax analysis and AST lowering. When an expression or call chain is excessively nested, the compiler may exhaust the available execution stack space (throwing <xref:System.InsufficientExecutionStackException>). Instead of crashing with an internal compiler error (`GSH0048`), G# detects stack exhaustion and reports `GSH0102` to point the developer directly to the offending method.

## Cause

An expression or control flow construct inside a `[GpuKernel]` or `[GpuDeviceFunction]` is too deeply nested, or an invocation chain requires more execution stack space than is safely available in the compiler runtime.

## How to Fix

Break up deeply nested expressions by storing intermediate results into local variables, or decompose large methods into smaller helper functions.

## Example

```csharp
[GpuKernel]
public static void Kernel(int[] data)
{
    // Deeply nested expression tree that exhausts compiler execution stack
    int x = (/* ... excessively deeply nested expression ... */);
}
```
