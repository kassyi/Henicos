# GSH0026: Static disposable allocation

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0026 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Non-Deterministic Driver Teardown and GPU Context Crashes
Static variables persist for the lifetime of the process. During application shutdown, the order in which static finalizers and driver modules unload is non-deterministic. If a static GPU buffer attempts to dispose after the NVIDIA CUDA driver has already unloaded its context, an uncatchable native access violation crash occurs.

## Cause

The Roslyn analyzer (`ObjectLifecycleAnalyzer`) triggers **GSH0026** when all of the following conditions are met:
1. A field is declared as `static`.
2. The field's type implements `System.IDisposable` (or `System.IAsyncDisposable`).
3. The field is directly initialized with an object instantiation expression (`new T(...)`).

## How to Fix

- **Do not store disposable resources in static fields initialized via `new`.**
- Tie GPU resources to structured, instance-scoped lifetimes managed deterministically via `using` statements.
- If a singleton-like lifecycle is strictly required across the host application, manage the instance explicitly via a dependency injection (DI) container or an application lifecycle manager that guarantees calling `.Dispose()` during graceful application shutdown before the CUDA driver context unloads.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
using System;
using Kassyi.GSharp.Runtime;

// Any resource or wrapper implementing IDisposable:
public class CustomGpuPipeline : IDisposable
{
    private readonly GpuBuffer<float> _deviceBuffer = new GpuBuffer<float>(256);

    public void Dispose()
    {
        _deviceBuffer.Dispose();
    }
}

public static class GlobalState
{
    // ❌ Error GSH0026: 'CustomGpuPipeline' implements IDisposable!
    // Static field allocation prevents deterministic disposal via 'using'.
    public static readonly CustomGpuPipeline Pipeline = new CustomGpuPipeline();

    // ❌ Error GSH0026: Built-in 'GpuBuffer<T>' also implements IDisposable!
    // (public sealed class GpuBuffer<T> : IGpuBuffer, IDisposable)
    public static readonly GpuBuffer<int> GlobalBuffer = new GpuBuffer<int>(1024);
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
using System;
using Kassyi.GSharp.Runtime;

public class CustomGpuPipeline : IDisposable
{
    private readonly GpuBuffer<float> _deviceBuffer = new GpuBuffer<float>(256);

    public void Dispose()
    {
        _deviceBuffer.Dispose();
    }
}

// ✅ Correct: Manage lifecycle with instance scope and explicit 'using' blocks
public class ApplicationHost
{
    public void Run()
    {
        // Deterministic disposal: both resources are guaranteed to be disposed
        // immediately upon exiting this scope, long before driver context unload
        using var pipeline = new CustomGpuPipeline();
        using var buffer = new GpuBuffer<int>(1024);

        // Safely launch GPU kernels using the resources...
    }
}
```
