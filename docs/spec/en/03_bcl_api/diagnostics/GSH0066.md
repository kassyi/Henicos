# GSH0066

## Instance [GpuDeviceFunction] method is not supported in this form

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

An instance method marked with `[GpuDeviceFunction]` cannot be lowered in its current form because one of the following holds:

1. It is declared on a `class` or other reference type (device code has no class instances).
2. It is not an ordinary method (for example, an explicit interface implementation).
3. It is declared on a generic struct (`struct Box<T>`).
4. It reaches a barrier (`Gpu.SyncThreads()`, `Gpu.SyncGrid()`) or a warp collective (`Warp.ShuffleSync()`, `Warp.ActiveMask()`, etc.), and the CPU state machine cannot keep the receiver across a barrier.

## Rule Description

Ordinary non-suspending `[GpuDeviceFunction]` instance methods on non-generic structs (`struct`, `readonly struct`, `record struct`, `readonly record struct`, and `ref struct`, including `readonly` methods) are supported and compiled with an explicit receiver pointer (`T*` or `const T*`).

The four forms listed above remain unsupported as instance `[GpuDeviceFunction]` methods. Mark the method `static` and pass the struct as an explicit parameter (`ref` when mutating, `in` when reading) instead.

## How to Fix

- On a `class`: mark the method `static` and pass the needed data or struct parameters explicitly.
- On a generic struct or explicit interface implementation: move the logic into an ordinary `static` `[GpuDeviceFunction]` method.
- When the method reaches a barrier or warp collective: mark the method `static` and pass the struct as a `ref` or `in` parameter.

## Examples

### Code with Error (Before)

```csharp
using Kassyi.GSharp.Core;

public partial class CounterClass
{
    public int Value;

    // Error GSH0066: declared on a reference type
    [GpuDeviceFunction]
    public int Add(int x) => Value + x;
}

public partial struct GenericBox<T> where T : unmanaged
{
    public T Value;

    // Error GSH0066: declared on a generic struct
    [GpuDeviceFunction]
    public void Set(T v) => Value = v;
}

public partial struct StepCounter
{
    public int Offset;

    // Error GSH0066: reaches a barrier or warp collective
    [GpuDeviceFunction]
    public void Step(int delta)
    {
        Gpu.SyncThreads();
        Offset += delta;
    }
}
```

### Corrected Code (After)

```csharp
using Kassyi.GSharp.Core;

public partial struct Counter
{
    public int Value;

    // Supported: non-suspending ordinary instance method on a non-generic struct
    [GpuDeviceFunction]
    public void Add(int delta) => Value += delta;

    // Supported: static [GpuDeviceFunction] reaching a barrier
    [GpuDeviceFunction]
    public static void Step(ref Counter counter, int delta)
    {
        Gpu.SyncThreads();
        counter.Value += delta;
    }
}
```
