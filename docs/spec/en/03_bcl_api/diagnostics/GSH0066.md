# GSH0066

## Instance [GpuDeviceFunction] methods are not supported

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A method marked with `[GpuDeviceFunction]` is an instance method instead of a static method.

## Rule Description

Instance methods on structs or classes require an implicit `this` receiver. In GPU C++ emission, instance device functions are not emitted with implicit receivers, which would result in invalid C++ referencing undefined fields or missing member declarations. Mark the method as `static` and explicitly pass the struct as a parameter.

## How to Fix

Mark the method as `static` and pass the struct or instance as an explicit parameter.

## Examples

### Code with Warning / Error (Before)

```csharp
public struct S
{
    public int V;

    // ❌ Error GSH0066: method is an instance method
    [GpuDeviceFunction]
    public int Twice() => V * 2;
}
```

### Corrected Code (After)

```csharp
public struct S
{
    public int V;

    // ✅ Correct: method is static with explicit receiver parameter
    [GpuDeviceFunction]
    public static int Twice(S s) => s.V * 2;
}
```
