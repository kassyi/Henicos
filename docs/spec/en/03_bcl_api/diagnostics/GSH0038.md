# GSH0038

## Exception handling is not supported in GPU kernels

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A `try`, `catch`, or `finally` block was detected inside a `[GpuKernel]` method.

## Rule Description

Structured exception handling (`try-catch-finally`) is not supported on GPU hardware.
Additionally, during CPU testing (using the G# CPU Emulation Context), the C# AOT state machine compiler cannot safely lower `try-catch` structures because jumping across barrier bounds via exceptions breaks the Bulk Synchronous Parallel (BSP) execution model.

Therefore, exception handling inside `[GpuKernel]` methods is strictly prohibited.

## How to Fix

Remove `try-catch-finally` blocks from your kernel. Use C-style error codes or status flags returned to the host instead of throwing exceptions.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel()
{
    try 
    {
        // ❌ Error GSH0038: try-catch is prohibited
        DoWork();
    }
    catch (Exception ex)
    {
        // ...
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel(Span<int> statusFlag)
{
    // ✅ Correct: Handle potential errors manually without exceptions
    bool success = DoWork();
    if (!success)
    {
        statusFlag[0] = -1; // Indicate error to the host
    }
}
```
