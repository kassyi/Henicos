# GSH0117: SharedMemory<T> count must not be negative

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0117 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

A `SharedMemory<T>` whose count is a C# constant is static shared memory: on CUDA it becomes `__shared__ T name[N]`,
whose size is fixed when the kernel is compiled. A negative number of elements has no meaning on any path: CUDA cannot
declare the array, and the CPU paths would have to pick a behavior of their own. C# rejects the same form for an array
(`new int[-1]` is error CS0248), so G# rejects it too, where the count is written, instead of letting each path fail in
its own way.

A count of 0 is not reported: like `new int[0]`, it declares empty shared memory on every path. A count that is known
only at run time (dynamic shared memory) is checked when the kernel runs: a negative one throws
`ArgumentOutOfRangeException` on CUDA and on both CPU paths.

## Cause

The count of a `SharedMemory<T>` creation is a negative constant: a literal, a `const` field or local, or a constant
expression. The error is reported at the count.

## How to Fix

Use a count of 0 or more. When the count comes from a calculation, check the calculation: a constant that turns
negative is usually a sign error or an off-by-one.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
private const int TileSize = 16;

[GpuKernel]
public static void BadKernel(float[] output)
{
    // error GSH0117: SharedMemory<T> cannot have a negative count (-16)
    var tile = new SharedMemory<float>(TileSize - 2 * TileSize);
    output[ThreadIndex.X] = 0f;
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
private const int TileSize = 16;

[GpuKernel]
public static void GoodKernel(float[] output)
{
    var tile = new SharedMemory<float>(2 * TileSize);
    tile[ThreadIndex.X] = 0f;
    Gpu.SyncThreads();
    output[ThreadIndex.X] = tile[ThreadIndex.X];
}
```
