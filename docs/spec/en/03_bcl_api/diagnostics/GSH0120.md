# GSH0120

## A goto jumps into the middle of a reconvergence region

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0120 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Cause

A `goto` statement in a kernel or `[GpuDeviceFunction]` that reaches `Warp.ActiveMask()` either:

- jumps from outside into the middle of a forward-goto range (`if (...) goto end; ... end:`) that holds a warp collective or barrier,
- jumps from outside (or from another `switch` section) into the middle or head of a goto loop (`top: ... goto top;`) that holds a warp collective or barrier, or
- forms a loop through a place where lanes from different sections of a thread-dependent `switch` meet: a cycle of `goto case`, `goto default` or cross-section `goto`, or a backward `goto`, `goto case` or `goto default` inside a section that jumps back across such a place in its own section, in a `switch` that holds a warp collective or barrier.

## Rule Description

On the CPU paths (native C++ and managed), a method that reaches `Warp.ActiveMask()` inserts reconvergence regions around thread-dependent branches, loops, suspending calls, forward-goto ranges, single-entry goto loops, and second-entry join points inside thread-dependent `switch` sections so that lanes taking different paths wait for each other where they meet again. A jump that enters the middle of one of those regions bypasses the region's entry, and a cycle of cross-section jumps in a thread-dependent `switch`, or a backward `goto` inside a section that jumps back across the place where lanes from another section join it, creates a loop through that place entered both by `switch` dispatch and by the jump, preventing the CPU paths from knowing which lanes run together there.

A jump to the first label of a goto loop from the same block or section, or to the target label that ends a forward-goto range, is allowed because those locations lie at the boundary of the region rather than in its middle. Acyclic `goto case`, `goto default`, and cross-section `goto` statements in a thread-dependent `switch` are also allowed and reconverge at the target section entry or label. A `goto case` or `goto default` to its own section is a plain loop back to the section head and is allowed too when no place where lanes of another section join lies between the section head and the jump, the head included; otherwise the loop passes that place again and is reported.

## How to Fix

- Move the target label out of the reconvergence range or goto loop.
- Break the loop through the meeting place in the `switch` statement.
- Replace the goto-based loop or switch cycle with a structured `while` or `for` loop.

## Examples

### Code with Error (Before)

```csharp
[GpuKernel]
public static void JumpIntoLoopMiddle(uint[] result)
{
    int t = ThreadIndex.X;
    int n = 0;
    if ((t & 2) != 0)
    {
        goto mid; // Error GSH0120: jumps into the middle of the 'top:' goto loop
    }

top:
    n++;
mid:
    uint m = Warp.ActiveMask();
    if ((t & 1) == 1 && n < 2)
    {
        goto top;
    }

    result[t] = m;
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void JumpToLoopHead(uint[] result)
{
    int t = ThreadIndex.X;
    int n = 0;
    if ((t & 2) != 0)
    {
        goto top; // OK: enters at the loop head
    }

top:
    n++;
    uint m = Warp.ActiveMask();
    if ((t & 1) == 1 && n < 2)
    {
        goto top;
    }

    result[t] = m;
}
```

### Switch Cycle with Error

```csharp
[GpuKernel]
public static void SwitchCycleWithSplit(uint[] result)
{
    int t = ThreadIndex.X;
    uint m = 0u;
    switch (t & 1)
    {
        case 0:
            m = Warp.ActiveMask();
            goto case 1; // Error GSH0120: lies on a cross-section jump cycle
        case 1:
            goto case 0; // Error GSH0120: lies on a cross-section jump cycle
    }

    result[t] = m;
}
```

### Backward Goto Across a Section Join with Error

```csharp
[GpuKernel]
public static void BackwardGotoAcrossSectionJoin(uint[] result)
{
    int t = ThreadIndex.X;
    int n = 0;
    uint m = 0u;
    switch (t % 3)
    {
        case 0:
            m = Warp.ActiveMask();
            goto first;
        case 1:
        first:
            n++;
        second: // lanes of the default section join here
            n++;
            if (n < 4)
            {
                goto first; // Error GSH0120: jumps back across the place where lanes of another section join
            }

            break;
        default:
            goto second;
    }

    result[t] = m;
}
```
