# GSH0120

## A goto jumps into the middle of a reconvergence region

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0120 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Cause

A `goto` statement in a kernel or `[GpuDeviceFunction]` that reaches `Warp.ActiveMask()` jumps from outside into the middle of:

- a forward-goto range (`if (...) goto end; ... end:`) that holds a warp collective or barrier, or
- a goto loop (`top: ... goto top;`) that holds a warp collective or barrier.

## Rule Description

On the CPU paths (native C++ and managed), a method that reaches `Warp.ActiveMask()` inserts reconvergence regions around thread-dependent branches, loops, suspending calls, forward-goto ranges, and single-entry goto loops so that lanes taking different paths wait for each other where they meet again. A jump that enters the middle of one of those regions bypasses the region's entry and prevents the CPU paths from knowing which lanes run together there.

A jump to the first label of a goto loop or to the target label that ends a forward-goto range is allowed, because those locations lie at the boundary of the region rather than in its middle.

## How to Fix

- Move the target label out of the reconvergence range or goto loop.
- Replace the goto-based loop with a structured `while` or `for` loop.

## Examples

### Code with Error (Before)

```csharp
[GpuKernel]
public static void JumpIntoLoopMiddle(uint[] result)
{
    int t = ThreadIndex.X;
    int n = 0;
    if ((t & 2) != 0)
    {
        goto mid; // Error GSH0120: jumps into the middle of the 'top:' goto loop
    }

top:
    n++;
mid:
    uint m = Warp.ActiveMask();
    if ((t & 1) == 1 && n < 2)
    {
        goto top;
    }

    result[t] = m;
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void JumpToLoopHead(uint[] result)
{
    int t = ThreadIndex.X;
    int n = 0;
    if ((t & 2) != 0)
    {
        goto top; // OK: enters at the loop head
    }

top:
    n++;
    uint m = Warp.ActiveMask();
    if ((t & 1) == 1 && n < 2)
    {
        goto top;
    }

    result[t] = m;
}
```
