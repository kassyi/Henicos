# GSH0120: goto cannot jump into a reconvergence range from outside

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0120 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

In a method that reaches `Warp.ActiveMask()`, the CPU paths track which lanes of a warp run together by inserting reconvergence regions around constructs that hold split points (barriers, warp collectives, or suspending device calls). Each region has a single entry (`enter`) and a single reconvergence point (`arrive`) where all lanes that entered together wait for each other:

- A `goto` loop covers the statements from a label `L:` through the last backward `goto L;` that holds a split point.
- A forward-goto range covers the statements from the earliest forward `goto M;` up to the statement before `M:` when those statements hold a split point.

When a `goto` enters the middle of a `goto` loop from outside, the control flow forms a multi-entry (irreducible) loop: there is no single entry point that defines which lanes belong to the same iteration. When a `goto` enters the middle of a forward-goto range from outside (for example from another `switch` section or backward from after the range), lanes reach the range's reconvergence point without having entered it. Neither shape has a valid CPU reconvergence stack.

## Cause

A `goto` statement in a method reaching `Warp.ActiveMask()` targets a label strictly inside a `goto` loop (`L:` through its last backward `goto L;`) or inside a forward-goto range (`goto M;` up to `M:`) from outside that range (including from another `switch` section).

## How to Fix

- Move the target label out of the reconvergence range (for example, jump to the start label `L:` of a `goto` loop rather than a label inside it).
- Replace the backward `goto` with a structured `while` or `for` loop.
- Restructure cross-section `switch` jumps so they do not land in the middle of another section's reconvergence range.

## Examples

### Code with an Error (Before)

```csharp
[GpuKernel]
public static void JumpIntoGotoLoopMiddle(uint[] result, int flag)
{
    int t = ThreadIndex.X;
    int n = 0;
    if (flag != 0)
    {
        goto middle; // ❌ Error GSH0120: enters the middle of the goto loop starting at 'top:'
    }

top:
    result[t] = Warp.ActiveMask();
middle:
    result[t + 32] = Warp.ActiveMask();
    if (n++ < 1)
    {
        goto top;
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void StructuredLoop(uint[] result, int flag)
{
    int t = ThreadIndex.X;
    int n = 0;
    bool skipFirst = flag != 0;
    while (n < 2)
    {
        if (!skipFirst)
        {
            result[t] = Warp.ActiveMask();
        }

        skipFirst = false;
        result[t + 32] = Warp.ActiveMask();
        n++;
    }
}
```
