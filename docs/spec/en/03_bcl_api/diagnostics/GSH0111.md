# GSH0111: [GpuKernel] is only allowed on an ordinary static method of a class

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0111 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

A kernel runs only through the launcher that G# generates for it (`Launch{Kernel}`). The launcher goes into a `partial class` with the kernel's name, next to the kernel, and starts the kernel on the GPU or on the CPU paths with the launch dimensions and the thread context. That works only for an ordinary `static` method of a class.

On any other declaration there is no launcher that C# can call, or the method also runs without one:

- Operators, conversion operators and accessors run when C# evaluates `a + b`, a conversion, or a property or indexer.
- A lambda is an ordinary delegate, and a local function an ordinary call.
- An instance method runs through `using`, an interface call or an override; a method that implements an interface member runs through that member, also as `T.Kernel()` in generic code.
- The entry point, a `[ModuleInitializer]` method and an `[UnmanagedCallersOnly]` method are called by the runtime or by native code.
- An extension method named `GetEnumerator`, `GetAsyncEnumerator`, `Deconstruct`, `GetAwaiter`, `GetPinnableReference`, `Add`, `Dispose` or `DisposeAsync` runs when C# expands `foreach`, a deconstruction, `await`, `fixed`, a collection initializer or `using`; so does a method that a `[CollectionBuilder]` attribute names, for a collection expression.
- The generated launcher is a member of a `partial class`, which cannot extend a struct, an interface or a C# 14 extension block, and it has no type parameters, so a generic method or a member of a generic type has none.

In each case the body would run as plain C# on the host, and a GPU intrinsic in it throws `GpuOnlyException`, or the generated C# would not compile. G# reports the declaration instead and generates nothing for it, so the rest of the project still compiles and its other diagnostics are reported.

## Cause

`[GpuKernel]` is on one of the declarations above. The message names which one.

A finalizer marked as GPU code is reported by GSH0003 instead.

## How to Fix

Move the body to a `[GpuDeviceFunction]` method (static, in any class or struct) and call it from a kernel that is an ordinary `static` method of a class. Launch that kernel with its `Launch{Kernel}` method.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public partial struct Vector
{
    public int X;

    [GpuKernel] // error GSH0111: a member of a struct
    public static void Scale(Vector[] values, int factor)
    {
        values[ThreadIndex.X].X *= factor;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public partial struct Vector
{
    public int X;

    [GpuDeviceFunction]
    public static void Scale(ref Vector value, int factor)
    {
        value.X *= factor;
    }
}

public static partial class VectorKernels
{
    [GpuKernel]
    public static void Scale(Vector[] values, int factor)
    {
        Vector.Scale(ref values[ThreadIndex.X], factor);
    }
}
```
