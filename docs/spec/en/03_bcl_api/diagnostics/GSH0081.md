# GSH0081: Struct array allocates the array field of each element

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0081 |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

An array field of a struct is a reference to a managed array on the host and a `GSharpArray<T>` (a device pointer and a length) on the device. To pass the struct, the launcher allocates device memory for the field, copies the array, and stores the device pointer in the struct's device copy; after the kernel it copies the array back and frees it.

For an array of such structs this happens once per element: `n` elements cost `n` device allocations and `n` transfers in each direction, each with a fixed overhead of microseconds, on top of the element-by-element conversion ([GSH0080](GSH0080.md)). One large transfer is much faster than many small ones.

## Cause

A `[GpuKernel]` parameter is an array (`T[]`, `Span<T>`, ...) of a struct that has an array field, directly or in a nested struct or `[InlineArray]` element. The message names the struct and the field. The CUDA dialect reports this warning; the CPU dialect, whose launcher does not copy array fields yet, reports [GSH0082](GSH0082.md) instead.

## How to Fix

Flatten the data: pass the values of all elements in one array parameter, and give each struct the offset and length of its part.

## Examples

### Code with Warning (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Bag
{
    public int Count;
    public int[] Items;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Sum(Bag[] bags, int[] sums) // ⚠️ GSH0081: each element allocates and copies 'Items'
    {
        var bag = bags[ThreadIndex.X];
        var total = 0;
        for (var i = 0; i < bag.Count; i++)
        {
            total += bag.Items[i];
        }

        sums[ThreadIndex.X] = total;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Bag
{
    public int Start;
    public int Count;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Sum(Bag[] bags, int[] items, int[] sums) // ✅ two block copies
    {
        var bag = bags[ThreadIndex.X];
        var total = 0;
        for (var i = 0; i < bag.Count; i++)
        {
            total += items[bag.Start + i];
        }

        sums[ThreadIndex.X] = total;
    }
}
```
