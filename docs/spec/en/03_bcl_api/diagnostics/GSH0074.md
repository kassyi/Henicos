# GSH0074: CopyAsyncWaitGroup count must be a compile-time constant between 0 and 7

- **ID:** `GSH0074`
- **Category:** `GSharpTranspiler`
- **Severity:** `Error`

## Cause

`Gpu.CopyAsyncWaitGroup(pendingGroups)` was called with an argument that is not a compile-time `int` constant in the range `0..7` (for example, a runtime variable, a negative constant, or a constant greater than `7`).

The underlying PTX instruction `cp.async.wait_group N` encodes the pending group count `N` as an immediate operand in the instruction stream and supports counts `0` through `7` in the G# CUDA prelude.

## Examples

### Invalid Code (Triggers GSH0074)

```csharp
[GpuKernel]
public static void BadWaitGroup(int[] input, int[] output, int dynamicCount)
{
    using var smem = new SharedMemory<int>(32);
    int tid = ThreadIndex.X;
    Gpu.CopyAsync(ref smem[tid], in input[tid]);
    Gpu.CopyAsyncCommitGroup();

    // Error GSH0074: runtime variable is not a compile-time constant in 0..7
    Gpu.CopyAsyncWaitGroup(dynamicCount);

    // Error GSH0074: out of range (must be 0..7)
    Gpu.CopyAsyncWaitGroup(8);
}
```

### Valid Code

```csharp
[GpuKernel]
public static void GoodWaitGroup(int[] input, int[] output)
{
    using var smem = new SharedMemory<int>(32);
    int tid = ThreadIndex.X;
    Gpu.CopyAsync(ref smem[tid], in input[tid]);
    Gpu.CopyAsyncCommitGroup();

    // OK: compile-time constant in 0..7
    Gpu.CopyAsyncWaitGroup(0);
    Gpu.SyncThreads();
    output[tid] = smem[tid];
}
```
