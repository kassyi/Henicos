# GSH0044

## ref, out, in, and ref struct parameters are prohibited in GPU kernels

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A `[GpuKernel]` method was declared with a `ref`, `out`, or `in` parameter modifier, or with a `ref struct` type.

## Rule Description

When a state machine suspends at a barrier (`Gpu.SyncThreads()`), it must save all parameters to a context struct. C#'s memory safety model strictly forbids saving `ref` variables or `ref struct`s inside non-ref structs. Therefore, it is physically impossible to persist these parameter types across barrier suspend points.

## How to Fix

Use raw pointers (`unmanaged` pointers like `int*`) or `GpuBuffer<T>` for passing data into the kernel instead of `Span<T>` or `ref` modifiers.

## Examples

### Code with Warning / Error (Before)

```csharp
// ❌ Error GSH0044: ref struct parameter cannot be saved to state machine context
[GpuKernel]
public static void Kernel(Span<int> buffer, ref int state)
{
    Gpu.SyncThreads(); 
}
```

### Corrected Code (After)

```csharp
// ✅ Correct: Unmanaged pointers can be saved to context
[GpuKernel]
public unsafe static void Kernel(int* buffer, int* state)
{
    Gpu.SyncThreads(); 
}
```
