# GSH0083

## Barrier that only some threads may reach, depending on the launch or on run-time values

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |

## Cause

A `Gpu.SyncThreads()`, a `Gpu.SyncGrid()`, or a call to a `[GpuDeviceFunction]` that reaches one, is reached by only some of the threads that must all reach it, and the threads that skip it go on to another barrier (or to the same one in the next iteration of a loop):

- it is inside a branch, a loop body, or an operand that only some threads evaluate (the right operand of `&&`, `||` and `??`, the branches of `?:`), whose condition is [thread-variant](#thread-variant-values);
- or it is a call to a device function whose barrier diverges because of an argument (`SyncIf(ThreadIndex.X)`), or that leaves early in some threads and is followed by a barrier.

A call that reaches only warp shuffles may sit in a branch, because a shuffle takes the mask of the threads that reach it. When the threads that skip the barrier only leave the kernel, the warning [GSH0084](GSH0084.md) is reported instead. A barrier written in a lambda or local function that the CPU dialects do not split is the error [GSH0037](GSH0037.md).

A thread skips the barrier only on a path that reaches the end of the branch without passing it: `if (ThreadIndex.X == 0 || flag)` lets every thread reach the barrier when `flag` is true, and the warning names the threads that may skip it when it is false.

## Rule Description

On the GPU a barrier that only some threads of the block reach is undefined behavior, and the CPU dialects split the kernel into phases at each barrier, so a barrier that some threads skip reorders the shared memory accesses of the others. Whether a branch diverges depends on the launch configuration and on values known only at run time: `if (ThreadIndex.X == 0)` is correct in a launch whose blocks are one thread wide in X (`blockDim = (1, 256)`), and every branch is correct in a block of one thread. The compiler does not know the launch, so it warns instead of rejecting code that may be correct (semantics charter §3). The barriers that do diverge are caught at run time.

### Thread-variant values

The analyzer follows the values in the body of the kernel or device function on its control flow graph. A value is thread-variant when it depends on:

- `ThreadIndex`, `Gpu.LaneId()`, `Gpu.WarpId()`, `Gpu.SmId()` or the clock (and, for `Gpu.SyncGrid()`, `BlockIndex`);
- the result of an atomic operation or a warp-level operation (shuffle, vote, match, reduce);
- a local that is assigned a thread-variant value, or assigned inside a branch or loop with a thread-variant condition and read where the paths of that branch meet again (assigning it a uniform value afterwards makes it uniform again);
- the result, or a `ref` / `out` argument, of a call to a device function whose body makes it thread-variant, given which arguments are thread-variant. A device function that takes each thread's value and returns a value read from shared memory with a uniform index (for example the result of a block reduction) returns a uniform value;
- a parameter of a lambda or a local function.

Two assumptions keep the analysis within one method, and both can hide a divergent barrier:

- A parameter of a kernel or a device function is uniform. Every thread of a kernel receives the same arguments; each call to a device function is checked with the arguments it passes.
- An array or shared memory element read with a uniform index is uniform, because the threads read the same memory after a barrier.

## How to Fix

- Move the barrier out of the branch, so that every thread reaches it.
- Or make the branch uniform: decide it on a kernel argument or on a value every thread of the block computes the same way.
- If the branch is a guard that a caller already took (for example a bounds check repeated in a device function), remove the repeated guard.

## Examples

```csharp
[GpuKernel]
public static void Kernel(int[] data, int n)
{
    int tid = ThreadIndex.X;
    if (tid < 16)
    {
        Gpu.SyncThreads(); // GSH0083: the threads past 16 skip it and reach the barrier below
    }

    if (tid < n)
    {
        data[tid] += 1;
    }

    Gpu.SyncThreads(); // every thread reaches this one
}
```
