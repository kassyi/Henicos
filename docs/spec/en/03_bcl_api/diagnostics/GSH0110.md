# GSH0110: The launcher of a [CudaImport] method cannot pass a parameter to the kernel

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0110 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

G# generates the body of a `[CudaImport]` method: it loads the external kernel from its module and passes the
parameters to `cuLaunchKernel`, each by the address of a copy on the launcher's stack. A one-dimensional array of
unmanaged elements is first copied to a device buffer, and the kernel receives a pointer to that buffer.

That is a faithful translation only for unmanaged values, pointers and such arrays. A reference would reach the kernel
as the host address of the managed object, which the kernel cannot use and which reads or writes the wrong memory
without any error. `Nullable<T>` has no counterpart in a kernel. A `ref`, `out` or `in` parameter would be passed as a
copy whose changes never come back, and a multidimensional or jagged array is not laid out as the kernel's pointer
expects. G# reports such a parameter instead of generating a launch with a wrong value, and the generated method throws
`NotSupportedException` with the same message, so that the rest of the project still compiles and the build shows
GSH0110.

The parameters named `gridDimX`, `gridDimY`, `gridDimZ`, `blockDimX`, `blockDimY`, `blockDimZ`, `sharedMemBytes` and
`stream` set the launch instead of passing a kernel argument. A parameter with one of these names and another type
(`int stream`, which would otherwise become the stream handle) is reported as well.

## Cause

A parameter of a `[CudaImport]` method is one of the following. The message names the parameter, the method, its type
and the reason.

- A reference type (`string`, `object`, a class, an interface, a delegate), or a struct that contains references.
- An array whose elements are references, pointers or `Nullable<T>`.
- `Nullable<T>` (`int?`).
- A `ref`, `out`, `in` or `scoped` parameter (not supported yet).
- A nullable array (`float[]?`), or a multidimensional array (`float[,]`) (not supported yet).
- A jagged array (`float[][]`).
- A launch setting name of the wrong type: the dimensions and `sharedMemBytes` must convert implicitly to `uint`, and
  `stream` must be `IntPtr` (`nint`).
- A name that starts with `__gsharp_`, which is reserved for the generated launcher.

## How to Fix

Pass the data in a form the kernel can receive: a one-dimensional array of unmanaged elements for a buffer, a
one-element array for a value the kernel writes back, the flattened elements of a multidimensional array, and the
correct type for a launch setting.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: Host (CPU)
public static partial class NativeKernels
{
    [CudaImport("kernels.fatbin")]
    public static partial void Count(float[] data, ref int count, int stream); // error GSH0110 (count, stream)
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public static partial class NativeKernels
{
    // The kernel writes count[0]; the stream is a CUstream handle
    [CudaImport("kernels.fatbin")]
    public static partial void Count(float[] data, int[] count, IntPtr stream);
}
```
