# GSH0118: A [GpuReadOnly] array is written

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0118 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

`[GpuReadOnly]` on an array parameter, field or property is a promise: no thread writes the array while the kernel
runs, through any alias. The device holds such an array with `const` elements, and later versions may read it through
the read-only data path of the GPU, which does not see a write of the same launch. A write would give a result that C#
defines but the GPU does not, so G# reports the writes it can see instead of leaving the result undefined.

## Cause

Code writes an element of an array with `[GpuReadOnly]`, or of a value computed from it without leaving the array (a
conversion to `uint[]`, `Span<T>` or `ReadOnlySpan<T>`, `Gpu.NotNull(array)`, `AsSpan()`, a slice, or a local that holds
only such values). The error is reported at the write:

- an element assignment, a compound assignment, `++` or `--` (`r[0] = 5;`, `h.Fixed[0] += 1;`, `r[0]++;`);
- an element passed by `ref` or `out` (`Inc(ref r[0])`);
- a method that writes its operand: `Fill`, `Clear`, `Reverse`, `Sort`, `CopyTo` or `TryCopyTo` into it, `Array.Fill`,
  `Array.Clear`, `Array.Reverse`, `Array.Sort`, `Array.Copy` into it;
- a `ref` foreach variable over the array (`foreach (ref uint e in r.AsSpan())`), which can write each element
  (`ref readonly` does not);
- passing the array, or a span or array made from it, to a method of the same compilation that writes that parameter
  (the parameter is not `[GpuReadOnly]` itself).

The array is followed through a local, a parameter, or a field of a struct local that is given nothing but such values
(`w.Data = r;` or `new S { Data = r }`, then `w.Data[0] = 4;`). A variable that is also given another array, passed by
`ref` or `out`, or assigned compound-wise or by deconstruction is not followed, so the rule never reports a write that
may go to another array.

### Limits

G# reports only what it can see. These writes break the promise too, and the result is undefined, but they are not
reported:

- The same host array passed to a `[GpuReadOnly]` parameter and to a writable one of one launch.
- A write after the array was given to a variable together with another one (`t = r; ...; t = o; Same(t);`): the
  analysis does not follow the order of the statements, so a variable that holds a read-only array on one path and
  another array on a second path is not followed.
- A write in a method that G# does not compile in this project, for example a method of another assembly: it counts as
  not writing.

## How to Fix

Remove the write, write to a different array, or remove `[GpuReadOnly]` from the array.

## Examples

### Code with Error (Before)

```csharp
[GpuKernel]
public static void Kernel([GpuReadOnly] uint[] table, uint[] output)
{
    Span<uint> view = table.AsSpan();
    view[0] = 5u; // GSH0118
    output[0] = table[0];
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel([GpuReadOnly] uint[] table, uint[] output)
{
    output[0] = table[0] + 5u;
}
```
