# GSH0056: Gpu.InlinePtx is not supported by the target dialect

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0056 |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Inline Assembly Is a Hardware Capability
`Gpu.InlinePtx` injects raw PTX into the generated CUDA C++ source. Only dialects that declare the `InlineAssembly` capability (the CUDA dialect) can honor it. The CPU dialect (`StandardCpp`) has no equivalent of PTX, so emitting the string verbatim would produce invalid C++.

Silently skipping the call is also unsafe: PTX typically has side effects (writing a register or memory), so a skipped call would let the CPU kernel return a different result from the GPU kernel without any signal.

Instead, the transpiler replaces the call with `__gsharp_unsupported(...)`. If the code path is executed on the CPU dialect, the runtime error channel records the first error across OpenMP worker threads, halts remaining work early, and propagates the failure across the native boundary so the host launch wrapper throws a managed `System.NotSupportedException`.

## Cause

`Gpu.InlinePtx` was transpiled for a dialect whose capabilities do not include `InlineAssembly`.

## How to Fix

Keep the PTX out of any code path that the CPU dialect executes, or provide a portable implementation for it. The warning is expected when a kernel that uses `Gpu.InlinePtx` is built for the CPU dialect but never executed there.

## Examples

### Code with Warning (Before)

```csharp
// Execution Context: G# Kernel (CPU dialect)
[GpuKernel]
public static void ReadLaneKernel(uint[] data)
{
    uint reg = data[0];
    // ⚠️ Warning GSH0056 on the CPU dialect; throws NotSupportedException at runtime if executed
    Gpu.InlinePtx($"mov.u32 {reg}, 42;");
    data[0] = reg;
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel
[GpuKernel]
public static void ReadLaneKernel(uint[] data)
{
    // ✅ Portable implementation that works on every dialect
    data[0] = 42;
}
```
