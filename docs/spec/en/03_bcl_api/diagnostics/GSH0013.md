# GSH0013: Excessive static shared memory usage

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0013 |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Streaming Multiprocessor (SM) Occupancy and Hardware Limits
NVIDIA GPUs provide an ultra-fast, on-chip SRAM pool known as **Shared Memory** shared among threads within a single thread block. 
Depending on the GPU microarchitecture (e.g. Ampere, Ada Lovelace, Blackwell), each SM contains between 48 KB and 164 KB of shared memory.

1. **Warp Occupancy Degradation**: If a single thread block requests 40 KB of static shared memory on an SM with 64 KB capacity, the hardware scheduler can only dispatch **one** active block per SM. Even if the SM has sufficient registers and compute units to run more warps, the remaining capacity sits idle.
2. **Latency Hiding Failure**: High occupancy is required for GPUs to hide memory fetch latency. When occupancy drops, memory stalls degrade overall kernel throughput.
`GSH0013` warns developers before execution that static shared memory consumption threatens occupancy.

## Cause

A `SharedMemory<T>` declaration statically allocated more than 32,768 bytes (32 KB) within a single block.

## How to Fix

Reduce the static shared memory allocation size, or switch to dynamic shared memory configured at launch time via `sharedMemBytes`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadKernel()
{
    // Warning GSH0013: 40,000 bytes exceeds the 32 KB threshold, crippling warp occupancy
    SharedMemory<int> cache = new SharedMemory<int>(10000);
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel()
{
    // Correct: Conservative shared memory allocation preserves multi-block SM occupancy
    SharedMemory<int> cache = new SharedMemory<int>(2048); // 8,192 bytes (8 KB)
}
```
