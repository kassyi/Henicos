# GSH0057: Identifier containing '__' is reserved

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0057 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### `__` Belongs to the Compiler
In C++, every identifier that contains a double underscore is reserved for the implementation. G# follows the same convention: names that the transpiler generates use the `__gsharp` prefix (for example the CPU dialect's per-thread context and state variables), and CUDA itself uses `__` for its qualifiers and intrinsics (`__global__`, `__syncthreads`).

Rejecting `__` in user identifiers guarantees that compiler-generated names can never collide with user code. Treat it like using `int` as a variable name: the name is reserved, not merely discouraged.

This restriction is permanent. Unlike [GSH0058](GSH0058.md), it is not lifted by automatic renaming. The renaming itself relies on the `__gsharp` prefix being free of user names.

## Cause

An identifier containing `__` (anywhere in the name) is used for one of the following:

- The name of a `[GpuKernel]` or `[GpuDeviceFunction]` method.
- A parameter, local variable, `out var` or pattern variable, `foreach` variable, local function, or lambda parameter declared in GPU code.
- A field or property of a custom struct that is used by a declaration in GPU code, directly or through arrays, spans, pointers, or nested struct fields. The diagnostic is reported at that declaration and names the member path (for example `Particle.__gsharp_value`).

Structs that are only used from host code are not checked. Identifiers with a single leading underscore (`_value`) are allowed.

## How to Fix

Rename the identifier or the struct member so that it no longer contains `__`.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel
[GpuKernel]
public static void ScaleKernel(float[] data, float scale__factor) // ❌ GSH0057
{
    float __gsharp_value = data[ThreadIndex.X]; // ❌ GSH0057
    data[ThreadIndex.X] = __gsharp_value * scale__factor;
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel
[GpuKernel]
public static void ScaleKernel(float[] data, float scaleFactor)
{
    float value = data[ThreadIndex.X]; // ✅
    data[ThreadIndex.X] = value * scaleFactor;
}
```
