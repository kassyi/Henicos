# GSH0116: No GPU of GSharpTargetArchitectures has an oversized shared memory configuration

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0116 |
| **Category** | GSharpCompiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The `[GpuKernel(AllowOversizedSharedMemory = true)]` property allows a kernel to request an oversized shared memory
configuration (such as up to 327 KB per block on compute capability 10.7, instead of 227 KB). This mode has an effect
only when running on a GPU architecture that supports an oversized configuration.

When the fatbin built for `GSharpTargetArchitectures` targets only GPUs without an oversized configuration, the property
has no effect on any GPU that the binary can run on. Because the semantics of the program remain valid without the
oversized configuration, G# emits a warning rather than a compile error.

## Cause

A method marked `[GpuKernel(AllowOversizedSharedMemory = true)]` is compiled in a project whose
`GSharpTargetArchitectures` targets only GPUs without an oversized shared memory configuration (for example,
`compute_86,sm_86`, which targets only 8.6 and 8.9).

The warning is not emitted when:
- At least one target GPU has an oversized shared memory configuration (such as the default `GSharpTargetArchitectures`,
  which includes PTX runnable on 10.7, or explicit targets like `sm_107a`).
- `GSharpTargetArchitectures` includes an unknown compute capability (reported separately by GSH0114).
- `AllowOversizedSharedMemory` is `false` or omitted.

## How to Fix

- If the kernel is intended to run with oversized shared memory, add an architecture with an oversized configuration to
  `GSharpTargetArchitectures` (for example, `compute_107,sm_107` or `sm_107a`).
- If the kernel targets only older GPUs, remove `AllowOversizedSharedMemory = true` from the `[GpuKernel]` attribute.

## Examples

### Code with Warning (Before)

```csharp
// Project file: <GSharpTargetArchitectures>compute_86,sm_86</GSharpTargetArchitectures>

public static class Kernels
{
    [GpuKernel(AllowOversizedSharedMemory = true)] // warning GSH0116
    public static void TileKernel()
    {
    }
}
```

### Corrected Code (After)

```csharp
// Option 1: Remove the property when targeting GPUs without oversized shared memory
public static class Kernels
{
    [GpuKernel]
    public static void TileKernel()
    {
    }
}
```

```xml
<!-- Option 2: Add an architecture with an oversized shared memory configuration to the project file -->
<PropertyGroup>
  <GSharpTargetArchitectures>compute_107,sm_107</GSharpTargetArchitectures>
</PropertyGroup>
```
