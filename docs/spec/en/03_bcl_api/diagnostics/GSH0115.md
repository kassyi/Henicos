# GSH0115: A file-local type cannot be named by the managed code G# generates

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0115 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

On the CPU dialect, G# runs some GPU code on the managed path, from a copy of its C# body that it writes into a
generated file:

- the body of every `[GpuKernel]` (its managed fallback),
- the body of a `[GpuDeviceFunction]` that may suspend (its state machine),
- the body of a `[GpuDeviceFunction]` that needs a managed version (one that expands an operator macro, or calls one
  that does).

A file-local type (`file struct`, `file class`) is visible only in the file that declares it, and C# has no way to name
it from another file. A copy that names one cannot compile, so G# reports each name instead. The CUDA dialect
transpiles the bodies to C++ and copies no C#, so it accepts them.

The name may be the type itself, a static member of it, or an extension method declared in it (the copy writes the
call as a call of the extension's class). `nameof(...)` is written as its string and is not reported.

## Cause

A body that the managed path copies names a file-local type. On the CPU dialect, the launcher of a kernel that needs
such a copy throws `NotSupportedException` instead of running the kernel.

## How to Fix

Declare the type without `file`, for example as a `private` type nested in the class that uses it.

## Examples

### Code with Error (Before)

```csharp
file struct LocalValue
{
    public int A;
}

public static partial class LocalKernels
{
    [GpuKernel]
    public static void Run(int[] data)
    {
        LocalValue v = new LocalValue { A = 1 }; // ❌ GSH0115 (CPU dialect), at both names
        data[ThreadIndex.X] = v.A;
    }
}
```

### Corrected Code (After)

```csharp
public static partial class LocalKernels
{
    private struct LocalValue
    {
        public int A;
    }

    [GpuKernel]
    public static void Run(int[] data)
    {
        LocalValue v = new LocalValue { A = 1 }; // ✅
        data[ThreadIndex.X] = v.A;
    }
}
```
