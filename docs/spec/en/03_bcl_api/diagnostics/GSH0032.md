# GSH0032: Unrolled loop bounds must be statically deterministic

## Details

| Property               | Value            |
| :--------------------- | :--------------- |
| **Diagnostic ID**      | GSH0032          |
| **Category**           | GSharpTranspiler |
| **Severity**           | Error            |
| **Enabled by Default** | Yes              |

## Why This Rule Exists (Architectural Context)

### Static Determinism for Loop Unrolling

G# and the underlying NVIDIA PTX/CUDA execution model require that loops explicitly requested to be unrolled (e.g., `#pragma unroll`) must have bounds that can be evaluated to a constant at compile-time.

If the loop bounds depend on runtime variables (such as standard method parameters, data loaded from GPU memory, or calculations inside the kernel), the `nvcc` compiler cannot statically determine how many iterations to expand. This violates the **Static Determinism** tenet of G# and leads to unpredictable performance or silent compilation failures on the device side.

## Cause

A `for`, `while`, or `do-while` loop was preceded by `[Gpu.Hint.Unroll(n)]` or `Gpu.Hint.Unroll()`, but the termination condition relies on a variable that is not a compile-time constant.

## How to Fix

Ensure the loop condition evaluates against a compile-time constant (e.g., `const int`, `[Constant]` method parameter, or a literal). Alternatively, if the loop must be dynamic, remove the `Gpu.Hint.Unroll` hint.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static unsafe void ProcessData(int* data, int dynamicLength)
{
    // ❌ Error GSH0032: The bounds of the loop marked with Gpu.Hint.Unroll cannot be statically determined. Loop conditions must rely on compile-time constants or [Constant] parameters.
    Gpu.Hint.Unroll();
    for (int i = 0; i < dynamicLength; i++)
    {
        data[i] *= 2;
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static unsafe void ProcessData(int* data)
{
    const int StaticLength = 64;

    // ✅ Correct: Loop bound is a compile-time constant
    Gpu.Hint.Unroll();
    for (int i = 0; i < StaticLength; i++)
    {
        data[i] *= 2;
    }
}
```
