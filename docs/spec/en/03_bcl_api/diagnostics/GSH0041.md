# GSH0041

## Stack pointers cannot be held across barrier synchronization

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A pointer to a local variable (using the `&` operator) or a pointer obtained via `stackalloc` was held across a `Gpu.SyncThreads()` barrier.

## Rule Description

To emulate GPU thread execution on the host CPU, the G# compiler transforms kernel methods into Bulk Synchronous Parallel (BSP) state machines. When a state machine suspends at a barrier, it physically returns from the method, destroying the C# call stack.
If a pointer points to memory allocated on the stack, that memory is discarded. When the state machine resumes, the pointer becomes a dangling pointer, leading to Access Violations.

## When the CPU paths run on stacks

When both `GSharpNativeBarrierModel` and `GSharpManagedBarrierModel` are set to `Stack`, each GPU thread runs on its own stack and keeps its stack frame across barriers. In that mode, `GSH0041` is not reported for a kernel or suspending device function that runs on stacks on both CPU paths (or on CUDA).

The diagnostic is still reported when either CPU path keeps the method on the state machine—such as a cooperative kernel (`Gpu.SyncGrid`), a kernel or device function reaching a recursive suspending device function, a suspending device function imported from another assembly without a stack form, or a warp collective layout failure—and the diagnostic message explains why. If a kernel passes static checks but falls back to the state machine during generation, the source generator reports `GSH0041` for held stack pointers in the fallback kernel's suspending closure.

## How to Fix

Do not allocate memory on the stack if it needs to persist across barriers. Instead, use block-scoped `SharedMemory<T>` or global memory pointers.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public unsafe static void Kernel()
{
    int* localArr = stackalloc int[10];
    
    // ❌ Error GSH0041: Stack pointer cannot cross barrier
    Gpu.SyncThreads(); 
    
    localArr[0] = 1; 
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public unsafe static void Kernel(int* globalMem)
{
    var shared = new SharedMemory<int>(10);
    
    // ✅ Correct: SharedMemory is managed by the emulation context
    Gpu.SyncThreads();
    
    globalMem[0] = 1;
    shared[0] = 1;
}
```
