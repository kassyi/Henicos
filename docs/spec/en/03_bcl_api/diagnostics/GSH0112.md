# GSH0112: Kernel parameter type has no device representation

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0112 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The launcher copies each kernel argument to the device: a value or a struct as its bytes, an array or span as a buffer of its elements. A class instance is a reference to an object on the managed heap. Its address means nothing on the device, and its fields cannot be copied without knowing the runtime layout of the object, so there is no faithful way to pass it. A `string`, an interface, a delegate and `object` are references in the same way, and so is each element of an array of them.

G# reports the parameter and generates nothing for the kernel, so the generated C# and the native code stay valid and the rest of the project still compiles.

## Cause

A parameter of a `[GpuKernel]` method, the receiver of a `[GpuKernel]` extension method included, has one of these types, also as a `ref`, `in` or `out` parameter:

- a reference type other than an array: a class, a record class, `string`, an interface, a delegate or `object`;
- an array or span whose elements are such references (`string[]`, `Settings[]`, `Span<object>`).

The message names the parameter, the kernel and the type. A `dynamic` parameter is reported as GSH0003 instead.

## How to Fix

Pass the fields that the kernel reads, or make the type a struct whose fields are values, structs or one-dimensional arrays.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public sealed class Settings
{
    public float Scale;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Apply(Settings settings, float[] data) // error GSH0112: 'settings' is a reference to a managed object
    {
        data[ThreadIndex.X] *= settings.Scale;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Settings
{
    public float Scale;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Apply(Settings settings, float[] data)
    {
        data[ThreadIndex.X] *= settings.Scale;
    }
}
```
