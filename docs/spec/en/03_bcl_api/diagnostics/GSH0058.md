# GSH0058: Identifier is a C++ keyword (temporary)

> [!IMPORTANT]
> **This is a temporary misuse-prevention diagnostic.** The identifiers it rejects are valid C#, and G# intends to accept them. Once the transpiler renames them automatically ([#369](https://github.com/kassyi/Henicos/issues/369)), this diagnostic will be removed and the affected code will compile without changes.

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0058 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Identifiers Are Currently Emitted Verbatim
The transpiler currently writes C# identifiers into the generated CUDA C++ (and CPU C++) source unchanged. Many names are valid in C# but are keywords in C++, for example `register`, `template`, `typename`, `union`, `mutable`, `friend`, and the alternative operator tokens `and`, `or`, `not`, and `xor`. Emitting one of them produces a C++ syntax error that NVRTC, nvcc, or the host C++ compiler reports against the generated file, far away from the C# source.

C# keywords themselves cannot be used as identifiers, except through verbatim identifiers such as `@class`. A verbatim identifier is emitted as the bare keyword (`class`), so it is reported as well.

This diagnostic moves the failure to the C# declaration until automatic renaming is available.

## Cause

One of the following is a C++20 keyword or alternative operator token:

- The name of a `[GpuKernel]` or `[GpuDeviceFunction]` method.
- A parameter, local variable, `out var` or pattern variable, `foreach` variable, local function, or lambda parameter declared in GPU code.
- A field or property of a custom struct that is used by a declaration in GPU code, directly or through arrays, spans, pointers, or nested struct fields. The diagnostic is reported at that declaration and names the member path (for example `Particle.register`).

Structs that are only used from host code are not checked.

## How to Fix

Rename the identifier or the struct member.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel
public struct Particle
{
    public int register;
}

[GpuKernel]
public static void UpdateKernel(Particle[] particles, int[] template) // ❌ GSH0058 on 'particles' (Particle.register) and 'template'
{
    int union = ThreadIndex.X; // ❌ GSH0058
    particles[union].register = template[union];
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel
public struct Particle
{
    public int RegisterIndex;
}

[GpuKernel]
public static void UpdateKernel(Particle[] particles, int[] source)
{
    int index = ThreadIndex.X; // ✅
    particles[index].RegisterIndex = source[index];
}
```
