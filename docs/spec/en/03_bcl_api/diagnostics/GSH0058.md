# GSH0058: Two structs share one AotContexts name

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0058 |
| **Category** | GSharpCompiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The generator declares the native layout of every struct that appears in a kernel signature as `{KernelClass}.AotContexts.{Name}`, together with its `Marshal_` and `Unmarshal_` helpers. The name is the C# name of the struct without a trailing `Context`, and it contains neither the namespace nor type arguments. These names are public so that advanced code can use them (see the host launcher section of the AOT transpiler specification), so they stay readable instead of being encoded.

Two different structs can therefore map to the same name: `N1.Pair` and `N2.Pair`, `FooContext` and `Foo`, or `Box<int>` and `Box<long>` (the native declaration is not generic, so each construction needs its own layout). G# reports the conflict instead of generating a class with two members of the same name. The second struct gets no native declaration or helpers.

Names in the C++ output do not have this limit: every struct, function and kernel there has a name derived from its full C# path.

## Cause

Two different structs used by the `[GpuKernel]` methods of one class (directly, or as fields of another struct) have the same `AotContexts` name. Two constructions of one generic struct count as different structs.

## How to Fix

Rename one of the structs. For a generic struct, use one construction per kernel class, or move the kernels that use another construction to a separate class.

## Examples

### Code with Error (Before)

```csharp
namespace N1 { public struct Pair { public int A; } }
namespace N2 { public struct Pair { public int A; } }

public static partial class Kernels
{
    [GpuKernel]
    public static void Run(int[] data, N1.Pair first, N2.Pair second) // ❌ GSH0058: both are AotContexts.Pair
    {
        data[ThreadIndex.X] = first.A + second.A;
    }
}
```

### Corrected Code (After)

```csharp
namespace N1 { public struct Pair { public int A; } }
namespace N2 { public struct Couple { public int A; } }

public static partial class Kernels
{
    [GpuKernel]
    public static void Run(int[] data, N1.Pair first, N2.Couple second) // ✅
    {
        data[ThreadIndex.X] = first.A + second.A;
    }
}
```
