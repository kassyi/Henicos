# GSH0076: Unsupported warp matrix (WMMA) type or operation

- **ID:** `GSH0076`
- **Category:** `GSharpTranspiler`
- **Severity:** `Error`

## Cause

A warp matrix (`Wmma`) fragment type (`WmmaMatrixA<TShape, T, TLayout>`, `WmmaMatrixB<TShape, T, TLayout>`, `WmmaAccumulator<TShape, T>`), marker type (`IWmmaShape`, `IWmmaLayout`), or `Wmma.*` operation is used in an unsupported way:

1. **Unsupported `(TShape, T)` fragment combination** or **`Wmma.MultiplyAccumulate` signature** outside the supported CUDA Tensor Core matrix profiles:
   - `WmmaM16N16K16`, `WmmaM32N8K16`, `WmmaM8N32K16` with `sbyte` (`int8_t`) or `byte` (`uint8_t`) inputs and `int` accumulator (`sm_72+`).
   - `WmmaM8N8K4` with `double` inputs and `double` accumulator (`sm_80+`).
2. **Invalid storage location**: WMMA fragments are register-backed `nvcuda::wmma::fragment` values and can only be declared as local variables in GPU code or passed by `ref` / `ref readonly` / `in` to `[GpuDeviceFunction]` methods. Using a fragment as a `[GpuKernel]` parameter, a struct field, an array/span/`SharedMemory<T>` element, a pointer target, or a return type is prohibited.
3. **Marker type used as a value**: Shape (`WmmaM16N16K16`, etc.) and layout (`WmmaRowMajor`, `WmmaColumnMajor`) marker structs exist only for generic type arguments and cannot be instantiated or declared as variables, parameters, or fields.
4. **Invalid `Wmma.Load` / `Wmma.Store` memory operand**: The `source` / `destination` argument must refer to an element of shared memory (`SharedMemory<T>`) or global memory (`T[]`, `Span<T>`, `ReadOnlySpan<T>`), or a `ref` / `ref readonly` / `in` parameter of a `[GpuDeviceFunction]`, rather than a stack scalar local variable or temporary expression.

## Examples

### Invalid Code (Triggers GSH0076)

```csharp
[GpuKernel]
public static void BadWmma(sbyte[] a, int[] d)
{
    // Error GSH0076: WmmaM8N8K4 only supports double, not sbyte
    WmmaMatrixA<WmmaM8N8K4, sbyte, WmmaRowMajor> badFrag = default;

    // Error GSH0076: marker struct cannot be declared as a local variable
    WmmaM16N16K16 badMarker = default;

    // Error GSH0076: Wmma.Load source must be in shared or global memory, not a stack scalar local
    sbyte localScalar = a[0];
    WmmaMatrixA<WmmaM16N16K16, sbyte, WmmaRowMajor> fragA = default;
    Wmma.Load(ref fragA, in localScalar, 16);
}
```

### Valid Code

```csharp
[GpuKernel]
public static void GoodWmma(sbyte[] a, sbyte[] b, int[] c, int[] d)
{
    WmmaMatrixA<WmmaM16N16K16, sbyte, WmmaRowMajor> fragA = default;
    WmmaMatrixB<WmmaM16N16K16, sbyte, WmmaRowMajor> fragB = default;
    WmmaAccumulator<WmmaM16N16K16, int> acc = default;

    Wmma.Load(ref fragA, in a[0], 16);
    Wmma.Load(ref fragB, in b[0], 16);
    Wmma.Load(ref acc, in c[0], 16, WmmaMemoryLayout.RowMajor);
    Wmma.MultiplyAccumulate(ref acc, in fragA, in fragB, in acc);
    Wmma.Store(ref d[0], in acc, 16, WmmaMemoryLayout.RowMajor);
}
```
