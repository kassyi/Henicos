# GSH0114: G# has no launch limits for a GSharpTargetArchitectures architecture

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0114 |
| **Category** | GSharpCompiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

Some launch limits depend on the GPU architecture (the compute capability), such as the shared memory one block may
use. G# takes these limits from the architectures the project compiles its fatbin for, the `GSharpTargetArchitectures`
MSBuild property (default `compute_86,sm_86;compute_86,compute_86`), so that the CPU paths can reject the launches that
a target GPU rejects.

For each architecture, G# finds every compute capability that runs its code (PTX runs on its own compute capability
and every newer one; SASS on the newer minor versions of its major version; `a` code on its own compute capability
only; `f` code on its family) and takes, for each limit, the strictest value over all of them. The values come from a
table of the compute capabilities that the CUDA Programming Guide lists: 7.5, 8.0, 8.6, 8.7, 8.9, 9.0, 10.0, 10.3,
10.7, 11.0, 12.0 and 12.1.

An architecture whose own compute capability is not in the table (an older one such as `sm_72`, or one newer than
this version of G#) has no limits G# can use. G# leaves it out and warns, instead of guessing values that could reject
launches the GPU accepts.

## Cause

`GSharpTargetArchitectures` includes an architecture whose compute capability is not in the table. The message names
each such architecture as written. A project without kernels gets no warning.

## How to Fix

- Target an architecture in the table, for example `compute_86,sm_86` or `compute_90,sm_90`.
- If the GPU is older or newer than the table and the build is meant for it, keep the setting and suppress the warning
  (`<NoWarn>$(NoWarn);GSH0114</NoWarn>`); the launches are then checked against the other architectures only, or only
  against the limits every GPU shares when no architecture of the setting is in the table.

## Examples

### Code with Warning (Before)

```xml
<!-- Project file -->
<PropertyGroup>
  <GSharpTargetArchitectures>compute_72,sm_72</GSharpTargetArchitectures> <!-- warning GSH0114 -->
</PropertyGroup>
```

### Corrected Code (After)

```xml
<!-- Project file -->
<PropertyGroup>
  <GSharpTargetArchitectures>compute_75,sm_75</GSharpTargetArchitectures>
</PropertyGroup>
```
