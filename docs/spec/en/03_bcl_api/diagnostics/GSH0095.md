# GSH0095: Warp shuffle width must be 1, 2, 4, 8, 16 or 32

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0095 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The `width` of `Warp.ShuffleSync`, `Warp.ShuffleUpSync`, `Warp.ShuffleDownSync` and `Warp.ShuffleXorSync` splits the warp
into segments of `width` lanes. CUDA defines the result only for a width of 1, 2, 4, 8, 16 or 32; with any other width the
result is undefined, and the GPU reports no error.

G# treats undefined behavior as an error ([Semantics](../../01_language/06_semantics.md)). A width that is a compile-time
constant is reported here. A width known only at run time is checked by the CPU paths (the native CPU build and the
managed fallback), which throw `InvalidOperationException` with the place of the shuffle when it runs.

## How to Fix

Use a width of 1, 2, 4, 8, 16 or 32. To work on a group of lanes that is not a power of two, shuffle with the next power of
two and ignore the lanes past the group.

## Example

```csharp
[GpuKernel]
public static void SumKernel(int[] data)
{
    int v = data[ThreadIndex.X];

    // Incorrect: GSH0095, a width of 12 is undefined on CUDA
    v += Warp.ShuffleDownSync(0xFFFFFFFFu, v, 1u, 12);

    // Correct: a segment of 16 lanes
    v += Warp.ShuffleDownSync(0xFFFFFFFFu, v, 1u, 16);

    data[ThreadIndex.X] = v;
}
```
