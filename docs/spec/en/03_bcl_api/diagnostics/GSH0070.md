# GSH0070: IteratorShapeNotSupported

- **Severity**: Error
- **Category**: `GSharpTranspiler`
- **Message Format**: `"Iterator method '{0}' is not supported on the GPU: {1}."`

## Cause

Device iterators in G# are lowered at compile time by **inlining the iterator body directly into each consumer `foreach` statement** (substituting `yield return` with the consumer loop body and `yield break` with an exit `goto`), without heap allocation, interface dispatch, or state-machine structs. To guarantee that the iterator target and its captured arguments are statically known and finite at every call site, a device iterator must satisfy all of the following rules:

1. **Attribute and Static Method**: The iterator must be a `static` `[GpuDeviceFunction]` method (`"iterator methods must be static"`). Iterators on `[GpuKernel]` entry points are reported as `GSH0046`.
2. **Non-Generic Method**: Generic iterator methods (`IEnumerable<T> Foo<T>(...)`) are not supported (`"generic iterator methods are not supported"`).
3. **Return Type**: The return type must be the constructed generic interface `System.Collections.Generic.IEnumerable<T>` (`"return type must be System.Collections.Generic.IEnumerable<T>, not '{type}'"`), not `IEnumerator<T>`, non-generic `IEnumerable`, non-generic `IEnumerator`, or `IAsyncEnumerable<T>`.
4. **Element Type (`T`)**: The yielded element type `T` must be a concrete unmanaged value type (`struct`, primitive, or `enum`) and cannot be:
   - a type parameter (`"element type '{T}' cannot be a type parameter"`),
   - `SharedMemory<T>` (`"element type '{T}' cannot be SharedMemory<T>"`),
   - a `ref struct` (`"element type '{T}' cannot be a ref struct"`),
   - a pointer or function pointer (`"element type '{T}' cannot be a pointer"`),
   - an array (`"element type '{T}' cannot be an array"`), or
   - a managed reference type or struct containing managed references (`"element type '{T}' must be an unmanaged value type"`).
5. **Non-Recursive**: Direct or mutual recursion through iterator or device functions is not allowed (`"recursive iterators are not supported"`), because compile-time inlining cannot terminate on a cycle.
6. **Top-Level Method Declaration Only**: Local function iterators (`"local function iterators are not supported"`) and anonymous function / lambda iterators (`"anonymous function iterators are not supported"`) are rejected.
7. **No Arbitrary Inline Expansion Depth Limit**: Non-recursive nested iterators have no fixed expansion depth limit (the earlier 16-level limit has been removed). Direct or mutual recursion is rejected with `GSH0070` (`"recursive iterators are not supported"` under rule 5). If an extraordinarily deep nesting chain exhausts compiler resources (execution stack) during inlining or transpilation, `GSH0102` (`MethodTooComplexToCompile`) is reported instead of `GSH0070`.

Violating any of these constraints triggers `GSH0070`.

## Example (Error)

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    // Error GSH0070: Iterator method 'BadEnumerator' is not supported on the GPU:
    // return type must be System.Collections.Generic.IEnumerable<T>, not 'System.Collections.Generic.IEnumerator<int>'.
    [GpuDeviceFunction]
    public static IEnumerator<int> BadEnumerator(int count)
    {
        yield return count;
    }

    // Error GSH0070: Iterator method 'BadElementType' is not supported on the GPU:
    // element type 'string' must be an unmanaged value type.
    [GpuDeviceFunction]
    public static IEnumerable<string> BadElementType()
    {
        yield return "hello";
    }

    // Error GSH0070: Iterator method 'BadRecursive' is not supported on the GPU:
    // recursive iterators are not supported.
    [GpuDeviceFunction]
    public static IEnumerable<int> BadRecursive(int n)
    {
        yield return n;
        if (n > 0)
        {
            foreach (int x in BadRecursive(n - 1))
            {
                yield return x;
            }
        }
    }
}
```

## How to Fix

Declare the iterator as a non-generic, non-recursive `static` `[GpuDeviceFunction]` method returning `System.Collections.Generic.IEnumerable<T>` where `T` is a concrete unmanaged value type:

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }
}
```
