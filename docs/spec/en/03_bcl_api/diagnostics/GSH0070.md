# GSH0070

## Iterator method must be a static [GpuDeviceFunction] returning IEnumerable<T> with a value-type element

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A method or local function containing `yield return` or `yield break` in GPU code is not a `static` `[GpuDeviceFunction]` returning `System.Collections.Generic.IEnumerable<T>` with an unmanaged value-type element `T`, or is recursive.

## Rule Description

G# lowers `[GpuDeviceFunction]` iterators into stack-only state machines that are inlined at `foreach` call sites without heap allocations or virtual dispatch. To guarantee zero-allocation stack execution:

1. The iterator must be a top-level `static` method marked with `[GpuDeviceFunction]` (local functions, lambdas, and instance methods are not supported).
2. The return type must be `System.Collections.Generic.IEnumerable<T>` (`IEnumerator<T>`, non-generic `IEnumerable`, and `IAsyncEnumerable<T>` are not supported).
3. The element type `T` must be an unmanaged value type (`ref struct`, `Span<T>`, `SharedMemory<T>`, pointers, and arrays cannot be stored in the hoisted iterator state).
4. The iterator must not be recursive.

## How to Fix

Declare the iterator as a `static` `[GpuDeviceFunction]` returning `IEnumerable<T>` where `T` is an unmanaged value type.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
// ❌ Error GSH0070: IEnumerator<T> return type is not supported
[GpuDeviceFunction]
public static IEnumerator<int> BadNumbers(int count)
{
    for (int i = 0; i < count; i++)
    {
        yield return i;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
// ✅ Correct: static [GpuDeviceFunction] returning IEnumerable<int>
[GpuDeviceFunction]
public static IEnumerable<int> GoodNumbers(int count)
{
    for (int i = 0; i < count; i++)
    {
        yield return i;
    }
}
```
