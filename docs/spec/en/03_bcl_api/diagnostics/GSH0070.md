# GSH0070: IteratorShapeNotSupported

- **Severity**: Error
- **Category**: `GSharp.Compiler`
- **Message Format**: `"The iterator '{0}' is not supported on GPU: {1}"`

## Cause

Device iterators in G# are lowered at compile time by **inlining the iterator body directly into each consumer `foreach` statement** (substituting `yield return` with the consumer loop body and `yield break` with an exit `goto`), without heap allocation, interface dispatch, or state-machine structs. To guarantee that the iterator target and its captured arguments are statically known at every call site, a device iterator must satisfy all of the following signature and declaration rules:

1. **Attribute**: The iterator must be a `[GpuDeviceFunction]` method. Iterators on `[GpuKernel]` entry points (reported as `GSH0046`), unattributed methods, properties, or indexers are not supported.
2. **Return Type**: The return type must be the constructed generic interface `System.Collections.Generic.IEnumerable<T>` (not `IEnumerator<T>`, non-generic `IEnumerable`, ` non-generic IEnumerator`, or `IAsyncEnumerable<T>`).
3. **Element Type (`T`)**: The yielded element type `T` must be an unmanaged value type (`struct`, primitive, or enum) with no managed references.
4. **Parameters**: All parameters must be passed by value. `ref`, `out`, `in`, and `ref readonly` parameters are not permitted on iterator methods.
5. **Static Resolution**: The iterator method cannot be `virtual`, `abstract`, `override`, an interface method implementation, a local function, or an anonymous function / lambda.

Violating any of these signature constraints triggers `GSH0070`.

## Example (Error)

```csharp
using System.Collections;
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    // Error GSH0070: Return type must be IEnumerable<T>, not IEnumerator<T>.
    [GpuDeviceFunction]
    public static IEnumerator<int> BadEnumerator(int count)
    {
        yield return count;
    }

    // Error GSH0070: Element type 'string' is a managed reference type.
    [GpuDeviceFunction]
    public static IEnumerable<string> BadElementType()
    {
        yield return "hello";
    }

    // Error GSH0070: 'ref' parameters are not allowed on device iterators.
    [GpuDeviceFunction]
    public static IEnumerable<int> BadRefParam(ref int state)
    {
        yield return state;
    }
}
```

## How to Fix

Declare the iterator as a `static` (or non-virtual instance) `[GpuDeviceFunction]` returning `System.Collections.Generic.IEnumerable<T>` where `T` is an unmanaged value type and all parameters are passed by value:

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }
}
```
