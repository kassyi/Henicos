# GSH0007: Foreach is not allowed in GPU kernels

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0007 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Enumerator Heap Allocations vs. Lowered Array Iteration
Under standard C# semantics, the `foreach` statement is syntactic sugar for calling `.GetEnumerator()`, advancing via `.MoveNext()`, and querying `.Current` inside a `try/finally` block that disposes the enumerator.

1. **Heap Allocation on Interfaces**: For abstract interfaces (such as `IEnumerable<T>`) or reference-type collections, `.GetEnumerator()` allocates an `IEnumerator` state machine on the managed heap, which is completely unsupported on GPU devices.
2. **Exception Handling Blocks**: Interface enumerators emit `try/finally` cleanup blocks, which cannot be unwound on GPU hardware.
3. **Where `foreach` IS Allowed in G#**:
   The G# compiler specifically intercepts `foreach` loops on zero-allocation contiguous buffers:
   - Standard single-dimensional arrays (`T[]`)
   - `Span<T>` and `ReadOnlySpan<T>`
   - Types decorated with `[InlineArray(N)]`
   - `List<T>`
   
   For these supported types, G# lowers the `foreach` directly into a native register-indexed pointer loop (`for (int i = 0; ...)`), completely bypassing the enumerator and achieving zero-allocation execution.
   `GSH0007` triggers only when `foreach` is attempted on unsupported collections (like `IEnumerable<T>`) that would require a heap-allocated enumerator.

## Cause

A `foreach` loop was used inside a `[GpuKernel]` or `[GpuDeviceFunction]` on an interface or collection type (such as `IEnumerable<T>`) that requires a heap-allocated `IEnumerator`.

## How to Fix

- Change the parameter type to a supported contiguous buffer: `T[]`, `ReadOnlySpan<T>`, or `Span<T>`.
- Or rewrite the iteration using a standard index-based `for` loop with explicit bounds.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
using System.Collections.Generic;

public static class IterationKernels
{
    [GpuKernel]
    public static void BadKernel(IEnumerable<float> data)
    {
        // Error GSH0007: foreach is not allowed on IEnumerable<T> because it allocates an IEnumerator
        foreach (var value in data)
        {
            // ...
        }
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
using System;

public static class IterationKernels
{
    // ✅ Option A: foreach is fully supported on arrays and ReadOnlySpan<T>
    // (The compiler lowers this directly into a zero-allocation pointer loop)
    [GpuKernel]
    public static void GoodKernelForeach(ReadOnlySpan<float> data)
    {
        foreach (var value in data)
        {
            // Zero-allocation; no IEnumerator allocated
        }
    }

    // ✅ Option B: Standard indexed for loop
    [GpuKernel]
    public static void GoodKernelFor(float[] data, int length)
    {
        for (int i = 0; i < length; i++)
        {
            float value = data[i];
        }
    }
}
```
