# GSH0050

## Test methods must have a Category trait

|              |                        |
| :----------- | :--------------------- |
| **Category** | GSharpTestArchitecture |
| **Severity** | Error                  |

## Cause

A test method marked with `[Fact]` or `[Theory]` does not have a `[Category(...)]`, `[Scenario(...)]`, `[TestTarget(...)]`, or legacy `[Trait("Category", "...")]` attribute applied to it or its containing class.

## Rule Description

To facilitate test filtering and ensure clean organization across orthogonal axes (Execution Target, Category, Scenario), all tests in the GSharp codebase must declare metadata attributes. Recommended attributes are:
- `[TestTarget(ExecutionTarget.GpuExecution)]` or `[TestTarget(ExecutionTarget.CpuExecution)]`
- `[Category(TestCategory.Compiler)]`, `[Category(TestCategory.Syntax)]`, `[Category(TestCategory.Runtime)]`, etc.
- `[Scenario(TestScenario.HappyPath)]`, `[Scenario(TestScenario.SadPath)]`, or `[Scenario(TestScenario.Boundary)]`

## How to Fix

Apply the strongly-typed `[Category(...)]`, `[Scenario(...)]`, or `[TestTarget(...)]` attribute to the test method or the test class.

## Examples

### Code with Warning / Error (Before)

```csharp
public class BranchTests : StateMachineTestBase
{
    // ❌ Error GSH0050: Test method is missing category / scenario attribute
    [Fact]
    public void TestBranch()
    {
        // ...
    }
}
```

### Corrected Code (After)

```csharp
//✅ Correct: Test method has strongly-typed metadata attributes
public class BranchTests : StateMachineTestBase
{
    [Fact]
    [Category(TestCategory.Compiler)]
    [Scenario(TestScenario.HappyPath)]
    public void TestBranch()
    {
        // ...
    }
}
```
