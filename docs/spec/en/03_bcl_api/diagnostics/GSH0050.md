# GSH0050: [TakesOwnership] is only allowed on constructor parameters

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0050 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Static Determinism vs. Dynamic Ownership Tracking
GSharp enforces a strict model of **Static Determinism** and **Zero-Allocation** for GPU resource lifecycle management. Under this paradigm, ownership transfer is modeled exclusively as dependency injection during object instantiation.

Allowing `[TakesOwnership]` on arbitrary member methods, static methods, local functions, lambda expressions, or action delegates would introduce dynamic runtime ownership relays (such as runtime transfer of custody mid-stream). Tracking dynamic moves requires full affine/linear type systems or runtime reference tracking, which is incompatible with C#'s standard memory model and GSharp's zero-overhead GPU bridge.

Consequently, ownership transfer is strictly confined to constructors (including C# 12 Primary Constructors). All standard method calls are considered non-consuming **Borrows**.

## Cause

The `[TakesOwnership]` attribute is applied to a parameter of a member method, static method, local function, or lambda expression instead of an instance constructor.

## How to Fix

- Pass the resource as a borrowed argument to the method without `[TakesOwnership]`. The caller retains ownership and remains responsible for disposing of the resource.
- If the receiving object must assume ownership of the resource, pass it during instantiation through a constructor parameter.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public class ResourceService
{
    // ❌ Error GSH0050: [TakesOwnership] is not permitted on member methods
    public void RegisterResource([TakesOwnership] CudaStream stream)
    {
    }

    public void SetupHandler()
    {
        // ❌ Error GSH0050: [TakesOwnership] is not permitted on lambda expressions
        Action<CudaStream> action = ([TakesOwnership] CudaStream s) => { };
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
// Option A: Borrowing the resource in a method
public class ResourceService
{
    // ✅ Correct: Borrowed parameter (caller retains ownership)
    public void ProcessStream(CudaStream stream)
    {
        // Use stream without disposing it
    }
}

// Option B: Transferring ownership via constructor
public class StreamConsumer : IDisposable
{
    private readonly CudaStream _stream;

    // ✅ Correct: Ownership transferred via constructor
    public StreamConsumer([TakesOwnership] CudaStream stream)
    {
        _stream = stream;
    }

    public void Dispose()
    {
        _stream.Dispose();
    }
}
```
