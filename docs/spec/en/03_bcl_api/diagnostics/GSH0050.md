# GSH0050

## Test methods must have a Category trait

|              |                        |
| :----------- | :--------------------- |
| **Category** | GSharpTestArchitecture |
| **Severity** | Error                  |

## Cause

A test method marked with `[Fact]` or `[Theory]` does not have a `[Trait("Category", "...")]` attribute applied to it or its containing class.

## Rule Description

To facilitate test filtering and ensure proper organization, all tests in the GSharp codebase must be categorized. Common categories include `"Compiler"`, `"SadPath"`, and `"GpuExecution"`.

## How to Fix

Apply the `[Trait("Category", "...")]` attribute to the test method or the test class.

## Examples

### Code with Warning / Error (Before)

```csharp
public class BranchTests : StateMachineTestBase
{
    // ❌ Error GSH0050: Test method is missing [Trait("Category", "...")]
    [Fact]
    public void TestBranch()
    {
        // ...
    }
}
```

### Corrected Code (After)

```csharp
//✅ Correct: Test method has [Trait("Category", "Compiler")]
public class BranchTests : StateMachineTestBase
{
    [Fact]
    [Trait("Category", "Compiler")]
    public void TestBranch()
    {
        // ...
    }
}
```
