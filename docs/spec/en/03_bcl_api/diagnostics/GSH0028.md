# GSH0028: Disposable resource in Default Interface Method

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0028 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Interface Statelessness and Ownership Contracts
C# 8.0 introduced **Default Interface Methods** (also known as *default interface implementations*), allowing interfaces to provide method bodies. However:
- Interfaces cannot declare private instance fields (they cannot hold state).
- Interfaces cannot declare finalizers or manage instance teardown safely.
- In a default interface method, you do not know the full lifecycle or identity of the implementing object.

If a default implementation in an interface calls `.Dispose()` on a shared resource, any implementing class that expects the resource to remain valid will crash with ObjectDisposedException or CUDA driver native memory faults. Therefore, resource disposal and ownership management must strictly be implemented by **concrete classes**, not by default interface implementations.

## Cause

An interface method with a **default implementation body** (Default Interface Method) calls `.Dispose()`.

## How to Fix

- **Keep interface methods abstract:** Define only the method signature in the interface, and let the concrete implementing class handle disposal.
- **Do not dispose resources in interface default implementations.**

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
using Kassyi.GSharp.Runtime;

public interface IGpuWorker
{
    // ❌ Error GSH0028: Resource disposal inside an interface default implementation!
    // Interfaces cannot maintain state or ensure coordinated disposal.
    // Default method implementations must NOT take ownership or call .Dispose().
    void CleanUp(GpuBuffer<int> buffer)
    {
        buffer.Dispose(); // Disposing in interface default body is prohibited
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
using Kassyi.GSharp.Runtime;

// 1. Declare the method as abstract on the interface (no default body)
public interface IGpuWorker
{
    void CleanUp(GpuBuffer<int> buffer);
}

// 2. Concrete class implements the interface and coordinates the actual disposal
public class ConcreteGpuWorker : IGpuWorker
{
    public void CleanUp(GpuBuffer<int> buffer)
    {
        // ✅ Allowed: Concrete classes own and deterministically manage resource lifecycles
        buffer.Dispose();
    }
}
```
