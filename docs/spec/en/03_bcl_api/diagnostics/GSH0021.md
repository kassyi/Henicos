# GSH0021: Undisposed GPU resource

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0021 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Incomplete Disposal and Silent VRAM Leaks
Implementing `IDisposable` is insufficient if the `Dispose()` method body omits calling `.Dispose()` on every owned resource field. Forgetting a single buffer field causes silent native memory leaks that persist until process termination.

## Cause

An owned GPU resource field was not disposed inside the containing class's `Dispose()` method.

## How to Fix

Add an explicit `.Dispose()` call for each owned GPU resource field in `Dispose()`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public class Pipeline : IDisposable
{
    private GpuBuffer<int> _buffer = new GpuBuffer<int>(1024);

    public void Dispose()
    {
        // Error GSH0021: _buffer is never disposed!
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public class Pipeline : IDisposable
{
    private GpuBuffer<int> _buffer = new GpuBuffer<int>(1024);

    public void Dispose()
    {
        // Correct: All owned native resources explicitly released
        _buffer.Dispose();
    }
}
```
