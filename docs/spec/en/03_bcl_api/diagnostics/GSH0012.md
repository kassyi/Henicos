# GSH0012: Macro arguments must be compile-time constants

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0012 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Compile-Time Code Generation and Preprocessor Expansion
Transpiler macros like static constant injections and unrolled loops (`Gpu.ForUnroll`) modify the generated C++ source code during the Roslyn compilation phase. They emit preprocessor directives or define template parameters that require literal numeric values.

If an argument is a runtime variable evaluated on the CPU or GPU at execution time, the Roslyn Source Generator cannot inspect its value during compilation, making static code expansion impossible.

The mode of `Gpu.SyncGrid(GridSyncMode mode)` is such an argument as well: the CUDA build calls a different grid barrier for each mode (`GridSyncMode.Deterministic` or `GridSyncMode.Fast`) and does not choose between them at run time.

## Cause

A runtime variable or dynamic expression was passed to a macro parameter requiring a compile-time constant: the bounds of `Gpu.ForUnroll`, or the `mode` of `Gpu.SyncGrid`.

## How to Fix

Pass a numeric literal, a `const` field, or mark the kernel parameter with `[Constant]`. For `Gpu.SyncGrid`, pass a member of `GridSyncMode` or a `const` of that type; to pick the mode per launch, write the two barriers in two branches of a condition that every thread of the grid evaluates alike.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadKernel(int count)
{
    // ❌ Error GSH0012: count is a runtime variable, not a compile-time constant
    Gpu.ForUnroll(0, count, i => {
        // ...
    });
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel()
{
    // ✅ Correct: Literal or const integer is known at compile-time
    const int LoopCount = 4;
    Gpu.ForUnroll(0, LoopCount, i => {
        // ...
    });
}
```

### Grid Barrier Mode

```csharp
[GpuKernel(Cooperative = true)]
public static void BarrierKernel(int[] data, GridSyncMode mode)
{
    Gpu.SyncGrid(mode);              // ❌ Error GSH0012: mode is a runtime value
    Gpu.SyncGrid(GridSyncMode.Fast); // ✅ Correct: a member of GridSyncMode
}
```
