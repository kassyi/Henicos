# GSH0071

## Iterator value must be consumed directly by foreach

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

An `IEnumerable<T>` value produced by a `[GpuDeviceFunction]` iterator was passed as a method argument, returned from a method, reassigned, declared without an initializer, or used in a conditional expression (`?:` or `??`).

## Rule Description

On the GPU, an `IEnumerable<T>` iterator is not a heap-allocated object; the compiler expands its state machine directly at the `foreach` loop that consumes it. Every `foreach` loop must map statically to a single known iterator invocation. Passing an iterator value as an argument, returning it, reassigning a local variable, or selecting between two iterators with `?:` hides the concrete iterator state machine at compile time.

You may either:
- Enumerate the iterator call directly in `foreach (var item in MyIterator(...))`, or
- Bind the iterator call once to a local variable (`var seq = MyIterator(...);`) and enumerate that local variable in one or more `foreach` loops without reassigning it.

## How to Fix

Enumerate the `[GpuDeviceFunction]` iterator directly in a `foreach` statement, or assign it once at declaration time to a local variable and only use that local variable as the source of `foreach`.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuDeviceFunction]
public static IEnumerable<int> Range(int start, int count)
{
    for (int i = 0; i < count; i++)
    {
        yield return start + i;
    }
}

[GpuKernel]
public static void BadKernel(int[] output, bool flag)
{
    // ❌ Error GSH0071: cannot select an iterator conditionally
    var seq = flag ? Range(0, 4) : Range(4, 4);
    foreach (var x in seq)
    {
        output[0] += x;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel(int[] output, bool flag)
{
    // ✅ Correct: pass the varying arguments into a single iterator call
    var seq = Range(flag ? 0 : 4, 4);
    foreach (var x in seq)
    {
        output[0] += x;
    }
}
```
