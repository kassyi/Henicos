# GSH0071: IteratorValueMustBeEnumeratedInPlace

- **Severity**: Error
- **Category**: `GSharp.Compiler`
- **Message Format**: `"An iterator value in a GPU kernel or device function must be consumed directly by 'foreach' or stored in a single-assignment local variable"`

## Cause

On the GPU, an `IEnumerable<T>` returned by a `[GpuDeviceFunction]` iterator is not a heap-allocated object and does not materialize a runtime enumerator struct; the compiler lowers it by **inlining the iterator body directly into each consumer `foreach` loop** and binding the iterator's arguments at the `foreach` site. Consequently, the compiler must be able to trace every `IEnumerable<T>` expression to a single, statically known iterator call site.

`GSH0071` is reported whenever an `IEnumerable<T>` value is used in a way that prevents static in-place lowering:

1. **Calling a non-iterator method returning `IEnumerable<T>`**: Only `[GpuDeviceFunction]` methods containing `yield return` or `yield break` may produce an `IEnumerable<T>` on the device.
2. **Passing `IEnumerable<T>` as an argument, returning it, or storing it in a field / array / tuple**: Iterator values cannot escape the declaring method scope.
3. **Reassigning or mutating an iterator local variable**: A local variable holding an iterator call result must have an initializer and must not be reassigned (`seq = ...`).
4. **Conditional or non-direct initializer**: The initializer of an iterator local (or the collection expression of `foreach`) must be a direct call to a `[GpuDeviceFunction]` iterator, not a conditional expression (`flag ? Range(0, 4) : Range(4, 4)`), parameter, or array/collection conversion.
5. **Explicit `GetEnumerator()` calls**: Calling `.GetEnumerator()`, `.MoveNext()`, or `.Current` directly on an `IEnumerable<T>` is not supported; always consume the iterator via `foreach`.

## Example (Error)

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }

    [GpuDeviceFunction]
    public static void Sink(IEnumerable<int> items) { }

    [GpuKernel]
    public static void BadConsumptionKernel(int[] output, bool flag)
    {
        // Error GSH0071: Passing an iterator value as an argument is not allowed.
        Sink(Range(0, 4));

        // Error GSH0071: Conditional expression cannot be statically resolved to a single iterator call.
        var selected = flag ? Range(0, 4) : Range(4, 4);
        foreach (var x in selected)
        {
            output[0] += x;
        }

        // Error GSH0071: Reassigning an iterator local variable is not allowed.
        var seq = Range(0, 4);
        seq = Range(4, 4);
        foreach (var y in seq)
        {
            output[0] += y;
        }
    }
}
```

## How to Fix

Consume the iterator call directly in a `foreach` statement, or assign it once to a local variable (`var seq = Range(0, 4);`) and enumerate that local variable in one or more `foreach` loops (each `foreach` receives its own fresh inlined expansion starting from the beginning):

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }

    [GpuKernel]
    public static void GoodConsumptionKernel(int[] output)
    {
        // Direct consumption in foreach
        foreach (var x in Range(0, 4))
        {
            output[0] += x;
        }

        // Single-assignment local variable (can be enumerated multiple times)
        var seq = Range(1, 3);
        foreach (var a in seq)
        {
            foreach (var b in seq)
            {
                output[0] += a * b;
            }
        }
    }
}
```
