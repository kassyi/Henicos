# GSH0075: Gpu.CopyAsync requires a SharedMemory<T> destination and a global memory source

- **ID:** `GSH0075`
- **Category:** `GSharpTranspiler`
- **Severity:** `Error`

## Cause

`Gpu.CopyAsync(ref sharedDst, ref readonly globalSrc)` was called with either:

1. A destination argument (`sharedDst`) that does not refer to an element of `SharedMemory<T>` (for example, a stack local variable or a global memory array element), or
2. A source argument (`globalSrc`) that does not refer to global memory of the target type `T` without implicit conversion (for example, a stack value local variable, a `SharedMemory<T>` element, an arithmetic expression `input[tid] + 1`, a literal, or an expression that undergoes an implicit numeric conversion).

The PTX `cp.async.ca.shared.global` instruction requires the destination pointer to reside in the `.shared` state space (`__cvta_generic_to_shared`) and the source pointer to reside in global memory (such as an element of a kernel/device-function array or `Span<T>` / `ReadOnlySpan<T>` parameter, or a `ref` / `ref readonly` / `in` parameter) rather than local/register memory, shared memory, or a compiler-materialized stack temporary.

> [!NOTE]
> Passing a `[GpuDeviceFunction]`'s `ref` parameter as `sharedDst` is also rejected because a general `ref T` parameter cannot be statically proven to point to shared memory. Call `Gpu.CopyAsync` at the caller site where `SharedMemory<T>` is in scope, or pass `SharedMemory<T>` directly to the device function.

## Examples

### Invalid Code (Triggers GSH0075)

```csharp
[GpuKernel]
public static void BadCopyAsync(int[] input, int[] output)
{
    var smem = new SharedMemory<int>(32);
    var smem2 = new SharedMemory<int>(32);
    int tid = ThreadIndex.X;
    int local = input[tid];

    // Error GSH0075: destination is not an element of SharedMemory<T>
    Gpu.CopyAsync(ref local, in input[tid]);
    Gpu.CopyAsync(ref output[tid], in input[tid]);

    // Error GSH0075: source is not in global memory or is a temporary value
    Gpu.CopyAsync(ref smem[tid], in local);
    Gpu.CopyAsync(ref smem[tid], in smem2[tid]);
    Gpu.CopyAsync(ref smem[tid], input[tid] + 1);
}
```

### Valid Code

```csharp
[GpuKernel]
public static void GoodCopyAsync(int[] input, int[] output)
{
    var smem = new SharedMemory<int>(32);
    int tid = ThreadIndex.X;

    Gpu.CopyAsync(ref smem[tid], in input[tid]);
    Gpu.CopyAsyncCommitGroup();
    Gpu.CopyAsyncWaitGroup(0);
    Gpu.SyncThreads();
    output[tid] = smem[tid];
}
```
