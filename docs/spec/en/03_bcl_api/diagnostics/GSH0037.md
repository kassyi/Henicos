# GSH0037

## Divergent barriers are prohibited

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

`Gpu.SyncThreads()` was placed inside a thread-dependent conditional branch (e.g., an `if` statement whose condition relies on `threadIdx`).

## Rule Description

In the CUDA programming model (SIMT), threads in a block execute concurrently. A barrier synchronization function like `Gpu.SyncThreads()` must be executed by *all* threads in the block. If some threads reach the barrier and others do not due to a conditional branch, it results in undefined behavior or a deadlock on the physical GPU.

Furthermore, during CPU testing (using the G# CPU Emulation Context), divergent barriers prevent the Bulk Synchronous Parallel (BSP) state machine from advancing, causing an immediate deadlock. The G# Roslyn Analyzer statically detects and blocks this to guarantee correctness across both environments.

## How to Fix

Ensure that all calls to `Gpu.SyncThreads()` are located in the uniform control flow of the kernel, where all threads within the block are guaranteed to reach the barrier.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel(Dim3 threadIdx)
{
    // ...
    if (threadIdx.X < 16) 
    {
        // ❌ Error GSH0037: Only some threads execute this barrier
        Gpu.SyncThreads();
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel(Dim3 threadIdx)
{
    // ...
    if (threadIdx.X < 16) 
    {
        // Perform work for the first 16 threads
    }
    
    // ✅ Correct: All threads execute the barrier uniformly
    Gpu.SyncThreads();
}
```
