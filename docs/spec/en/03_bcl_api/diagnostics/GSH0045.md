# GSH0045

## Recursive local functions cannot contain Gpu.SyncThreads()

| | |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A local function contains a call to `Gpu.SyncThreads()` and is invoked recursively.

## Rule Description

The G# Source Generator inlines all local functions and transforms the kernel AST into a flat state machine. If a local function is recursive and contains a barrier, the generator would fall into an infinite loop attempting to inline the recursion statically, making state machine generation impossible.

## How to Fix

Do not call `Gpu.SyncThreads()` inside recursive local functions. If recursion is required, ensure it does not cross barrier boundaries.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel()
{
    void RecursiveHelper(int depth)
    {
        if (depth == 0) return;
        
        // ❌ Error GSH0045: Recursive barrier prevents static inlining
        Gpu.SyncThreads(); 
        
        RecursiveHelper(depth - 1); 
    }
    
    RecursiveHelper(5);
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel()
{
    void IterativeHelper(int depth)
    {
        for (int i = 0; i < depth; i++)
        {
            // ✅ Correct: Loops with barriers are statically lowered to goto
            Gpu.SyncThreads(); 
        }
    }
    
    IterativeHelper(5);
}
```
