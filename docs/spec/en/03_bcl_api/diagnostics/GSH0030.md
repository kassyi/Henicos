# GSH0030: SyncGrid requires a cooperative kernel

## Details

| Property               | Value            |
| :--------------------- | :--------------- |
| **Diagnostic ID**      | GSH0030          |
| **Category**           | GSharpTranspiler |
| **Severity**           | Error            |
| **Enabled by Default** | Yes              |

## Why This Rule Exists (Architectural Context)

### Cooperative Grid Synchronization Barrier

The `Gpu.SyncGrid` method transpiles directly to `cg::this_grid().sync();` from the CUDA Cooperative Groups API. This powerful primitive synchronizes all threads across all blocks in the entire grid.

For this instruction to execute safely and correctly, the hardware requires the kernel to be launched via the `cudaLaunchCooperativeKernel` API (instead of the standard `cudaLaunchKernel`). If a grid synchronization barrier is hit inside a standard kernel launch, it may cause unpredictable behavior, deadlock, or crash the GPU. 

To enforce safety at compile-time, the `GSH0030` analyzer ensures that `Gpu.SyncGrid` is only used inside kernels explicitly decorated with `[GpuKernel(Cooperative = true)]`. By default, `[GpuKernel]` implies `Cooperative = false`.

## Cause

A call to `Gpu.SyncGrid()` or `Gpu.SyncGrid(Action)` was found inside a kernel method that is marked with `[GpuKernel]` or `[GpuKernel(Cooperative = false)]`.

## How to Fix

Change the kernel attribute to explicitly enable the cooperative launch mode: `[GpuKernel(Cooperative = true)]`. 

*Note: You can safely use `Gpu.SyncGrid` inside `[GpuDeviceFunction]` methods without warnings, as they inherit the execution context of the calling kernel. However, the root kernel calling that device function must be cooperative.*

## Examples

### 1. Compiler Errors (GSH0030)

The analyzer will flag any variation of `SyncGrid` if the kernel is not cooperative. This includes empty lambdas, expression-bodied lambdas, and nested `SyncGrid` calls.

```csharp
// ❌ ERROR: Cooperative is false by default
[GpuKernel] 
public static void ImplicitNonCooperative()
{
    Gpu.SyncGrid(); // GSH0030
}

// ❌ ERROR: Explicitly false
[GpuKernel(Cooperative = false)]
public static void ExplicitNonCooperative()
{
    Gpu.SyncGrid(() => 
    {
        // GSH0030
    });

    // GSH0030 is also emitted for nested, empty, or expression-bodied lambdas
    Gpu.SyncGrid(() => { }); 
}
```

```csharp
// ✅ OK: Explicitly cooperative
[GpuKernel(Cooperative = true)] 
public static void CooperativeKernelValid()
{
    Gpu.SyncGrid();
    Gpu.SyncGrid(() => { /* safely flattened */ });
}
```
