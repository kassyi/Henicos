# GSH0005: GpuBigIntExpr is discarded without being evaluated

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0005 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Host-Side Expression Templates and Silent Data Loss Prevention
`GpuBigInt` and `GpuBigIntExpr` are **Host-Side Orchestration APIs** located in `Kassyi.GSharp.Stdlib.GpuMath.BigNum`. They are executed on the host CPU to manage, chain, and launch arbitrary-precision arithmetic kernels on the GPU without intermediate memory overhead. **They cannot be used inside device-side `[GpuKernel]` methods.**

1. **Avoiding Intermediate GPU Allocations**: In high-precision arithmetic (e.g., 256-bit or 1024-bit cryptography), an expression like `(a + b) * c` would naively allocate a temporary GPU buffer for `(a + b)` and launch two separate kernels. To prevent this, G# uses **Host-Side Expression Templates**: arithmetic operators return a lightweight lazy `IDisposable` struct `GpuBigIntExpr` that builds a symbolic expression tree in host memory.
2. **The Hazard of Discarded Expressions**: If a developer writes `var sum = a + b;`, no GPU kernel is launched, and no result buffer is populated. If `sum` is never evaluated, compiled, returned, or disposed (for example, when only reading metadata such as `sum.Node.NumWords`), the calculation is silently discarded.
3. **Compile-Time Enforcement**: To catch discarded expression templates without rejecting valid API patterns, `GpuBigIntExprAnalyzer` reports **GSH0005** when a `GpuBigIntExpr` local is declared and neither evaluated nor disposed in its enclosing body, or when a `GpuBigIntExpr` is assigned to a field or other non-local target. The check is path-insensitive (a local accepted on one path is accepted) so valid conditional patterns are not falsely rejected.

## Cause

One of the following occurred:

1. A local variable of type `GpuBigIntExpr` was declared, and within its enclosing body it was neither:
   - declared with `using` (`using GpuBigIntExpr e = ...;` or `using (var e = ...)`),
   - evaluated or compiled (`Evaluate`, `CompileToGraph`, `EvaluateWithCudaGraph`, `EvaluateWithCudaGraphAsync`),
   - disposed (`Dispose`, `DisposeAsync`),
   - assigned to a `.Value` result property (`dest.Value = e;`),
   - passed as an argument (other than `out`), or to an operator taking `GpuBigIntExpr`,
   - returned to the caller, put into a tuple, a collection or an initializer, or otherwise passed to code that
     the analyzer does not follow, nor
   - assigned or copied to another local that is accepted.

   Reading a member (`e.Node.NumWords`), assigning to `_`, and copying into a local or a pattern variable that is
   itself dropped do not count. A `foreach` variable is not reported: it is a copy of an element that the collection
   owns.
2. A `GpuBigIntExpr` was assigned directly to a field or other non-local target (`_field = expr;`), which has no owning evaluation path.

## How to Fix

- Hold the expression in a `using` declaration: `using GpuBigIntExpr expr = a + b;`
- Compile it to an executable graph: `using var graph = expr.CompileToGraph(workspace);`
- Evaluate it into a buffer or workspace: `expr.Evaluate(dest);` or `using var result = expr.Evaluate(workspace);`
- Assign the expression directly to a destination buffer's `.Value`: `destination.Value = a + b;`
- Pass it to a method, call `expr.Dispose()`, or `return expr;` to transfer ownership to the caller.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: Host (CPU)
using Kassyi.GSharp.Stdlib.GpuMath.BigNum;
using Kassyi.GSharp.Stdlib.GpuMath.BigNum.Expressions;

public class CryptographyHostService
{
    public int InspectWidth(GpuBigInt a, GpuBigInt b)
    {
        // ❌ Error GSH0005: 'sum' is only read for .Node.NumWords and then dropped without being evaluated or disposed.
        GpuBigIntExpr sum = a + b;
        return sum.Node.NumWords;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
using Kassyi.GSharp.Stdlib.GpuMath;
using Kassyi.GSharp.Stdlib.GpuMath.BigNum;
using Kassyi.GSharp.Stdlib.GpuMath.BigNum.Expressions;

public class CryptographyHostService
{
    public void ComputeKeys(GpuWorkspace workspace, GpuBigInt a, GpuBigInt b, GpuBigUInt ua, GpuBigUInt ub, GpuBigUInt destination)
    {
        // ✅ Correct: Evaluated into a destination buffer
        GpuBigIntExpr sum = a + b;
        sum.Evaluate(destination);

        // ✅ Correct: Compiled into an executable CUDA graph
        GpuBigIntExpr expr = (GpuBigIntExpr)a + b;
        using var graph = expr.CompileToGraph(workspace);

        // ✅ Correct: Held in a using declaration
        using GpuBigIntExpr scoped = a + b;

        // ✅ Correct: Assigned directly via .Value
        destination.Value = ua + ub;
    }
}
```
