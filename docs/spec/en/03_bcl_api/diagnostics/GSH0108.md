# GSH0108: Struct field type is not accessible to the generated launcher

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0108 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

G# generates the launcher of a kernel into the kernel's class. The launcher copies every field of a struct argument to the device and back, private fields included: it declares a native shadow of each struct, and, when the host and device layouts differ, marshaling methods per struct and a mirror of the struct that names its private fields. Each of these names the type of every field. A field whose type the kernel's class cannot see, such as a private struct nested in the parameter struct, would make the generated C# fail with CS0122, so G# reports it at the parameter instead.

The field itself may be private: the launcher reaches private fields through the mirror. Only the field's type has to be accessible.

## Cause

A `[GpuKernel]` parameter or return value has a struct type with a field (directly or in a nested struct, or as the element of an array field) whose type is not accessible from the kernel's class. The message names the type, the path of the field and the kernel's class.

## How to Fix

Make the field's type `internal` or `public`, or declare it outside the struct.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Holder
{
    public int[] Data;
    private Hidden _hidden;

    public readonly int Value => _hidden.V;

    private struct Hidden
    {
        public int V;
    }
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Holder holder) // ❌ GSH0108: the type 'Holder.Hidden' of field '_hidden' is not accessible from 'Kernels'
    {
        holder.Data[0] = holder.Value;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Holder
{
    public int[] Data;
    private Hidden _hidden;

    public readonly int Value => _hidden.V;

    internal struct Hidden
    {
        public int V;
    }
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Holder holder) // ✅
    {
        holder.Data[0] = holder.Value;
    }
}
```
