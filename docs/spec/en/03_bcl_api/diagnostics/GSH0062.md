# GSH0062: User-defined operators are not supported in GPU code

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0062 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

User-defined operators (`operator +`, `operator *`, etc.) declared on C# value types are compiled as standard method overloads in C#. Emitting them as C++ operator expressions without corresponding C++ operator definitions causes C++ compilation failures. Furthermore, letting C++ perform overload resolution on native operators could violate the principle that C# resolved overload semantics must be preserved exactly in GPU code ("C++ must never re-resolve a name").

Direct support for emitting user-defined operators as named device functions is planned for a future release. Until then, user-defined operators in GPU code are rejected at compile time.

## Cause

An expression inside a `[GpuKernel]` or `[GpuDeviceFunction]` method uses a user-defined operator on a type that is not mapped via built-in prelude types or `[GpuOperatorMacro]`.

This includes binary expressions (`a + b`), compound assignments (`a += b`), prefix unary expressions (`-a`), and postfix expressions (`a++`).

## How to Fix

Move the operator logic into a `[GpuDeviceFunction]` method and call it directly, or decorate the operator with `[GpuOperatorMacro]`.

## Examples

### Code with Error (Before)

```csharp
public struct V2
{
    public float X;
    public float Y;

    public static V2 operator +(V2 a, V2 b) => new V2 { X = a.X + b.X, Y = a.Y + b.Y };
}

public static partial class ScaleKernel
{
    [GpuKernel]
    public static void Run(V2[] v)
    {
        int t = ThreadIndex.X;
        v[t] = v[t] + v[t]; // ❌ GSH0062
    }
}
```

### Corrected Code (After)

```csharp
public struct V2
{
    public float X;
    public float Y;
}

public static partial class ScaleKernel
{
    [GpuDeviceFunction]
    public static V2 Add(V2 a, V2 b)
    {
        return new V2 { X = a.X + b.X, Y = a.Y + b.Y };
    }

    [GpuKernel]
    public static void Run(V2[] v)
    {
        int t = ThreadIndex.X;
        v[t] = Add(v[t], v[t]); // ✅
    }
}
```
