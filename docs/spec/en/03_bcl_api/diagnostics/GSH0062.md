# GSH0062

## A call that suspends at a barrier is not supported in this context

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A warp shuffle (`Warp.Shuffle*Sync`, `Gpu.MatchAnySync`, `Gpu.MatchAllSync`), a warp vote or reduction (`Warp.BallotSync`, `Warp.AllSync`, `Warp.AnySync`, `Warp.Reduce*Sync`), the warp barrier `Gpu.SyncWarp`, `Warp.ActiveMask()`, or a `[GpuDeviceFunction]` that reaches `Gpu.SyncThreads()`, `Gpu.SyncGrid()` or one of them, directly or through other device functions, is called from one of these places in a kernel or device function:

- a lambda, an anonymous method or a local function (the bodies of `Gpu.ForUnroll` and `Gpu.SyncGrid(body)` are not lambdas here, and neither is the body of `Gpu.GridStrideLoop` for a warp shuffle, vote or reduction written directly in it: the CPU paths turn that loop into a `for` loop, which they split)
- an arm of a `switch` expression, or a `when` clause
- the part after `?.`, or the right operand of `??`
- for a warp shuffle, vote or reduction only: the body of a `using` or `fixed` statement, or the rest of a block after a `using` declaration (a device function that reaches a barrier there is GSH0003 or GSH0043)
- for such a device function only: a call that passes by reference (`ref`, `out`, `in`, or a variable given to an `in` or `ref readonly` parameter without the keyword) a variable that a call, a property or a ref conditional selects: `ref GetRef()`, `ref GetRef().F`, `GetInlineArray()[0]` (the element of an inline array that a call returns by reference), `ref cell.RefProperty`, `c ? ref a : ref b`. A local, a parameter, a field of one of them, an array element (also of an array that a call returns), an element of an inline array or fixed-size buffer variable, and what a pointer points to (`*p`, `p[i]`, `p->F`) are allowed: the array or pointer is evaluated once, before the call

## Rule Description

On the CPU dialects every thread of a block runs as a state machine that suspends at each barrier. A call to a device function that reaches a barrier suspends the caller, so the caller's body is split into states at that call and the call is made again on every resume until it completes.

A warp shuffle splits the state machine in the same way: the lanes of its mask write their values and wait until every lane of the mask that has not exited has reached the same call, and only then read each other's values. `Gpu.SyncWarp` is such a meeting without a value, and `Warp.ActiveMask()` returns the lanes that stop at the same call in the same round of the state machine. Only the statements of the kernel or device function body are split this way. The compiler also turns the operands of `&&`, `||` and `?:` into `if` statements first. The places listed above are not part of that state machine, so a suspended call there could not be resumed, and a warp shuffle there would read a lane that has not written its value yet, or run where C# does not evaluate it. A by-reference argument selected by an expression, such as the result of a method that returns by reference (`ref Select(cells, i)`, also through a member access as in `ref Select(cells, i).F` or an element access, and also when it is passed to an `in` parameter without the `in` keyword), a property that returns by reference, or a ref conditional (`c ? ref a : ref b`), would be selected again on every resume and could refer to a different variable each time. This is a limit of the CPU state machine, which a later version lifts by keeping the reference itself.

Calls to device functions that never reach a barrier are not affected. A warp shuffle, vote or reduction written directly in one of these places is reported only when the project builds the CPU paths (`GSharpTargetDialect` other than `Cuda`): CUDA runs the shuffle where it stands, so a project built only for CUDA accepts it. A call to a device function that reaches a barrier or a warp shuffle is reported for every target, so that such a kernel builds and behaves the same on all of them.

## How to Fix

Move the call into a statement of the kernel or device function body, store its result in a local, and use the local in the original place. For a by-reference argument, store the reference in a `ref` local first, or pass the array element directly.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuDeviceFunction]
public static int Broadcast(int value) => Warp.ShuffleSync(0xFFFFFFFFu, value, 0);

[GpuKernel]
public static void Kernel(int[] buffer, int mode)
{
    // ❌ Error GSH0062: a switch expression arm is not split into states
    buffer[ThreadIndex.X] = mode switch
    {
        0 => Broadcast(buffer[ThreadIndex.X]),
        _ => buffer[ThreadIndex.X]
    };
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel(int[] buffer, int mode)
{
    int value = buffer[ThreadIndex.X];
    if (mode == 0)
    {
        // ✅ Correct: the call is a statement of the kernel body
        value = Broadcast(value);
    }

    buffer[ThreadIndex.X] = value;
}
```
