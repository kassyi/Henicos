# GSH0072: IteratorBodyConstructNotSupported

- **Severity**: Error
- **Category**: `GSharp.Compiler`
- **Message Format**: `"'{0}' is not supported inside a GPU iterator or its consuming foreach"`

## Cause

Device iterators in G# are lowered by **inlining the iterator body into each consumer `foreach` loop**, substituting every `yield return` with the consumer loop body. While general control flow (`for`, `while`, `do`, `if`/`else`, `switch`, nested `foreach`, `[InlineArray]` `foreach`, `using`, `Span<T>`, and deconstruction) is supported inside device iterators, thread-group synchronization and shared-memory allocations interact with SIMT execution and barrier-splitting in ways that cannot cross an inlined iterator boundary.

`GSH0072` is reported in the following situations:

1. **Thread-group barriers or suspending calls inside an iterator body**: Calling `Gpu.SyncThreads()`, `Gpu.SyncWarp()`, or any function that transitively synchronizes threads inside a `[GpuDeviceFunction]` iterator is prohibited.
2. **Thread-group barriers or suspending calls inside a consumer `foreach` body over an iterator**: Because the consumer `foreach` body is substituted at every `yield return` inside the iterator's control flow, placing `Gpu.SyncThreads()` or a suspending call inside the body of a `foreach` that consumes a device iterator is prohibited.
3. **`SharedMemory<T>` allocation inside an iterator body**: Declaring `SharedMemory<T>` inside an iterator is prohibited because each inlined `foreach` (or `yield return` path) would otherwise duplicate or misalign block-wide shared memory declarations. Allocate `SharedMemory<T>` in the `[GpuKernel]` entry point instead.
4. **Iterator local variable crossing a thread-group barrier**: Storing an iterator call in a local variable (`var seq = MyIterator(...);`) and consuming `seq` after a `Gpu.SyncThreads()` barrier (or across iterations of an enclosing loop that contains a barrier) is prohibited because iterator locals are expanded from their declaration site and are not hoisted into barrier state frames.

## Example (Error)

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> BadIteratorWithBarrier(int count)
    {
        for (int i = 0; i < count; i++)
        {
            // Error GSH0072: Gpu.SyncThreads() is not allowed inside an iterator.
            Gpu.SyncThreads();
            yield return i;
        }
    }

    [GpuDeviceFunction]
    public static IEnumerable<int> BadIteratorWithSharedMemory(int count)
    {
        // Error GSH0072: SharedMemory<T> allocation is not allowed inside an iterator.
        SharedMemory<int> shared = new(16);
        shared[0] = count;
        yield return shared[0];
    }

    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }

    [GpuKernel]
    public static void BadConsumerKernel(int[] output)
    {
        foreach (var x in Range(0, 4))
        {
            // Error GSH0072: Gpu.SyncThreads() is not allowed inside a foreach over an iterator.
            Gpu.SyncThreads();
            output[0] += x;
        }

        // Error GSH0072: Iterator local 'seq' crosses a barrier before being consumed.
        var seq = Range(0, 4);
        Gpu.SyncThreads();
        foreach (var y in seq)
        {
            output[0] += y;
        }
    }
}
```

## How to Fix

- Keep `Gpu.SyncThreads()` and `SharedMemory<T>` declarations in the `[GpuKernel]` method outside of iterator bodies and outside of `foreach` loops that consume iterators.
- Declare iterator locals on the same side of any barrier where they are consumed, or call the iterator directly in the `foreach` header (`foreach (var y in Range(0, 4))`).

```csharp
using System.Collections.Generic;
using Kassyi.GSharp.Core;

public static partial class Kernels
{
    [GpuDeviceFunction]
    public static IEnumerable<int> Range(int start, int count)
    {
        for (int i = 0; i < count; i++)
        {
            yield return start + i;
        }
    }

    [GpuKernel]
    public static void GoodConsumerKernel(int[] output)
    {
        SharedMemory<int> scratch = new(64);
        int tid = ThreadIndex.X;

        int acc = 0;
        foreach (var x in Range(0, 4))
        {
            acc += x;
        }

        scratch[tid] = acc;
        Gpu.SyncThreads();

        foreach (var y in Range(0, 4))
        {
            acc += scratch[tid] + y;
        }

        output[tid] = acc;
    }
}
```
