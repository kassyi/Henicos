# GSH0072

## Unsupported construct in or around an iterator

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

One of the following constructs was used inside a `[GpuDeviceFunction]` iterator or inside a `foreach` loop over an iterator:

- Thread barriers (`Gpu.SyncThreads()`, `Gpu.SyncGrid()`), warp shuffles, or calls to suspending device functions inside an iterator body or inside a `foreach` loop over an iterator.
- A `using` statement or `using` declaration inside an iterator body.
- A `SharedMemory<T>` declaration inside an iterator body.
- A `yield return` or `yield break` inside a `switch` statement.
- A `foreach` loop over an `[InlineArray]` type inside an iterator body.
- A `ref` local, `ref struct` local (such as `Span<T>`), or local pointer (`stackalloc` / `&local`) whose lifetime crosses a `yield return` boundary.

## Rule Description

G# lowers `[GpuDeviceFunction]` iterators by hoisting locals that survive across `yield return` into a stack frame and rewriting `yield return` into state transitions. Constructs that require block-wide thread synchronization (`Gpu.SyncThreads()`), deterministic scope disposal across suspension (`using`), shared memory allocation, or stack-bound references (`ref` / `Span<T>` / stack pointers) across suspension boundaries cannot be safely preserved in an iterator state machine.

## How to Fix

Keep barriers, `using` scopes, and `SharedMemory<T>` allocations in the caller outside the iterator and outside the `foreach` loop over the iterator, and keep `Span<T>` or `ref` locals scoped within a single step between `yield return` statements.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuDeviceFunction]
public static IEnumerable<int> BadIterator(int[] data)
{
    Span<int> slice = data.AsSpan();
    yield return slice[0];
    // ❌ Error GSH0072: ref struct local 'slice' crosses a yield boundary
    yield return slice[1];
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuDeviceFunction]
public static IEnumerable<int> GoodIterator(int[] data)
{
    // ✅ Correct: Span<T> does not cross yield return
    yield return data[0];
    yield return data[1];
}
```
