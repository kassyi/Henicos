# SLQ0001: StackLinq method chain is too deep

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | SLQ0001 |
| **Category** | CompilerLimits |
| **Severity** | Error |
| **Enabled by Default** | Yes |

---

## Why This Rule Exists (Architectural Context)

`Kassyi.ZeroAlloc.Linq` (`StackLinq`) relies on nesting `ref struct` enumerators to avoid heap allocations. While this eliminates garbage collection and permits loop fusion:

1. **Compiler Template Instantiation Limits**:
   During C++ transpilation, deeply nested generic struct chains produce heavily nested C++ template types. Exceeding compiler limits causes template instantiation overflow and excessive build times.
2. **Register Pressure on GPU (CUDA)**:
   In GPU Streaming Multiprocessors (SMs), each thread has a fixed, hardware-limited register pool. Extremely deep enumerator state chains force the compiler to accumulate state across operations, threatening register spilling into local memory.

To maintain compiler stability and runtime efficiency, `SLQ0001` reports an error when the chain depth exceeds the threshold (`MaxChainDepth = 50`).

---

## Cause

A single fluent StackLinq query chain exceeds the maximum allowed depth of 50 chained method invocations.

---

## How to Fix

1. **Break into Intermediate Variables**:
   Split long queries across multiple statements or assign intermediate results to separate variables.
2. **Combine Predicates and Projections**:
   Combine consecutive `.Where()` calls into a single compound predicate `.Where(x => cond1 && cond2)`.
3. **AST Loop Fusion**:
   The GSharp transpiler's `StackLinqFusionRule` automatically fuses and optimizes compatible iterator chains; keep query structure clear and localized.

---

## Examples

### Code with Error (Before)

```csharp
// ❌ Error SLQ0001: StackLinq method chain exceeds maximum allowed depth
// (Chaining more than 50 consecutive operators)
var result = data
    .AsStackEnumerable()
    .SkipLast(2)
    .Where(x => x > 0)
    .Select(x => x * 2)
    // ... 50+ operators chained consecutively ...
    .Sum();
```

### Preferred Code (After)

```csharp
// ✅ Break into intermediate variables or combine predicates
var filtered = data
    .AsStackEnumerable()
    .SkipLast(2)
    .Where(x => x > 0 && (x * 2) % 4 == 0);

var result = filtered
    .Select(x => (x * 2) + 1)
    .Sum();
```
