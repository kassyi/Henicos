# GSH0079: Struct field type has no device representation

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0079 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

The device definition of a user struct declares each field with the C++ type that the dialect maps its C# type to: the primitive types, `char`, the `System.Numerics` and `Kassyi.GSharp.Core` vectors, enums, pointers, arrays (`GSharpArray<T>`) and other user structs. A field of any other value type, such as `decimal`, `DateTime` or `Guid`, has no C++ type and no known device size, so the generated C++ would not compile, and its layout could not be checked against the host.

## Cause

A `[GpuKernel]` parameter or a local variable in GPU code has a struct type with a field (directly or in a nested struct) whose type the dialect does not map. The message names the type and the field.

## How to Fix

Store the value in a type the device supports: an integer or floating-point number (for example a fixed-point `long` in place of `decimal`, or `DateTime.Ticks` in place of `DateTime`), or a user struct of supported fields.

## Examples

### Code with Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Priced
{
    public int Id;
    public decimal Price;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Priced p, int[] r) // ❌ GSH0079: the type 'decimal' of field 'Price' has no device representation
    {
        r[0] = p.Id;
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Priced
{
    public int Id;
    public long PriceInCents;
}

public static partial class Kernels
{
    [GpuKernel]
    public static void Read(Priced p, int[] r) // ✅
    {
        r[0] = p.Id;
    }
}
```
