# GSH0099: An AsParallel() aggregate runs sequentially in each thread

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0099 |
| **Category** | GSharpTranspiler |
| **Severity** | Warning |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

In a kernel, `data.AsStackEnumerable().AsParallel().Sum()` means what it means in C#: every thread that calls it receives the sum of the whole sequence. `AsParallel()` lets G# choose how to compute that sum. On CUDA, the threads of a block share the elements and combine their partial sums, which needs every thread of the block to reach the call together and to sum the same values. When G# cannot show that, each thread sums the whole sequence on its own: the result is the same, but the work is repeated in every thread. This warning says so, and why.

## Cause

The aggregate is in one of these forms:

- in a `[GpuDeviceFunction]`, or inside a lambda or local function (other than the body of `Gpu.SyncGrid` / `Gpu.ForUnroll`);
- under a condition that may differ between the threads of a block, or after a `return`, `break`, `continue` or `goto` that only some threads may take;
- its source is not an array or span parameter of the kernel (a local array or span, `stackalloc`, a reassigned local);
- a stage depends on the elements before it: `TakeWhile`, `SkipWhile`, or `Skip` / `Take` after `Where`;
- a lambda of the chain has a statement body or writes to a variable or memory;
- the source, a stage argument or a value a lambda reads may differ between threads (for example `ThreadIndex.X`);
- the sum is not of `int`, `uint`, `long` or `ulong` (a `float` or `double` sum is not shared yet).

## How to Fix

Move the call out of the branch, make its inputs the same in every thread, or keep it as it is when the cost is acceptable: the value is correct either way.

## Example

```csharp
[GpuKernel]
public static void Run(int[] data, int[] result)
{
    if (ThreadIndex.X == 0)
    {
        result[BlockIndex.X] = data.AsStackEnumerable().AsParallel().Sum(); // GSH0099: under a thread-dependent condition
    }

    int sum = data.AsStackEnumerable().AsParallel().Sum(); // Shared by the threads of the block
    result[BlockIndex.X * BlockDimension.X + ThreadIndex.X] = sum;
}
```
