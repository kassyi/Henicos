# GSH0043

## Gpu.SyncThreads() cannot be called inside a fixed block

| | |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A call to `Gpu.SyncThreads()` was found inside a `fixed` statement block.

## Rule Description

The C# `fixed` statement pins a managed object in memory. During CPU emulation, `Gpu.SyncThreads()` physically `return`s from the C# method. When this happens inside a `fixed` block, the GC pin is immediately released. When the state machine resumes, the object may have been moved by the GC, resulting in an Access Violation.

## How to Fix

Avoid using `fixed` blocks around barriers. GPU kernels usually receive pre-pinned memory via Unmanaged pointers or `GpuBuffer<T>`.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public unsafe static void Kernel(int[] managedArray)
{
    fixed (int* ptr = &managedArray[0])
    {
        // ❌ Error GSH0043: Emulation suspend will release the GC pin!
        Gpu.SyncThreads();
        ptr[0] = 1;
    }
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public unsafe static void Kernel(int* unmanagedPtr)
{
    // ✅ Correct: The memory is not managed by the GC
    Gpu.SyncThreads();
    unmanagedPtr[0] = 1;
}
```
