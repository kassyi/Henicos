# GSH0040

## goto statements cannot cross barrier synchronization

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

A `goto` statement jumps across a `Gpu.SyncThreads()` barrier, or across a call to a `[GpuDeviceFunction]` that may suspend (one that reaches a barrier, directly or through its own calls). The check is textual: the barrier or the call lies between the `goto` and its label in the source.

## Rule Description

The CPU emulator transforms the kernel into a flat `switch-case` state machine, using `Gpu.SyncThreads()` and the calls to device functions that may suspend as phase boundaries. A `goto` statement that jumps from one phase (before a barrier) to another phase (after a barrier) breaks the linear progression of the state machine and makes control flow restoration impossible. A call that may suspend counts as a barrier because the calling thread waits in it for the other threads of the block.

## How to Fix

Refactor the code to avoid `goto` jumps across barriers. Standard loops (`for`, `while`) containing barriers are automatically supported and handled by the compiler.

## Examples

### Code with Warning / Error (Before)

```csharp
[GpuKernel]
public static void Kernel()
{
    goto SkipBarrier; // ❌ Error GSH0040: jumps across barrier
    
    Gpu.SyncThreads();
    
SkipBarrier:
    return;
}
```

A call to a device function that reaches a barrier is reported the same way:

```csharp
[GpuDeviceFunction]
public static void Publish(int[] data, int value)
{
    data[ThreadIndex.X] = value;
    Gpu.SyncThreads();
}

[GpuKernel]
public static void Kernel(int[] data, int flag)
{
    if (flag != 0)
    {
        goto Done; // Error GSH0040: Publish may suspend, so the jump crosses a barrier
    }

    Publish(data, 1);

Done:
    data[ThreadIndex.X] += 1;
}
```

### Corrected Code (After)

```csharp
[GpuKernel]
public static void Kernel(bool skip)
{
    if (!skip)
    {
        Gpu.SyncThreads(); 
    }
    // ✅ Correct: Control flow does not use arbitrary cross-barrier goto
}
```
