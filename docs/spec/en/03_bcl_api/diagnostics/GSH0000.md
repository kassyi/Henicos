# GSH0000: AOT Artifact Error

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0000 |
| **Category** | Build |
| **Severity** | Info |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Best-Effort AOT Artifacts
The `GpuKernelGenerator` writes the transpiled CUDA C++ (`.g.cu` / `.g.cpp`) and its sidecar symbol map
(`*.gsym.json`) to `$(IntermediateOutputPath)` so that native toolchains can consume them ahead of time. The write is
best-effort: a failure must never break compilation, but it must not be swallowed silently either. The generator
therefore reports the I/O error as an informational diagnostic.

## Cause

The artifact path could not be created or written, for example because the file is locked by another process, the
directory is read-only, or the path is too long.

## How to Fix

Check that `$(IntermediateOutputPath)` is writable and that no other process (an IDE worker, `nvcc`, `cl.exe`) holds
the file open. The managed build output is not affected by this diagnostic.
