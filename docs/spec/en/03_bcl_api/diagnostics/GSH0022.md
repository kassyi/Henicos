# GSH0022: Undisposed GPU scope

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0022 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Owned Resources Leak With Their Owner
A type that owns a disposable field (a `GpuWorkspace`, a GPU array, any `IDisposable` it did not borrow) is the only thing that can free it. When the `Dispose()` of the type does not release the field, the native allocation behind it stays alive until the process ends.

## Cause

A type implements `IDisposable`, but its `Dispose()` method does not release a disposable field the type owns. The field counts as released when one of these appears in a `Dispose` method:

- `field.Dispose()`, `this.field.Dispose()` or `field?.Dispose()`;
- a call to a method of the same type, or a local function of `Dispose`, whose body releases the field: by its name, or through the parameter that the field is passed to (`ref`, `in` or by value), up to three helpers deep;
- the field passed to a method whose body the analysis cannot see (another type, a base type, a delegate), which may release it; a chain deeper than three helpers counts the same way.

A field that no path releases is reported at the identifier of `Dispose()`, with its name. A borrowed field (a constructor parameter without `[TakesOwnership]`) is never reported here; releasing it is [GSH0027](GSH0027.md).

An error is reported only when the field is surely not released: the analysis does not reject code it cannot prove wrong (the semantics charter). It follows helpers as the .NET analyzer CA2213 does.

## How to Fix

Release the field in `Dispose()`, directly or through a helper of the type.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public sealed class Cache : IDisposable
{
    private GpuBigUIntArray _values;
    private GpuBigUIntArray _signs;

    public void Dispose()
    {
        _values.Dispose();
        // Error GSH0022: '_signs' is never released
    }
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public sealed class Cache : IDisposable
{
    private GpuBigUIntArray _values;
    private GpuBigUIntArray _signs;

    public void Dispose()
    {
        // Correct: each field released through the helper, which clears it even when the release throws
        List<Exception>? errors = null;
        Release(ref _values, ref errors);
        Release(ref _signs, ref errors);
        if (errors != null)
        {
            throw new AggregateException(errors);
        }
    }

    private static void Release(ref GpuBigUIntArray field, ref List<Exception>? errors)
    {
        try
        {
            field.Dispose();
        }
        catch (Exception ex)
        {
            (errors ??= []).Add(ex);
        }
        finally
        {
            field = default;
        }
    }
}
```
