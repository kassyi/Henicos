# GSH0065: Non-const static fields and properties are not supported in GPU code

| Detail | Value |
| :--- | :--- |
| **ID** | GSH0065 |
| **Title** | Non-const static fields and properties are not supported in GPU code |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists

Static fields (both `static readonly` and mutable `static`) and static properties reside in host System.RAM memory. GPU kernels execute asynchronously on physical GPU VRAM and cannot directly access or dereference arbitrary host static memory locations. Referencing non-const static fields or properties inside GPU code results in undefined GPU symbol references or invalid memory accesses.

Compile-time constants (`const` fields), enum members, and hardware intrinsics remain supported because their values are inlined or mapped to CUDA intrinsics.

## Cause

A `[GpuKernel]` or `[GpuDeviceFunction]` method reads a non-const static field (e.g., `static readonly int`) or a static property.

```csharp
public static class Cfg
{
    public static readonly int Limit = 100;
}

[GpuKernel]
public static void Run(int[] data)
{
    // Error GSH0065: Non-const static fields and properties are not supported in GPU code
    data[ThreadIndex.X] = Cfg.Limit;
}
```

## How to Fix

1. Change the static field to a `const` field if its value is known at compile time:

```csharp
public static class Cfg
{
    public const int Limit = 100;
}
```

2. Alternatively, pass the runtime configuration value as a parameter to the GPU kernel:

```csharp
[GpuKernel]
public static void Run(int[] data, int limit)
{
    data[ThreadIndex.X] = limit;
}
```

## Examples

### Incorrect

```csharp
public static class Config
{
    public static readonly int BatchSize = 64;
    public static int Counter = 0;
    public static int Threshold => 10;
}

[GpuKernel]
public static void ProcessKernel(int[] output)
{
    int val = Config.BatchSize + Config.Counter + Config.Threshold;
}
```

### Correct

```csharp
public static class Config
{
    public const int BatchSize = 64;
}

[GpuKernel]
public static void ProcessKernel(int[] output, int counter, int threshold)
{
    int val = Config.BatchSize + counter + threshold;
}
```
