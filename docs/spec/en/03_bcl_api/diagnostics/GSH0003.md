# GSH0003: Unsupported syntax in GPU kernel

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0003 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Static Determinism and Transpilation Guarantees
G# guarantees **Static Determinism** (YES Static Determinism): all kernel logic and type operations must be resolvable at compile-time by the Roslyn Source Generator into valid, deterministic CUDA C++ without any runtime interpretation, dynamic dispatch, or reflection overhead.

When an unknown or unsupported syntax node is encountered (such as dynamic `stackalloc`, complex pattern-matching expressions, or unmapped .NET runtime functions), the compiler rejects it immediately. Allowing unsupported syntax to pass through would generate invalid CUDA code or result in silent CUDA driver compilation errors (`nvrtcCompilationError` / `PTXAS syntax error`) that are nearly impossible to debug at runtime.

## Cause

The Roslyn transpiler encountered a C# syntax construct that cannot be safely translated into native CUDA C++ / PTX.

## How to Fix

Refactor the logic using standard supported imperative constructs: fixed compile-time size arrays, standard `if/else` statements, or explicitly supported G# BCL APIs.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadKernel(int dynamicSize)
{
    // ❌ Error GSH0003: Dynamic stackalloc size cannot be statically allocated in GPU stack frames
    int* buffer = stackalloc int[dynamicSize];
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel()
{
    // ✅ Correct: Compile-time constant size allows static register/stack reservation
    int* buffer = stackalloc int[64];
}
```

### Arrays That Cannot Be Stack Arrays

A local array is a C++ array of the thread. An array of more than one dimension has no such form (the message is `multidimensional array`), and an array of length zero cannot be told apart from a null array, which G# represents as an array without data (`zero-length array`). A span over an empty `stackalloc` is not reported.

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadArrayKernel(int[] output)
{
    // ❌ Error GSH0003: multidimensional array
    int[,] m = new int[2, 3];
    // ❌ Error GSH0003: zero-length array
    int[] empty = new int[0];
    int[] none = { };
}

[GpuKernel]
public static void GoodArrayKernel(int[] output)
{
    // ✅ One dimension, indexed as row * 3 + column
    int[] m = new int[2 * 3];
    output[0] = m[1 * 3 + 2];
}
```

### Return and Loop Variable Assignment in a Loop Macro Body

The body of `Gpu.ForUnroll` and `Gpu.GridStrideLoop` is written into the surrounding kernel code. A `return` statement in it would therefore end the kernel instead of one iteration, and an assignment to the loop variable, or a reference to it (an `in` argument or `&i`), would assign or point at the iteration index. All are reported (the message is `return in a Gpu.ForUnroll body`, `assignment to the Gpu.ForUnroll loop variable 'i'` or `reference to the Gpu.ForUnroll loop variable 'i'`).

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadLoopKernel(int[] data)
{
    Gpu.ForUnroll(0, 4, i =>
    {
        // ❌ Error GSH0003: return in a Gpu.ForUnroll body
        if (i == 2) return;
        // ❌ Error GSH0003: assignment to the Gpu.ForUnroll loop variable 'i'
        i += 1;
        data[i] += 1;
    });
}
```

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodLoopKernel(int[] data)
{
    Gpu.ForUnroll(0, 4, i =>
    {
        // ✅ Correct: skip the work with a condition, and put a changed index in a local variable
        if (i != 2)
        {
            int index = i + 1;
            data[index] += 1;
        }
    });
}
```

### Declarations After a Return and goto in a Gpu.SyncGrid Body

A `return` in a `Gpu.SyncGrid(() => { ... })` body ends the body for the thread, and the statements after it run only on the threads that did not return (see [Gpu.SyncGrid](../gpu_class/SyncGrid.md#return-in-a-body)). To keep a local declared after the `return` visible to the later statements, the compiler declares it at the top of the body and assigns it where it was declared. Some locals cannot be declared apart from their initializer and are reported when they come after a `return` (the message ends in `declared after a return in a Gpu.SyncGrid body`):

- a `ref`, `scoped` or `using` local;
- a deconstruction (`var (a, b) = pair;`) or a pattern variable that stays in scope after its statement (`if (x is int v) ...;`);
- a local of a `SharedMemory<T>`, array-like or iterator type.

A `goto` whose label is outside its own statement of the body would jump past the grid synchronization between the statements, and is reported anywhere in the body (`goto out of a statement of a Gpu.SyncGrid body`). An `out` variable (`Read(out var x);`) and a plain local can be declared after a `return`.

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel(Cooperative = true)]
public static void BadSyncGridBody(int[] data, int n)
{
    int tid = BlockIndex.X * BlockDimension.X + ThreadIndex.X;
    Gpu.SyncGrid(() =>
    {
        if (tid >= n) return;
        // Error GSH0003: ref, scoped, using, pattern or deconstruction local, ... declared after a return in a Gpu.SyncGrid body
        ref int slot = ref data[tid];
        slot += 1;
        // Error GSH0003: goto out of a statement of a Gpu.SyncGrid body
        if (slot > 10) goto end;
        data[tid] *= 2;
        end: data[tid] += 1;
    });
}
```

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel(Cooperative = true)]
public static void GoodSyncGridBody(int[] data, int n)
{
    int tid = BlockIndex.X * BlockDimension.X + ThreadIndex.X;
    Gpu.SyncGrid(() =>
    {
        if (tid >= n) return;
        // Correct: a plain local, and the condition in the statement that it guards
        int value = data[tid] + 1;
        data[tid] = value > 10 ? value + 1 : value * 2 + 1;
    });
}
```
