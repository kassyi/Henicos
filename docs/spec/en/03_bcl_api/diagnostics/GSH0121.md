# GSH0121: A generic device function cannot be compiled for the GPU

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0121 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

A type parameter has no C++ type: the C++ and CUDA output of a function depends on the concrete type of every value
(integer semantics, conversions, the layout of a struct), so G# compiles a generic device function once for each set of
type arguments that the kernels use, as a closed function of its own. Until that is in place, G# does not compile the
generic declaration as it is written. It reports this diagnostic once, at the name of the function, instead of one
diagnostic for each use of a type parameter in its body, and it writes neither the C++ nor the CUDA function, nor, for a
function that waits at a barrier, the frame and the managed state machine of the CPU paths.

Generic iterators (`IEnumerable<T>` with `yield`) are reported by [GSH0070](GSH0070.md) instead. Generic kernels are
reported by [GSH0111](GSH0111.md). Generic structs and their constructors are not affected: each closed struct type is
written as a type of its own. A device function that declares no type parameter of its own but is a member of a
generic type is not reported here.

## Cause

A method marked `[GpuDeviceFunction]` declares type parameters.

## How to Fix

Write the function for the types that the kernels use, without type parameters.

## Examples

### Code with an Error (Before)

```csharp
public static partial class PickKernels
{
    [GpuDeviceFunction]
    public static T Pick<T>(T a, T b, bool first) where T : unmanaged => first ? a : b;   // GSH0121 at 'Pick'

    [GpuKernel]
    public static void Run(int[] xs)
    {
        int tid = ThreadIndex.X;
        xs[tid] = Pick(xs[tid], 0, tid % 2 == 0);
    }
}
```

### Corrected Code (After)

```csharp
public static partial class PickKernels
{
    [GpuDeviceFunction]
    public static int Pick(int a, int b, bool first) => first ? a : b;   // OK

    [GpuKernel]
    public static void Run(int[] xs)
    {
        int tid = ThreadIndex.X;
        xs[tid] = Pick(xs[tid], 0, tid % 2 == 0);
    }
}
```
