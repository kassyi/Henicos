# GSH0006: InlinePtx argument must be a string literal

## Details

| Property | Value |
| :--- | :--- |
| **Diagnostic ID** | GSH0006 |
| **Category** | GSharpTranspiler |
| **Severity** | Error |
| **Enabled by Default** | Yes |

## Why This Rule Exists (Architectural Context)

### Ahead-Of-Time (AOT) Inline Assembly Injection
`Gpu.InlinePtx` allows low-level developers to inject hardware assembly instructions directly into the generated CUDA C++ source code. The G# Roslyn Source Generator executes strictly at compile-time during the MSBuild process, translating C# AST nodes into CUDA source text.

If the argument to `Gpu.InlinePtx` is a variable or dynamic string evaluated at runtime (e.g. `Gpu.InlinePtx(GetPtxString())`), the Roslyn analyzer cannot inspect its contents at compile-time. Consequently, the compiler cannot validate register constraints, inject proper operand clobbers, or embed the assembly into the emitted `.cu` file.

## Cause

A non-constant variable or method invocation was passed as the argument to `Gpu.InlinePtx`.

## How to Fix

Supply a compile-time string literal or a `const string` declaration.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void BadKernel(string dynamicAssembly)
{
    // Error GSH0006: Runtime variable passed to InlinePtx
    Gpu.InlinePtx(dynamicAssembly);
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
[GpuKernel]
public static void GoodKernel()
{
    // Correct: Compile-time constant string literal embedded directly during source generation
    Gpu.InlinePtx("mov.u32 %r0, %ctaid.x;");
}
```
