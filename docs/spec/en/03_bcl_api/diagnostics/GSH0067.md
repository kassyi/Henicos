# GSH0067

## Disposable resource is created and discarded

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

An expression statement creates a resource whose type implements `IDisposable` (`new GpuWorkspace();`, `_ = new GpuWorkspace();`) and does not keep the result.

## Rule Description

Nothing can call `Dispose()` on a resource that no variable holds, so its native allocation leaks at once. This is the "Discarded Allocation" pattern of Layer 1 in the [memory safety guide](../../04_guides/02_memory_safety_patterns.md). A type counts as disposable under the same test that the field checks (`GSH0020`, `GSH0022`) use.

The check looks only at creation expressions. A call whose return value is discarded is not reported, because the analyzer cannot tell a factory that hands over ownership from a method that returns a borrowed reference.

## How to Fix

Bind the resource to a `using` declaration, or remove the allocation.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: Host (CPU)
public void Run()
{
    // ❌ Error GSH0067: the workspace can never be disposed
    new GpuWorkspace();
}
```

### Corrected Code (After)

```csharp
// Execution Context: Host (CPU)
public void Run()
{
    // ✅ Correct: disposed when the scope ends
    using var ctx = new GpuWorkspace();
}
```
