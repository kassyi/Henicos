# GSH0069

## SharedMemory element type must not be disposable

|  |  |
| :--- | :--- |
| **Category** | GSharpTranspiler |
| **Severity** | Error |

## Cause

`new SharedMemory<T>(...)` (or target-typed `new(...)`) in a `[GpuKernel]` or `[GpuDeviceFunction]`, where `T` implements `System.IDisposable`. A type parameter is checked through its constraints.

## Rule Description

Shared memory belongs to the thread block and is released when the block ends. No thread owns an element, so no thread can run its `Dispose()`: a disposable element would hold a resource that is never released. An element type that does not implement `IDisposable` is accepted.

## How to Fix

Use a plain value type as the element and release the resource it stands for on the host, where the owner can dispose it.

## Examples

### Code with Warning / Error (Before)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Handle : IDisposable
{
    public int Value;
    public void Dispose() { }
}

[GpuKernel]
public static void BadKernel(int[] result)
{
    // ❌ Error GSH0069: Handle is disposable
    SharedMemory<Handle> handles = new(64);
    result[ThreadIndex.X] = handles[0].Value;
}
```

### Corrected Code (After)

```csharp
// Execution Context: G# Kernel (GPU)
public struct Slot
{
    public int Value;
}

[GpuKernel]
public static void GoodKernel(int[] result)
{
    // ✅ Correct: a plain value type
    SharedMemory<Slot> slots = new(64);
    result[ThreadIndex.X] = slots[0].Value;
}
```
