# ==============================================================================
# Banned APIs in G# Compiler & Transpiler (Mentalism & Safety Guardrails)
# ==============================================================================
# Format: {Prefix}:{DocumentationCommentId}[;Description]
#
# Prefixes:
#   #  - Comment line (ignored by analyzer)
#   T: - Type (class, struct, interface, delegate, etc.)
#   N: - Namespace
#   M: - Method (regular method, extension method, operator, constructor, etc.)
#   P: - Property
#   F: - Field
#   E: - Event
#
# Critical Gotchas & Pitfalls (4 Must-Know Rules):
#   1. Parameterless methods must NOT include parentheses '()' (DocId Specification):
#      Roslyn's DocumentationCommentId format omits parentheses for parameterless methods.
#      ❌ M:Microsoft.CodeAnalysis.ISymbol.ToString() (Does not match DocId format and is silently ignored)
#      ✅ M:Microsoft.CodeAnalysis.ISymbol.ToString
#
#   2. 'T:' does NOT capture extension method invocations:
#      Specifying 'T:System.Linq.Enumerable' only detects direct type references (e.g., typeof(Enumerable)).
#      Extension method calls on instances (e.g., list.FirstOrDefault(), source.Where(...)) are NOT caught.
#      To ban extension methods like LINQ, ban specific methods explicitly using 'M:' (e.g., M:System.Linq.Enumerable.FirstOrDefault...)
#      or remove implicit usings via <Using Remove="System.Linq" /> in Directory.Build.props.
#
#   3. Interface .ToString() statically binds to System.Object.ToString:
#      ISymbol and INamespaceSymbol are interfaces and do not declare ToString().
#      In C#, calling symbol.ToString() statically resolves to System.Object.ToString at compile-time.
#      Therefore, banning only M:Microsoft.CodeAnalysis.ISymbol.ToString will NOT catch invocations on interface instances.
#
#   4. Backtick syntax for generics (DocId specification):
#      - Generic Types: Single backtick with arity count (e.g., List`1, Dictionary`2).
#      - Generic Methods: Double backticks for method type parameters in signature (e.g., IEnumerable{``0}, Func{``0,System.Boolean}).
# ==============================================================================

# 1. Regular expressions: banned in the root BannedSymbols.txt

# 2. Reflection prohibition (keeps the compilation fast; .agents/rules/transpiler-emission.md 1.1)
N:System.Reflection;Direct reflection is strictly prohibited in the compiler (it slows the compilation down). Use Roslyn SemanticModel, ITypeSymbol, and IMethodSymbol instead.
P:System.Type.Assembly;Reflection via Type.Assembly is strictly prohibited in the compiler (it slows the compilation down).
M:System.Type.GetType(System.String);Dynamic type resolution via string is strictly prohibited. Use Compilation.GetTypeByMetadataName instead.

# 3. Non-deterministic APIs (incremental cache, deterministic output)
P:System.DateTime.Now;Values that change between runs break the incremental cache and deterministic output. Derive the value from the input (a hash of the source).
P:System.DateTime.UtcNow;Values that change between runs break the incremental cache and deterministic output. Derive the value from the input (a hash of the source).
M:System.Guid.NewGuid;Values that change between runs break the incremental cache and deterministic output. Derive the value from the input (a hash of the source).

# 4. Collection prohibitions in Compiler
T:System.Collections.Generic.List`1;List<T> grows by reallocation. Use ImmutableArray (ImmutableArray.CreateBuilder), an array, ArrayPool, or StackLinq .AsStackEnumerable().ToArray().

# 5. LINQ prohibition (Enforces Zero-Allocation / High Performance in Compiler)
# Covered by the root BannedSymbols.Linq.txt. Use the embedded StackLinq (Kassyi.ZeroAlloc.Linq.Embedded) via .AsStackEnumerable(), not hand-written loops.

# 6. StringBuilder prohibition (generated code goes through SourceWriter)
T:System.Text.StringBuilder;Emit code with SourceWriter, and build a name with + or an interpolated string.
